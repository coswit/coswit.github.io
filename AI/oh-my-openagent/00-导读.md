# 导读

本系列是 [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent)（社区简称 **OmO**）的中文学习笔记，依据 **2026 年 8 月** 项目 dev 分支的 README 与 `docs/`（installation / overview / orchestration / features / configuration / team-mode）整理。OmO 迭代极快，阅读时若与上游最新文档有出入，以上游为准。

## 这个项目是什么

一句话：**把 OpenCode 这个开源 AI 编程客户端，武装成一支多模型协同的 AI 工程团队。** 装上插件，敲 `ultrawork`，Sisyphus、Hephaestus、Oracle 等一队智能体自己开会、拆任务、写代码、验证、交付。

当前它以**三个发行版**（edition）存在：

| 发行版 | 宿主 | 安装命令 | 定位 |
| --- | --- | --- | --- |
| **Ultimate** | OpenCode 插件 | `bunx oh-my-openagent install` | 完整版：11 个 Agent、约 50–62 个 Hook、全部斜杠命令、Team Mode |
| **Light**（LazyCodex） | OpenAI Codex CLI | `npx lazycodex-ai install` | 可移植组件子集（rules、comment-checker、LSP、ultrawork、ulw-loop 等） |
| **Senpi**（beta） | 独立运行 | `npm i -g omo-ai@beta` | 原生 `omo` 命令，内置 OMO 扩展，无需先装宿主 |

本系列以 **Ultimate（OpenCode 插件）** 为主线。

## 从旧版本过来的速查

这套笔记的前一版基于旧快照（`/start-work`、`/ulw-loop` 时代），如果你也从那个时期过来，下面是最重要的对应关系：

| 旧 | 现（2026-08） |
| --- | --- |
| `bunx oh-my-opencode install` | `bunx oh-my-openagent install`（装好后短命令 `omo-agent-toolkit`） |
| `/start-work` 启动 Atlas | `/ulw-execute [plan-name] [--worktree] [--make-pr] [--ship]` |
| `/ulw-loop`、`/ralph-loop`、`/cancel-ralph` | 已移除，持续追击改由 `/goal` 承担 |
| 配置 `~/.config/opencode/oh-my-openagent.json` | 统一配置 `~/.omo/omo.jsonc` 的 `[opencode]` 块（旧文件一次性自动迁移） |
| 计划目录 `.sisyphus/` | `.omo/`（plans、notepads、boulder.json、goal 等） |
| Hashline 编辑默认启用 | 改为 opt-in：`hashline_edit: true` |
| Skill `frontend-ui-ux` / `ai-slop-remover` | 更名 `frontend` / `remove-ai-slops` |
| 模型 claude-opus-4-7 / gpt-5.4 / kimi-k2.5 | 换代 claude-opus-5 / gpt-5.6-sol / kimi-k3 等 |

## 术语约定

- **Agent（智能体）**：Sisyphus、Atlas 等角色名保留英文原名；
- **Category（类别）**：`visual-engineering`、`quick` 等按"任务种类"路由模型的抽象；
- **Skill（技能）**：SKILL.md 定义的领域知识 + 内嵌 MCP 组合；
- **Hook（钩子）**：生命周期拦截器，OmO 的"操作系统"层；
- **MCP（Model Context Protocol）**：模型对接外部工具的标准协议；
- **LSP（Language Server Protocol）**：语言服务器协议，IDE 语义能力；
- **Hashline**：按内容哈希定位行的编辑技术（`LINE#ID`）。
