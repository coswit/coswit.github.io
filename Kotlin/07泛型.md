## 泛型参数(generic type parameters)

类型参数既可以在变量中声明类型，也可以在创建列表的函数中声明：

```kotlin
val readers: MutableList<String> = mutableListOf()
val readers = mutableListOf<String>()
```

在Kotlin中有时编译器可以推导出类型：

```kotlin
// 函数定义
public fun <T> List<T>.slice(indices: IntRange): List<T>

fun main(args: Array<String>) {
    val letters = ('a'..'z').toList()
    println(letters.slice<Char>(0..2)) // 显式指定类型
    println(letters.slice(10..13)) // 编译器推导出类型
}
```

### 参数约束 constraints

上界约束(upper bound)对应类型为子类型：

```kotlin
fun <T : Number> oneHalf(value: T): Double {
    return value.toDouble() / 2.0
}

fun main(args: Array<String>) {
    println(oneHalf(3))
}
```

可以为一个类型指定多个约束，如实参类型必须同时实现`CharSequence`和`Appendable`：

```kotlin
fun <T> ensureTrailingPeriod(seq: T)where T : CharSequence, T : Appendable {
    if (!seq.endsWith('.')) {
        seq.append('.')
    }
}

fun main(args: Array<String>) {
    val helloWorld = StringBuilder("Hello World")
    ensureTrailingPeriod(helloWorld)
    println(helloWorld)
}
// Hello World.
```
### 类型参数的可空性

声明泛型参数时，没有指定上界时，会使用`Any？`作为默认上界，是可空的：

```kotlin
class Processor<T> {
    fun process(value: T) {
        value?.hashCode()
    }
}

fun main(args: Array<String>) {
    val processor = Processor<String?>()
    println(processor.process(null))
}
```

如果想保证为非空类型，可使用`Any`来代替`Any?`：

```kotlin
class Processor<T : Any> {
    fun process(value: T) {
        value.hashCode()
    }
}
```
## 泛型擦除(type erasure )和实化类型参数(reified type parameters)

泛型擦除是JVM历史遗留问题，Java1.5引入泛型时，为了兼容老版本，选择了擦除方式，Kotlin运行在JVM上，同样受此限制。

```kotlin
fun <T> isA(value: Any) = value is T
//Error: Cannot check for instance of erased type: T
```

不知道具体类型时，可以使用`*`，表示类型为`Any?`，在运行时类型信息会被擦除：

```kotlin
fun printSum(c: Collection<*>) {
    // 会有编译告警:Unchecked cast: List<*> to List<Int>
    val intList = c as? List<Int> ?: throw IllegalArgumentException("List is expected")
    println(intList.sum())
}

fun main(args: Array<String>) {
    printSum(listOf(1, 2, 3))
    printSum(listOf("a", "b"))
}
// 6
//ClassCastException: java.lang.String cannot be cast to java.lang.Number
```

### reified实化

内联函数的类型参数能够被实化，可通过`reified`配合`inline`函数，让编译器在展开时保留类型信息：

```kotlin
inline fun <reified T> isA(value: Any) = value is T

fun main(args: Array<String>) {
    println(isA<String>("abc"))
    println(isA<String>(123))
}
// true false
```

实化(reification)只对内联函数有效，因为编译会把内联函数调用的地方，生成引用作为类型实参的具体类的字节码：

```kotlin
inline fun<reified T> Iterable<*>.filterIsInstance():List<T>{
    val destination = mutableListOf<T>()
    for (element in this){
        if (element is T){
            destination.add(element)
        }
    }
    return destination
}

fun main(args: Array<String>) {
    val items = listOf("one", 2, "three")
    println(items.filterIsInstance<String>())
}
//[one, three]
```

上述代码，会生成如下字节码：

```kotlin
 for (element in this){
        if (element is String){
            destination.add(element)
        }
    }
```

### 通过实化参数(reified type parameters)来减少 传递`class`类型

```kotlin
// 不用传 Class 参数，更简洁
inline fun <reified T> fromJson(json: String): T {
    return Gson().fromJson(json, T::class.java)
}

// 普通写法需要手动传 Class
fun <T> fromJson(json: String, clazz: Class<T>): T {
    return Gson().fromJson(json, clazz)
}

// 对比调用方式
val user1 = fromJson<User>(json)           // reified，简洁
val user2 = fromJson(json, User::class.java) // 普通，繁琐
```
如在Android中：

```kotlin
inline fun <reified T : Activity> Context.startActivity() {
    val intent = Intent(this, T::class.java)
    startActivity(intent)
}

startActivity<DetailActivity>()
```

##  型变variance

型变描述的是泛型类型之间的继承关系，如String是Any的子类型，但`List<String>`和`List<Any>`是什么关系？

默认情况下，泛型是**不变的(Invariant)**，如果泛型类型是用于输出，只读的，则类型是是**协变的(Covariant)**。如String是Any的子类型，方向一致，称之为Covariant：

```kotlin
fun printContents(list: List<Any>) {
    println(list.joinToString())
}

fun main(args: Array<String>) {
    printContents(listOf("abc", "bac"))
}
// abc, bac

// List源码
public interface List<out E> : Collection<E> {
    fun get(index: Int): E   // 只读，E 只出现在 out 位置
}
```

当`List`变为`MutableList`后，由只读变为可读可写，此时是Invariant：

```kotlin
fun addAnswer(list: MutableList<Any>){
    list.add(42)
}

fun main(args: Array<String>) {
    val strings  = mutableListOf("abc","abd")
    addAnswer(strings)//编译错误
}
```

### 不变(Invariant)

在一个方法接收一个T类型对像时，可以给方法传任何T的派生对像。但是如果方法的接收类型为T的泛型对像，则方法不能接收其派生对像，这就是类型的不变性：

```kotlin
open class Fruit
class Banana : Fruit()
class Orange : Fruit()

fun receiveFruits(fruits: Array<Fruit>) {
    println("Number of fruits: ${fruits.size}")
}

fun main(args: Array<String>) {
    // 使用了泛型
    val bananas: Array<Banana> = arrayOf()
    receiveFruits(bananas) //ERROR: type mismatch
}
```

### 协变(Covariance)-`out`

在Java中，使用语法`<? extends T>`来传递协变。在Kotlin中，**协变Covariant**可用来保留子类的型，要声明某个类型参数上是可协变的，在对应的类型名称前加上`out`关键字：

```kotlin
interface Producer<out T> {
    fun produce(): T
}
```

将示例中的`Array<Fruit>`改为`List<Fruit>`则可以，因为List中定义了协变：

```kotlin
fun receiveFruits(fruits: List<Fruit>) {
    println("Number of fruits: ${fruits.size}")
}

fun main(args: Array<String>) {
    val bananas = listOf<Banana>()
    receiveFruits(bananas)
}
```

通过协变将允许Fruit类型接收Banana类型，但只能读取，不能修改，这种语法称为**使用点型变(use-site variance)**：


```kotlin
fun copyFromTo(from: Array<out Fruit>, to: Array<Fruit>) {
    for (i in 0 until from.size) {
        to[i] = from[i]
    }
}

fun main(args: Array<String>) {
    val fruitsBasket = Array<Fruit>(3) { _ -> Fruit() }
    val bananaBasket = Array<Banana>(3) { _ -> Banana() }
    copyFromTo(bananaBasket, fruitsBasket) //OK
    println(bananaBasket[0] == fruitsBasket[0])
}
```


### 逆变(Contravariance)-`in`

当我们期望，在类型T的地方允许T的超类，即告诉编译器允许逆变。在Java中，逆变通过语法<? super T>来实现，Kotlin中通过`in`来实现，该语法称为**声明点型变(declaration-site varianc)**。

```kotlin
fun copyFromTo(from: Array<out Fruit>, to: Array<in Fruit>) {
    for (i in 0 until from.size) {
        to[i] = from[i]
    }
}

fun main(args: Array<String>) {
    val things = Array<Any>(3) { _ -> Fruit() }
    val bananaBasket = Array<Banana>(3) { _ -> Banana() }
    copyFromTo(bananaBasket, things) //OK
    println(bananaBasket[0] == things[0])
}
// true
```

### 星号投影

当不知道关于泛型实参的任何信息时，可以使用星号投影，如`List<*>`。`MutableList<*>`和`MutableList<Any?>`是不同的，前者表示要放入某种特定类型，只是不知道具体类型；而后者表示放入任意类型的元素。Kotlin的`Type<*>`对应Java的`Type<?>`。

```kotlin
val list:MutableList<Any?> = mutableListOf("a",1,"qwe")
val chars = mutableListOf('a','b','c')
val unkonownElements:MutableList<*> = if (Random().nextBoolean()) list else chars

fun main(args: Array<String>) {
    // 编译器禁示调用修改方法
    unkonownElements.add(42)
    // 读取是安全的
    print(unkonownElements.first())
}
```
