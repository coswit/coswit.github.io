## 并发与并行

并发(Concurrency)：逻辑上同时处理多任务（结构），单核处理器即可实现，让任务交替执行。

并行(parallelism)：物理上的同时执行（运行），必须多核处理器，多核CPU同时运行多个程序或线程。

## 协程Coroutine

Coroutine是Kotlin中处理并发的核心工具，协程可挂起和恢复，相比线程更加轻量，挂起时释放线程，不占用资源。而线程则由操作系统管理，创建过多线程时会耗尽内存资源。

```kotlin
fun main() {
    println("I'm on ${Thread.currentThread().name}")
    thread { // <1>
        println("And I'm on ${Thread.currentThread().name}")
    }
}
// I'm on main
// And I'm on Thread-0
```

### suspend

挂起函数（`suspend`)的本质是，编译器会将其转换为状态机+回调，不会阻塞线程，只能在协程或另一个suspend函数中调用：

```kotlin
// 普通函数, 会阻塞线程
fun fetchData(): String {
    Thread.sleep(2000) // 阻塞线程
    return "data"
}

// 挂起函数, 挂起协程，线程可以去做别的事
suspend fun fetchData(): String {
    delay(2000) // 只挂起协程，不阻塞线程
    return "data"
}
```

### runBlocking

`runBlocking`是`kotlinx.coroutines`中的一个函数，接受一个lambda作为参数，并在协程中执行该参数，会阻塞当前执行线程：

```kotlin
fun task1() {
    println("start task1 in Thread ${Thread.currentThread()}")
    println("end task1 in Thread ${Thread.currentThread()}")
}

fun task2() {
    println("start task2 in Thread ${Thread.currentThread()}")
    println("end task2 in Thread ${Thread.currentThread()}")
}

fun main() = runBlocking {
    println("start")
    runBlocking {
        task1()
        task2()
        println("called task1 and task2 from ${Thread.currentThread()}")
    }
    println("done")
}
/*
start
start task1 in Thread Thread[main,5,main]
end task1 in Thread Thread[main,5,main]
start task2 in Thread Thread[main,5,main]
end task2 in Thread Thread[main,5,main]
called task1 and task2 from Thread[main,5,main]
done
*/

```

### launch

launch函数用于启动一个新的协程来执行给定的lambda，且不阻塞当前执行线程，会返回Job，可用于取消任务；但不会返回执行结果。在Kotlin中，将当前任务挂起，而让另一个任务执行，有两种方法实现

- `delay`：会将当前任务暂停指定毫秒数

- `yield`：类似于Unix中的nice命令，通过nice会降低进程在系统上的优先级。在Kotlin中，yield会让当前协程主动暂停，让给其他协程，等机会再恢复。yield只能用于suspend函数中使用挂起点。

```kotlin
suspend fun task1() {
    println("start task1 in Thread ${Thread.currentThread()}")
    yield()
    println("end task1 in Thread ${Thread.currentThread()}")
}

suspend fun task2() {
    println("start task2 in Thread ${Thread.currentThread()}")
    yield()
    println("end task2 in Thread ${Thread.currentThread()}")
}

fun main() {
    println("start")
    runBlocking {
        launch { task1() }
        launch { task2() }
        println("called task1 and task2 from ${Thread.currentThread()}")
    }
    println("done")
}
/*
start
called task1 and task2 from Thread[main,5,main]
start task1 in Thread Thread[main,5,main]
start task2 in Thread Thread[main,5,main]
end task1 in Thread Thread[main,5,main]
end task2 in Thread Thread[main,5,main]
done
*/
```

### async

类似于launch，`async`用于并发时，会返回一个持有值的Job：`Deferred<T>`，可通过`await`来取值。

```kotlin
suspend fun slowlyAddNumbers(a: Int, b: Int): Int {
    log("Waiting a bit before calculating $a + $b")
    delay(100.milliseconds * a)
    return a + b
}

fun main() = runBlocking {
    log("Starting the async computation")
    val myFirstDeferred = async { slowlyAddNumbers(2, 2) } 
    val mySecondDeferred = async { slowlyAddNumbers(4, 4) } 
    log("Waiting for the deferred value to be available")
    log("The first result: ${myFirstDeferred.await()}") 
    log("The second result: ${mySecondDeferred.await()}")
}
/*
0 [main] Starting the async computation
4 [main] Waiting for the deferred value to be available
8 [main] Waiting a bit before calculating 2 + 2
9 [main] Waiting a bit before calculating 4 + 4
213 [main] The first result: 4
415 [main] The second result: 8
*/
```

## Dispatcher调度器

`Dispatcher`是协程的调度器，指定协程运行在哪个线程或线程池上。`Dispatcher`的主要类型：

- `Dispatchers.Default`：主要用于CPU密集型计算，如复杂计算、排序等。线程数为CPU核数，线程数超过CPU核数时，会进行上下文切换。
- `Dispatchers.IO`：用于IO型任务，如网络请求，文件读写等。
- `Dispatchers.Main`：主线程，用于UI更新。
- `Dispatchers.Unconfined`：一个特殊的调度器，不限定任何特定线程。

在协程构建时，如`runBlocking`，`launch`，`async`中都可以指定调度器：

```kotlin
fun main() {
    runBlocking {
        log("Doing some work")
        launch(Dispatchers.Default) {
            log("Doing some background work")
        }
    }
}
```

### withContext

使用`withContext`可进行调度器的灵活切换，与`launch`不同，`withContext`会先切换指定线程执行，等结果，再切回原来执行线程。而`launch`会新开协程，并发执行，不等结果。

```kotlin
suspend fun fetchUserData(): User {
    // 在 IO 线程执行网络请求
    val response = withContext(Dispatchers.IO) {
        api.fetchUser()
    }
    // 回到主线程处理 UI
    withContext(Dispatchers.Main) {
        updateUI(response)
    }
    return response
}
```

```kotlin
suspend fun loadUser(id: String): User {
    return withContext(Dispatchers.IO) {    // 切到 IO 线程
        api.getUser(id)                     // 网络请求
    }                                       // 自动切回调用者的线程
}

// ViewModel中使用
viewModelScope.launch {                    // Main 线程
    val user = loadUser("123")             // 内部切到 IO，返回后回到 Main
    nameTextView.text = user.name          // 仍在 Main 线程，安全
}
```

### Mutex

互斥锁(Mutex)用多协程调用时，对共享资源进行互斥协调的同步机制。当协程尝试获取已被占用的锁时，会挂起而非阻塞线程，使底层线程去执行其他协程。

在单一协程下，不存在数据竞争：

```kotlin
fun main4() {
    runBlocking {
        launch(Dispatchers.Default) { // <1>
            var x = 0
            repeat(10_000) {
                x++
            }
            println(x)
        }
    }
} // 10000
```

在多协程时，访问修改同一数据时会有问题：

```kotlin
runBlocking {
    var x = 0
    repeat(10_000) {
        launch(Dispatchers.Default) { // <1>
            x++
        }
    }
    delay(1.seconds)
    println(x)
} // 9969
```

增加互斥锁后可修复：

```kotlin
fun main() = runBlocking {
    val mutex = Mutex()
    var x = 0
    repeat(10_000) {
        launch(Dispatchers.Default) {
            mutex.withLock {
                x++
            }
        }
    }
    delay(1.seconds)
    println(x)
} // 10000
```

### CoroutineContext

`CoroutineContext`使用下述元素定义协程的行为：

- Job：控制协程的生命周期。
- `CoroutineDispather`：将执行过程分配到适当的线程。
- `CoroutineName`：协程名称
- `CoroutineExceptionHandler`：处理异常。

```kotlin
val scope = CoroutineScope(Job() + Dispatchers.Main)

val job1 = scope.launch {}
//  New coroutine with CoroutineName = "BackgroundCoroutine" (overridden)
val job2 = scope.launch(Dispatchers.Default
    + CoroutineName("BackgroundCoroutine")) {}
```

`CoroutineContext`协程上下文，是协程运进环境的属性配置，包含Dispatcher、协程名称、异常处理器等。可自定义：

```kotlin
suspend fun introspect() {
    log(coroutineContext)
}

fun main() {
    runBlocking {
        introspect()
    }

    runBlocking(Dispatchers.IO + CoroutineName("Coolroutine")) {
        introspect()
    }
}
// 0 [main] [BlockingCoroutine{Active}@8807e25, BlockingEventLoop@2a3046da]
// 14 [DefaultDispatcher-worker-1] [CoroutineName(Coolroutine), BlockingCoroutine{Active}@7c9d1590, Dispatchers.IO]
```

## 协程作用域(CoroutineScope)

`CoroutineScope`的定义：

```kotlin
public interface CoroutineScope {
    public val coroutineContext: CoroutineContext
}
```

### 创建

`CoroutineScope`是对Context的一层包装，通过`CoroutineScope`实现结构化并发，使协程的生命周期限制在某个作用域内。

```kotlin
// ❌ GlobalScope协程生命周期和整个应用一样长
GlobalScope.launch {
    delay(10_000)
    updateUI()   // Activity 早就销毁了，但协程还在跑！内存泄漏！
}

// ✅ 绑定生命周期的 Scope
viewModelScope.launch {
    delay(10_000)
    updateUI()   // ViewModel 销毁时，协程自动取消，安全
}
```

创建`CoroutineScope`：

```kotlin
suspend fun generateValue(): Int {
    delay(500.milliseconds)
    return Random.nextInt(0, 10)
}

suspend fun computeSum() { // suspending
    log("Computing a sum...")
    val sum = coroutineScope { // 作用域
        val a = async { generateValue() }
        val b = async { generateValue() }
        a.await() + b.await() // 等待结果返回
    }
    log("Sum is $sum")
}

fun main() = runBlocking {
    computeSum()
}
// 0 [main] Computing a sum...
// 533 [main] Sum is 15
```

通过`CoroutineScope()`函数来创建，同时使用`SupervisorJob`，`SupervisorJob`不同于普通的Job，它的异常不会传导给父协程及其他同级子协程，需要每个子协程独立处理自己的异常：

```kotlin
class ComponentWithScope(dispatcher: CoroutineDispatcher = Dispatchers.Default) {
    private val scope = CoroutineScope(dispatcher + SupervisorJob())

    fun start() {
        log("Starting!")
        scope.launch {
            while (true) {
                delay(500.milliseconds)
                log("Component working!")
            }
        }
        scope.launch {
            log("Doing a one-off task...")
            delay(500.milliseconds)
            log("Task done!")
        }
    }

    fun stop() {
        log("Stopping!")
        scope.cancel()
    }
}

fun main() {
    val c = ComponentWithScope()
    c.start()
    Thread.sleep(2000)
    c.stop()
}
/*
0 [main] Starting!
23 [DefaultDispatcher-worker-2] Doing a one-off task...
537 [DefaultDispatcher-worker-1] Component working!
537 [DefaultDispatcher-worker-2] Task done!
1040 [DefaultDispatcher-worker-2] Component working!
1550 [DefaultDispatcher-worker-2] Component working!
2035 [main] Stopping!
*/
```

### 取消

取消任务：

```kotlin
fun main() {
    runBlocking {
        val launchedJob = launch {
            log("I'm launched!")
            delay(1000.milliseconds)
            log("I'm done!")
        }
        val asyncDeferred = async {
            log("I'm async")
            delay(1000.milliseconds)
            log("I'm done!")
        }
        delay(200.milliseconds)
        launchedJob.cancel() 
        asyncDeferred.cancel()
    }
}
// 0 [main] I'm launched!
// 1 [main] I'm async
```

`withTimeoutOrNull`用于协程的超时控制，超过设定的超时时间，会返回null，而不的正常的执行结果：

```kotlin
suspend fun calculateSomething(): Int {
    delay(3.seconds)
    return 2 + 2
}

fun main() = runBlocking {
    val quickResult = withTimeoutOrNull(500.milliseconds) {
        calculateSomething()
    }
    println(quickResult)
    // null
    val slowResult = withTimeoutOrNull(5.seconds) {
        calculateSomething()
    }
    println(slowResult)
    // 4
}
```

当一个协程取消时，协程内的所有子协程也会被同时取消：

```kotlin
fun main() = runBlocking {
    val job = launch {
        launch {
            launch {
                launch { // <1>
                    log("I'm started")
                    delay(500.milliseconds)
                    log("I'm done!")
                }
            }
        }
    }
    delay(200.milliseconds)
    job.cancel()
} // 0 [main] I'm started
```

`yield`配合`suspend`来对多协程进行挂起：

```kotlin
suspend fun doCpuHeavyWork(): Int {
    log("I'm doing work!")
    var counter = 0
    val startTime = System.currentTimeMillis()
    while (System.currentTimeMillis() < startTime + 500) {
        counter++
        // 如果不加yield，不会将协程1挂起，直到1执行完，才会执行2
        yield()
    }
    return counter
}

fun main() {
    runBlocking {
        launch {
            repeat(3) {
                val ret = doCpuHeavyWork()
                log("launch 1: $ret")
            }
        }
        launch {
            repeat(3) {
                val ret = doCpuHeavyWork()
                log("launch 2: $ret")
            }
        }
    }
}
```
