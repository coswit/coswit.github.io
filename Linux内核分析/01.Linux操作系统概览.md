## 1. 什么是操作系统

**操作系统(Operating System, OS)是直接管理计算机硬件资源、控制其他程序执行并为应用程序提供服务的系统软件**。它向下管理 CPU、内存、I/O(Input/Output) 设备等资源，向上为应用程序提供运行环境和服务接口，是硬件与应用软件之间的桥梁。

理解操作系统通常有两个互补的视角：

| 视角 | 操作系统是什么 | 典型职责 |
| --- | --- | --- |
| 资源管理者 | 计算机资源的管理者 | 进程管理、内存管理、设备管理、文件管理 |
| 服务提供者 | 为应用程序提供服务的软件层 | 系统调用接口、库函数、Shell 环境 |

应用程序不能直接访问硬件，必须通过操作系统提供的**系统调用(System Call)**进入内核获得服务——这是操作系统保护硬件资源、实现多任务并存的基础。

## 2. Linux 操作系统简介

- 1991 年 Linus Torvalds 发布第一版 Linux 内核，遵循 GPL(GNU General Public License) 开源协议，与 GNU 工具链结合形成完整的操作系统
- 今天广泛应用于服务器、嵌入式设备、云计算与移动端（Android 的底层即 Linux 内核）
- 内核与发行版的关系：内核(kernel)负责进程、内存、驱动、文件系统等核心功能；Ubuntu、openEuler 等发行版在内核之外打包了 shell、库和应用软件

## 3. 单内核与微内核

| 体系结构 | 思想 | 优点 | 缺点 | 代表 |
| --- | --- | --- | --- | --- |
| 单内核(monolithic kernel) | 所有核心服务运行在同一内核态地址空间 | 性能高，模块间调用就是函数调用 | 内核庞大，一处崩溃全盘皆输 | Linux |
| 微内核(micro kernel) | 内核只保留最小能力（IPC、调度、基本内存），其他服务作为用户态进程 | 可靠、易扩展 | 大量消息传递开销，性能低 | Minix、QNX |

Linux 采用单内核结构，但通过**可加载内核模块(Loadable Kernel Module, LKM)**吸收了微内核的灵活性：驱动、文件系统等可以编译成模块，按需 insmod 加载，不必整体重编内核。

## 4. Linux 内核源码目录结构

| 目录 | 内容 |
| --- | --- |
| arch/ | 体系结构相关代码，如 arch/x86/（课程分析的重点） |
| kernel/ | 进程调度、fork、时间、软中断等核心子系统 |
| mm/ | 内存管理 |
| fs/ | 各具体文件系统与 VFS(Virtual File System) |
| drivers/ | 设备驱动，占源码大头 |
| ipc/ | 进程间通信(Inter-Process Communication, IPC) |
| net/ | 网络协议栈 |
| include/ | 内核头文件，如 include/linux/sched.h 中的 task_struct |
| init/ | 内核启动入口 start_kernel 所在的 main.c |

## 5. 分析主线

孟宁老师课程的一条主线是：**存储程序计算机工作模型 + 函数调用堆栈 + 中断机制**。

- 存储程序计算机：硬件如何自动执行程序
- 函数调用堆栈：高级语言如何基于堆栈组织函数调用、参数与局部变量
- 中断机制：操作系统如何夺回控制权，时钟如何驱动调度
