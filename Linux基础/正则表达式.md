## 语法

定位符 Anchors

| 字符 | 描述                       |
| :--: | -------------------------- |
| `^`  | 为匹配输入字符串的开始位置（多行模式下匹配行首） |
| `$`  | 为匹配输入字符串的结束位置（多行模式下匹配行尾） |

字符集 

|   字符   | 描述                                          |
| :------: | --------------------------------------------- |
| `[a-z]`  | 字符集。`-` 表示范围，不转义时要放在首位或末位才表示字面量 |
| `[^a-z]` | 否定字符集                                    |

重复

| 字符 | 描述                                               |
| :--: | -------------------------------------------------- |
|  ？  | 表示前一个字符是可选的，匹配0次或1次，等价于 {0,1} |
|  *   | 通配符匹配零个或多个字符                           |
|  +   | 匹配一个或者多个                                   |

简写字符

| 字符 | 描述                                         |
| :--: | -------------------------------------------- |
| `.`  | 匹配除换行符 \n 之外的任何单字符             |
| `\w` | 匹配字母、数字、下划线。等价于`[A-Za-z0-9_]` |
| `\W` | 匹配非字母和数字的字符：`[^\w]`              |
| `\d` | 匹配数字：`[0-9]`                            |
| `\D` | 匹配非数字：`[^\d]`                          |
| `\s` | 匹配空格符：`[\t\n\f\r\p{Z}]`                |
| `\S` | 匹配非空格符：`[^\s]`                        |

其他

|     字符      | 描述                                                         |
| :-----------: | :----------------------------------------------------------- |
|      \|      | 分支结构                                                     |
|      `\`      | 转义字符，允许保留字符 `[ ] ( ) { } . * + ? ^ $ \ |`         |
|     `()`      | 子表达式的开始和结束位置                                     |
|     `{n}`     | 匹配确定的 n 次                                              |
|    `{n,}`     | 至少匹配n 次                                                 |
|     {n,m}     | 匹配 n 次且最多匹配 m 次                                     |
|  `(pattern)`  | 匹配pattern并获取这一匹配的子字符串，捕获组                  |
| `(?:pattern)` | 匹配 `pattern` 但不获取匹配结果，非捕获组，不进行存储供以后使用。<br>这在使用 "或" 字符 `(|)` 来组合一个模式的各个部分是很有用。<br>例如， `industr(?:y|ies)` 是一个比 `industry|industries` 更简略的表达式。<br>匹配86手机号` ^(?:\+?86)?1(?:[3456789])\d{9}$` |

贪婪与懒惰（Greedy and Lazy）

贪婪量词默认尽可能多地匹配；在量词后加 `?` 变为懒惰（非贪婪）模式，尽可能少地匹配：

| 字符  | 描述                                       |
| :---: | ------------------------------------------ |
| `*?`  | 懒惰匹配任意次                             |
| `+?`  | 懒惰匹配一次或多次                         |
| `??`  | 懒惰匹配零次或一次                         |

```text
# 贪婪：匹配从第一个 < 到最后一个 > 的整段
<.*>   对 "<a><b>" 匹配 "<a><b>"
# 懒惰：匹配到最近的 > 就停
<.*?>  对 "<a><b>" 匹配 "<a>" 和 "<b>"
```

修饰符（Flags），写在正则表达式之外，如 `/\d+/g`：

| 修饰符 | 描述                                           |
| :----: | ---------------------------------------------- |
| `i`    | ignoreCase，忽略大小写                         |
| `g`    | global，全局匹配（找出所有匹配，而非第一个）   |
| `m`    | multiline，多行模式，`^` 与 `$` 匹配行首/行尾  |
| `s`    | single line（dotAll），让 `.` 也能匹配换行符   |

环视断言（Lookaround，零宽断言）

| 符号 | 描述         | 示例                                       |
| ---- | ------------ | ------------------------------------------ |
| `?=`  | 正向先行断言 | `foo(?=bar)` 匹配后面跟着 bar 的 foo       |
| `?!`  | 负向先行断言 | `foo(?!bar)` 匹配后面不跟 bar 的 foo       |
| `?<=` | 正向后行断言 | `(?<=foo)bar` 匹配前面是 foo 的 bar        |
| `?<!` | 负向后行断言 | `(?<!foo)bar` 匹配前面不是 foo 的 bar      |

> 环视断言只判断位置，不消耗字符（零宽），匹配结果里不包含括号内的内容。常用于"有/没有某前缀后缀才匹配"的场景，如强密码校验 `(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,10}`。

## 实例

> 说明：实例部分源自网络流传的常用表达式清单，已修正其中明显的转义错误（如未转义的小数点 `.`）与过时段位（手机号），不同语言/工具的正则方言略有差异，使用前建议先在 [regex101](https://regex101.com) 验证。

### 校验数字的表达式
```text
 1 数字：^[0-9]*$
 2 n位的数字：^\d{n}$
 3 至少n位的数字：^\d{n,}$
 4 m-n位的数字：^\d{m,n}$
 5 零和非零开头的数字：^(0|[1-9][0-9]*)$
 6 非零开头的最多带两位小数的数字：^([1-9][0-9]*)+(\.[0-9]{1,2})?$
 7 带1-2位小数的正数或负数：^(\-)?\d+(\.\d{1,2})?$
 8 正数、负数、和小数：^(\-|\+)?\d+(\.\d+)?$
 9 有两位小数的正实数：^[0-9]+(\.[0-9]{2})?$
10 有1~3位小数的正实数：^[0-9]+(\.[0-9]{1,3})?$
11 非零的正整数：^[1-9]\d*$ 或 ^([1-9][0-9]*){1,3}$ 或 ^\+?[1-9][0-9]*$
12 非零的负整数：^-[1-9]\d*$
13 非负整数：^\d+$ 或 ^([1-9]\d*|0)$
14 非正整数：^(-[1-9]\d*|0)$ 或 ^((-\d+)|(0+))$
15 非负浮点数：^\d+(\.\d+)?$ 或 ^([1-9]\d*\.\d*|0\.\d*[1-9]\d*|0?\.0+|0)$
16 非正浮点数：^((-\d+(\.\d+)?)|(0+(\.0+)?))$ 或 ^(-([1-9]\d*\.\d*|0\.\d*[1-9]\d*)|0?\.0+|0)$
17 正浮点数：^[1-9]\d*\.\d*|0\.\d*[1-9]\d*$ 或 ^(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*))$
18 负浮点数：^-([1-9]\d*\.\d*|0\.\d*[1-9]\d*)$ 或 ^-(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*))$
19 浮点数：^(-?\d+)(\.\d+)?$ 或 ^-?([1-9]\d*\.\d*|0\.\d*[1-9]\d*|0?\.0+|0)$
```
### 校验字符的表达式
```text
 1 汉字：^[\u4e00-\u9fa5]{0,}$
 2 英文和数字：^[A-Za-z0-9]+$ 或 ^[A-Za-z0-9]{4,40}$
 3 长度为3-20的所有字符：^.{3,20}$
 4 由26个英文字母组成的字符串：^[A-Za-z]+$
 5 由26个大写英文字母组成的字符串：^[A-Z]+$
 6 由26个小写英文字母组成的字符串：^[a-z]+$
 7 由数字和26个英文字母组成的字符串：^[A-Za-z0-9]+$
 8 由数字、26个英文字母或者下划线组成的字符串：^\w+$ 或 ^\w{3,20}$
 9 中文、英文、数字包括下划线：^[\u4E00-\u9FA5A-Za-z0-9_]+$
10 中文、英文、数字但不包括下划线等符号：^[\u4E00-\u9FA5A-Za-z0-9]+$ 或 ^[\u4E00-\u9FA5A-Za-z0-9]{2,20}$
11 可以输入含有^%&',;=?$\"等字符：[^%&',;=?$\x22]+
12 禁止输入含有~的字符：[^~\x22]+
```
### 特殊需求表达式
```text
 1 Email地址：^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$
 2 域名：[a-zA-Z0-9][-a-zA-Z0-9]{0,62}(\.[a-zA-Z0-9][-a-zA-Z0-9]{0,62})+\.?
 3 InternetURL：[a-zA-Z]+://[^\s]* 或 ^https?://([\w-]+\.)+[\w-]+(/[\w-./?%&=]*)?$
 4 手机号码（现行号段，不带前缀）：^1[3-9]\d{9}$
   含国际前缀 +86：^(?:\+?86)?1[3-9]\d{9}$
 5 电话号码("XXX-XXXXXXX"、"XXXX-XXXXXXXX"等)：^(\(\d{3,4}-|\d{3,4}-)?\d{7,8}$
 6 国内电话号码(0511-4405222、021-87888822)：\d{3}-\d{8}|\d{4}-\d{7}
 7 身份证号(15位数字，或18位末位为数字/X)：^(\d{15}|\d{17}[\dXx])$
 8 短身份证号码(数字、字母x结尾)：^[0-9]{7,18}[xX]?$
 9 帐号是否合法(字母开头，允许5-16字节，允许字母数字下划线)：^[a-zA-Z][a-zA-Z0-9_]{4,15}$
10 密码(以字母开头，长度在6~18之间，只能包含字母、数字和下划线)：^[a-zA-Z]\w{5,17}$
11 强密码(必须包含大小写字母和数字的组合，不能使用特殊字符，长度在8-10之间)：^(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,10}$
12 日期格式：^\d{4}-\d{1,2}-\d{1,2}$
13 一年的12个月(01～09和1～12)：^(0?[1-9]|1[0-2])$
14 一个月的31天(01～09和1～31)：^((0?[1-9])|((1|2)[0-9])|30|31)$
15 钱的输入格式（逐级演进）：
   1. "10000.00" 和 "10,000.00"，以及没有 "分" 的 "10000" 和 "10,000"：^[1-9][0-9]*$
   2. 还要接受单个字符"0"：^(0|[1-9][0-9]*)$
   3. 再允许开头有一个负号：^(0|-?[1-9][0-9]*)$
   4. 加上小数部分（小数点后至少 1 位，"10." 不通过）：^[0-9]+(\.[0-9]+)?$
   5. 小数点后必须两位：^[0-9]+(\.[0-9]{2})?$
   6. 放宽为 1~2 位：^[0-9]+(\.[0-9]{1,2})?$
   7. 考虑数字中的逗号分组：^[0-9]{1,3}(,[0-9]{3})*(\.[0-9]{1,2})?$
   8. 逗号成为可选：^([0-9]+|[0-9]{1,3}(,[0-9]{3})*)(\.[0-9]{1,2})?$
16 xml文件：^([a-zA-Z]+-?)+[a-zA-Z0-9]+\.[xX][mM][lL]$
17 中文字符：[\u4e00-\u9fa5]
18 双字节字符：[^\x00-\xff]    (包括汉字在内，可以用来计算字符串的长度(一个双字节字符长度计2，ASCII字符计1))
19 空白行：\n\s*\r    (可以用来删除空白行)
20 HTML标记：<(\S*?)[^>]*>.*?</\1>|<.*? />    (网上流传的版本太糟糕，上面这个也仅仅能部分，对于复杂的嵌套标记依旧无能为力)
21 首尾空白字符：^\s*|\s*$ 或 (^\s*)|(\s*$)    (可以用来删除行首行尾的空白字符(包括空格、制表符、换页符等等)，非常有用的表达式)
22 腾讯QQ号：[1-9][0-9]{4,}    (腾讯QQ号从10000开始)
23 中国邮政编码：[1-9]\d{5}(?!\d)    (中国邮政编码为6位数字)
24 IP地址（粗匹配，提取时有用）：\d+\.\d+\.\d+\.\d+
25 IP地址（精确）：((?:(?:25[0-5]|2[0-4]\d|[01]?\d?\d)\.){3}(?:25[0-5]|2[0-4]\d|[01]?\d?\d))
```
