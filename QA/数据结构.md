#### 线性表

线性表是具有相同类型的 n（n≥0）个数据元素组成的有限序列。

**数组**

元素在上下界内连续存储。特点：**随机访问 O(1)**（下标直接定位）、插入删除 O(n)（要搬移元素）。多维数组本质仍是一维数组实现；动态数组（容量可增长）在 Java 中即 ArrayList / Vector（ArrayList 扩容 1.5 倍、Vector 2 倍且方法同步）。

**单向链表**

每个节点包含数据与指向后继的指针，表头无前驱。增删只改指针（找到位置后 O(1)），但**随机访问 O(n)**、不能回溯。删除节点：`p.next = p.next.next`；插入节点：先接后继再接前驱（`node.next = p.next; p.next = node`，顺序不能反）。

**双向链表**

每个节点有 prior 和 next 两个指针，任意节点都能方便访问前驱与后继（常构造为双向循环链表）。代价是每个节点多一个指针的空间。LinkedList 就是双向链表——按索引查找时会从距端点更近的一端遍历。

**对比总结**

|  | 数组 | 单链表 | 双链表 |
| --- | --- | --- | --- |
| 随机访问 | O(1) | O(n) | O(n) |
| 头部插入删除 | O(n) | O(1) | O(1) |
| 已知节点处插入删除 | O(n) | O(1)（单向改一个指针） | O(1)（改两个指针） |
| 空间 | 连续、紧凑 | 可不连续 + 1 指针 | 可不连续 + 2 指针 |
| 回溯 | 可以 | 不可以 | 可以 |

**单链表的基本操作**

获取长度（只能遍历计数）：

```java
public int getLength(Node head) {
    int len = 0;
    while (head != null) {
        len++;
        head = head.next;
    }
    return len;
}
```

按角标取值 / 按值找角标（都要遍历，O(n)）：

```java
/** 获取指定角标的节点值 */
public int getValueOfIndex(Node head, int index) {
    if (index < 0 || index >= getLength(head))
        throw new IndexOutOfBoundsException("角标越界: " + index);
    Node cur = head;
    while (index > 0) {
        cur = cur.next;
        index--;
    }
    return cur.value;
}

/** 获取节点值等于 value 的第一个元素角标，不存在返回 -1 */
public int getNodeIndex(Node head, int value) {
    int index = 0;
    for (Node cur = head; cur != null; cur = cur.next, index++) {
        if (cur.value == value) return index;
    }
    return -1;
}
```

插入分头插法、尾插法、指定位置插入三种：

```java
/** 在 index 位置插入节点（头插法适配 index=0） */
public Node insert(Node head, int index, Node node) {
    if (index == 0) {            // 头插
        node.next = head;
        return node;             // 新头节点
    }
    Node prev = head;
    while (--index > 0)          // 找到前驱
        prev = prev.next;
    node.next = prev.next;       // 先接后继
    prev.next = node;            // 再接前驱（顺序不能反）
    return head;
}
```

经典面试题（快慢指针系列）：

- **链表中点**：快指针走两步、慢指针走一步，快到尾时慢在中点；
- **倒数第 k 个**：两指针相距 k 同速前进，先手到尾时后手即答案；
- **判环**：快慢指针相遇则有环（Floyd 判圈），再从表头与相遇点同速前进，再相遇处即入环点；
- **反转链表**：三指针迭代（prev/cur/next）或递归。

#### 栈和队列

**栈**（LIFO）：压栈 push、弹栈 pop、 peek 看栈顶，都 O(1)。Java 的 Deque 接口（ArrayDeque）是栈的推荐实现（Stack 继承 Vector 已不推荐）；JVM 的方法栈、Android 的回退栈、括号匹配、表达式求值、DFS（显式栈）都是栈结构。

**队列**（FIFO）：offer/poll O(1)。ArrayDeque（循环数组）做普通队列；LinkedList 也实现了 Deque。变体：

- 双端队列 Deque：两端都能进出的通用结构；
- 优先队列 PriorityQueue：小顶堆实现，出队按优先级 O(log n)；
- 阻塞队列 BlockingQueue：生产者-消费者（线程池的工作队列）；
- 单调队列：滑动窗口最大值等题型的利器。

#### 树

**二叉树**：每个节点最多两个子节点。遍历：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS 用队列）。已知前序+中序可重建二叉树。

**二叉搜索树 BST**：左 < 根 < 右，**中序遍历有序**；查找/插入/删除平均 O(log n)，最坏（退化成链）O(n)。

**平衡树**：为避免退化，通过旋转保持平衡：

- **AVL**：严格平衡（左右子树高度差 ≤1），查询快，插入删除旋转成本高；
- **红黑树**：近似平衡（最长路径不超过最短两倍），增删查综合性能好——TreeMap/TreeSet、HashMap 树化（链表 ≥8）、Linux 进程调度都用它。

**堆**：完全二叉树 + 父节点不大于（小顶堆）或不小于（大顶堆）子节点，物理上用数组存储（下标 i 的孩子是 2i+1 / 2i+2）。PriorityQueue 的底层；堆排序、Top-K 问题的标准工具。

**B / B+ 树**：多路平衡搜索树，节点对应磁盘页，扇出大、树矮，减少磁盘 IO——数据库索引（MySQL InnoDB）的基石。B+ 树非叶子节点只存键、数据全在叶子层且叶子间有链表，非常适合范围查询。

**Trie（前缀树）**：按字符分支的树，前缀匹配/词频统计，输入法候选、路由表。

#### 图

**存储**：

- 邻接矩阵：二维数组，查边 O(1)，空间 O(V²)，适合稠密图；
- 邻接表：每个顶点挂边链表，空间 O(V+E)，适合稀疏图。

**遍历**：BFS（队列，可求无权图最短路）、DFS（栈/递归，拓扑排序、判环、连通分量）。

**经典算法**：最短路 Dijkstra（不能有负权）/ Bellman-Ford / Floyd；最小生成树 Prim / Kruskal；拓扑排序（课程表问题）。

#### 散列查找

散列表（哈希表）：键经散列函数映射到数组下标，理想 O(1) 查找。

- **冲突解决**：链地址法（拉链，HashMap 采用）与开放地址法（线性/平方探测）；
- **负载因子** = 元素数 / 桶数，超过阈值扩容（rehash）；
- 好的散列函数要均匀、快速（HashMap 的扰动函数：高 16 位异或低 16 位）。

Java 实现的演进：HashMap（数组+链表，JDK 8 起链表过长树化）、TreeMap（红黑树有序）、LinkedHashMap（双向链表保序，可做 LRU）。详见 [HashMap原理](/QA/HasMap原理.md)。

#### 海量数据处理

核心思想：**分治 + 哈希 + 位图 + 堆**，空间不够就分批：

- **Top-K 高频词**：哈希分片（同一词必然落同一片）→ 每片 HashMap 计数 → 每片小顶堆（大小 K）取前 K → 归并各片结果。或直接维护一个全局大小为 K 的小顶堆流式处理；
- **海量整数判重/统计**：位图 bitmap（一个 int 标记 32 个数）与布隆过滤器（可能误判"存在"、绝不漏判"不存在"）；
- **两个 100GB 文件找交集**：分片哈希（按元素哈希值切成 1000 份），对应分片两两求交集，交集的并即总交集；
- **外排序**：大文件切成内存放得下的块分别排序，多路归并（K 路归并用小顶堆加速）。
