## 2.1 简单的C程序示例

原书第一个程序 `list2_1.c`（first.c）：

```c
#include <stdio.h>             /* 预处理指令,包含标准输入输出头文件 */
int main(void)                 /* main 是程序入口,int 表示返回整数 */
{
    int num;                   /* 声明:定义一个 int 变量 */
    num = 1;                   /* 赋值 */

    printf("I am a simple ");  /* printf 语句 */
    printf("computer.\n");
    printf("My favorite number is %d because it is first.\n", num);

    return 0;                  /* 向操作系统返回 0,表示正常结束 */
}
```

## 2.2 示例解释

逐要素拆解这个程序：

- **`#include` 指令与头文件**：预处理阶段把 `stdio.h`（standard input/output header，标准输入输出头文件）的内容插入源文件，为 `printf` 提供声明
- **`main()` 函数**：C 程序总是从 `main` 开始执行；`int main(void)` 表示不接收参数、返回整数。C99 标准要求 main 必须显式声明返回类型
- **注释**：`/* ... */`，可跨行；C99 起支持 `//` 单行注释
- **花括号、主体与代码块**：函数体用 `{}` 包围
- **声明（declaration）**：`int num;` 向编译器登记变量的名字与类型，为它分配内存。C99 之前变量声明必须位于块顶部，C99 允许声明与语句混排、在 `for` 中声明变量
- **赋值（assignment）**：`num = 1`
- **`printf()` 函数**：格式化输出，`%d` 是占位的转换说明，被 `num` 的值替换；`\n` 表示换行
- **`return` 语句**：返回 0 表示程序正常结束（UNIX 惯例，0 = 成功）

## 2.3 简单程序的结构

一个典型的 C 程序骨架：

```c
#include <stdio.h>

int main(void)
{
    语句序列;
    return 0;
}
```

**语句**（statement）以分号结尾；**块**（block）由一对花括号包裹。函数由函数头（返回类型 + 函数名 + 形参列表）和函数体组成。

## 2.4 提高程序可读性的技巧

- 选择有意义的变量名
- 每条语句独占一行
- 用空行分隔逻辑段落
- 一条语句过长时合理换行（在逗号或运算符后断行）

## 2.5 进一步使用C

原书 `fathm_ft.c`：用两个变量完成单位换算。

```c
#include <stdio.h>
int main(void)
{
    int feet, fathoms;      /* 一条声明语句可同时声明多个变量 */

    fathoms = 2;
    feet = 6 * fathoms;     /* 表达式可以直接参与赋值 */
    printf("There are %d feet in %d fathoms!\n", feet, fathoms);
    return 0;
}
```

也可以在声明的同时初始化：`int fathoms = 2;`。

## 2.6 多个函数

原书 `two_func.c`，演示一个源文件中的两个函数：

```c
#include <stdio.h>

void butler(void);          /* 函数原型(prototype):告知编译器 butler 的存在 */

int main(void)
{
    printf("I will summon the butler function.\n");
    butler();               /* 函数调用 */
    printf("Yes. Bring me some tea and writeable DVDs.\n");
    return 0;
}

void butler(void)           /* 函数定义 */
{
    printf("You rang, sir?\n");
}
```

要点：

- **函数原型**让编译器提前知道函数的返回类型与参数类型，是 ANSI C 的核心改进之一
- `butler()` 的执行时机由 `main` 中的调用位置决定，而非定义位置
- C 标准建议：要使用的函数要么先定义、要么先声明原型

## 2.7 调试程序

程序的错误分两类：

- **语法错误**（syntax error）：违反 C 的语法规则，如漏分号、漏花括号，编译器能直接指出
- **语义错误**（semantic error）：语法正确但意图错误，如 `n * 2` 写成 `n + 2`，编译器不报错，只能靠对比预期输出与实际输出来定位

逐步定位语义错误的常用手段：在关键位置插入 `printf` 打印中间值，或使用调试器（debugger）单步跟踪。

## 2.8 关键字和保留标识符

**关键字**（keyword）是 C 语言保留的词汇，不能用作用户标识符：

| 来源 | 关键字 |
| --- | --- |
| C90（32 个） | `int` `long` `short` `unsigned` `char` `float` `double` `void` `if` `else` `switch` `case` `default` `for` `while` `do` `break` `continue` `goto` `return` `auto` `extern` `static` `register` `const` `volatile` `signed` `enum` `struct` `union` `typedef` `sizeof` |
| C99 新增 | `inline` `restrict` `_Bool` `_Complex` `_Imaginary` |
| C11 新增 | `_Alignas` `_Alignof` `_Atomic` `_Generic` `_Noreturn` `_Static_assert` `_Thread_local` |

**标识符**（identifier）命名规则：由大小写字母、数字、下划线组成，首字符不能是数字；C 大小写敏感。保留标识符还包括以下划线开头的名字和标准库已占用的函数名，自己命名时应避开。

### 小结

- 程序 = 预处理指令 + 若干函数，从 `main` 开始执行
- 声明先于使用；函数原型让“先用后定义”成为可能
- 语法错误靠编译器，语义错误靠测试与调试
- 关键字与保留标识符不可用作变量名
