## 3.1 示例程序

原书 `list3_1.c`（platinum.c），按输入的体重估算等重铂金的价值，引出 `scanf` 读入 `float`：

```c
#include <stdio.h>
int main(void)
{
    float weight;                     /* 用户的体重 */
    float value;                      /* 相等重量的铂金价值 */

    printf("Are you worth your weight in platinum?\n");
    printf("Let's check it out.\n");
    printf("Please enter your weight in pounds: ");

    scanf("%f", &weight);             /* 从标准输入读取一个浮点数,& 取地址 */
    value = 1700.0 * weight * 14.5833;
    printf("Your weight in platinum is worth $%.2f.\n", value);
    return 0;
}
```

`%.2f` 表示保留两位小数输出。

## 3.2 变量与常量数据

- **常量**（constant）：程序运行期间不可变，如字面量 `1700.0`、`'a'`
- **变量**（variable）：程序运行期间可被修改，本质是“类型 + 名字 + 内存位置”

## 3.3 数据：数据类型关键字

C 的基本类型关键字（K&R C 起就有 7 个，C90 加 `signed`/`void`，C99 加 3 个，C11 加 1 个）：

| 关键字 | 含义 |
| --- | --- |
| `int` | 整型，系统给定的基本整数类型 |
| `long` `short` `unsigned` `signed` | 为 int 提供变体（修饰符） |
| `char` | 字符型，也可存小整数 |
| `float` `double` | 浮点型，带小数部分的数 |
| `_Bool` | C99 新增，布尔型（0 或 1） |
| `_Complex` `_Imaginary` | C99 新增，复数与虚数 |
| `_Atomic` | C11 新增，原子类型限定符 |

**位、字节与字**：位（bit）是最小存储单位，取 0/1；字节（byte）是常用的字符存储单位，C 规定 `char` 大小为一个字节；字（word）是设计计算机时规定的自然存储单元。

## 3.4 C语言基本数据类型

### int 类型

`int` 是有符号整型，取值范围依实现而定，常见为 32 位（-2147483648 ~ 2147483647）。ISO C 只保证 int 至少能表示 -32767 ~ 32767。

八进制（`020`）与十六进制（`0x10`）字面量：

```c
int int_decimal = 42;    /* 十进制 */
int int_octal   = 052;   /* 八进制,以 0 开头 */
int int_hex     = 0x2A;  /* 十六进制,以 0x 开头 */
```

打印时 `%d` 十进制、`%o` 八进制、`%#o` 带前导 0、`%x` 十六进制、`%#x` 带前导 0x。

### 其他整数类型

| 类型 | 声明形式 | 打印 |
| --- | --- | --- |
| short int（短整型） | `short` | `%hd` |
| unsigned int（无符号整型） | `unsigned int` | `%u` |
| long（长整型） | `long` | `%ld` |
| unsigned long | `unsigned long` | `%lu` |
| long long（C99） | `long long`，至少 64 位 | `%lld` |
| unsigned long long | `unsigned long long` | `%llu` |

使用 `long` 的理由：需要处理的数可能超过 16 位 `int` 的范围（现代平台上 `int` 多为 32 位，与 `long` 相同大小；需要 64 位时用 `long long`）。

**溢出（overflow）**：整数运算结果超出类型范围时的行为：

- `unsigned` 类型：值“回绕”（wrap around），相当于对最大值 +1 取模
- `signed` 类型溢出：行为未定义（undefined），由实现决定

```c
int i = 2147483647;
printf("%d\n", i + 1);   /* 常见输出 -2147483648,回绕;严格说 signed 溢出未定义 */
unsigned int u = 0;
printf("%u\n", u - 1);   /* 输出 4294967295,无符号回绕是明确定义的 */
```

### char 类型

`char` 本质是小整数，标准 ASCII（American Standard Code for Information Interchange，美国信息交换标准码）范围 0~127。字符常量用单引号：`'A'`（即 65）。

```c
char ch = 'A';              /* 存入的是 65 */
printf("%c\n", ch + 1);     /* 'B':字符与整数可运算 */
printf("%d\n", ch);         /* 65 */
```

`char` 默认是否带符号由实现定义（x86 上常为 signed，ARM 上常为 unsigned），跨平台移植时若作小整数使用，应显式写 `signed char` 或 `unsigned char`。转义序列（如 `'\n'`）见 3.7。

### _Bool 类型

C99 新增，变量只能存 0 或 1，用于表示真/假。配合 `<stdbool.h>` 提供的 `bool` 宏与 `true`/`false`，可写出更可读的代码：

```c
#include <stdbool.h>
bool flag = true;    /* bool 是 _Bool 的宏,true/false 是 1/0 的宏 */
```

### float、double 和 long double

- `float`：单精度，至少能表示 6 位有效数字，典型实现为 32 位（1 符号 + 8 指数 + 23 尾数）
- `double`：双精度，至少 10 位有效数字，典型 64 位
- `long double`：满足更高精度要求，至少与 `double` 同精度

浮点字面量默认类型是 `double`；`float f = 4.0f;` 的 `f` 后缀指明 float。记数法：`-1.56E+12` 表示 $-1.56 \times 10^{12}$。打印用 `%f`（十进制）、`%e`（指数）、`%a`（C99，十六进制浮点）。

`float.h` 中的明示常量：`FLT_MANT_DIG` 尾数位数、`FLT_DIG` 有效数字位数（典型 float 为 6，double 为 15）、`FLT_MIN`/`FLT_MAX` 取值范围。浮点运算存在舍入误差，`0.1` 无法被二进制浮点精确表示：

```c
float a = 0.1f + 0.2f;   /* 结果并不精确等于 0.3f */
```

### 类型大小

`sizeof` 运算符以字节为单位返回类型或变量的大小，类型是 `size_t`，打印用 `%zu`（C99；旧代码用 `%zd`）：

```c
printf("int: %zu bytes\n", sizeof(int));        /* 典型 4 */
printf("char: %zu\n", sizeof(char));            /* 恒为 1 */
printf("double: %zu\n", sizeof(double));        /* 典型 8 */
```

常见 64 位 Linux/gcc 下的典型值：`char` 1、`short` 2、`int` 4、`long` 8、`long long` 8、`float` 4、`double` 8（Windows/MSVC 下 `long` 为 4）。

## 3.5 使用数据类型

经验法则：

- 计数、下标、状态 → `int`（够用且效率高）
- 数值可能超过 16 位 int 的历史场景 → `long`；需要 64 位 → `long long`；不可能为负 → `unsigned`
- 精确的小数运算注意浮点误差；普通浮点计算用 `double`（现代 CPU 上 float 未必更快，且 float 精度低）
- 字符才用 `char`

## 3.6 参数和陷阱

`printf`/`scanf` 的转换说明必须与参数类型严格匹配，编译器（未开警告时）不会替你检查：

```c
int n = 5;
printf("n = %ld\n", n);   /* 错配:读了 8 字节,输出垃圾值 */
scanf("%d", &f);          /* f 是 float 却按 int 解释,出错 */
```

`scanf` 用 `%f` 读 float、`%lf` 读 double；`printf` 打印两者都用 `%f`（float 参数会被自动提升为 double）。

## 3.7 转义序列示例

| 转义序列 | 含义 | 转义序列 | 含义 |
| --- | --- | --- | --- |
| `\a` | 警报（响铃） | `\\` | 反斜杠 `\` |
| `\b` | 退格 | `\'` | 单引号 |
| `\f` | 换页 | `\"` | 双引号 |
| `\n` | 换行 | `\?` | 问号 |
| `\r` | 回车 | `\0oo` | 八进制值，如 `\013` |
| `\t` | 水平制表符 | `\xhh` | 十六进制值，如 `\x1b` |
| `\v` | 垂直制表符 | `\0` | 空字符（null character） |

注意：`\0oo` 与 `\xhh` 是“数字转义序列”，可能嵌入字符串字面量，如 `"Beep!\a"`。

### 小结

- C 的基本类型：整型家族（int 及其变体、char、_Bool）+ 浮点家族（float、double、long double）
- 类型大小因平台而异，用 `sizeof` 查证；unsigned 回绕是定义行为，signed 溢出未定义
- `char` 是小整数、可参与运算，默认符号性由实现定义
- 浮点数有精度限制，`%f` 打印、`scanf` 用 `%lf` 读 double
- 转换说明与参数类型必须匹配，这是初学者最常见的坑
