## 4.1 前导程序

原书 `talkback.c`，综合演示字符串、`strlen`、`sizeof` 与 `#define`：

```c
#include <stdio.h>
#include <string.h>             /* 提供 strlen 的原型 */
#define DENSITY 62.4            /* 人体的密度(磅/立方英尺) */

int main(void)
{
    float weight, volume;
    int size, letters;
    char name[40];              /* char 数组用于存放字符串 */

    printf("Hi! What's your first name?\n");
    scanf("%s", name);
    printf("%s, what's your weight in pounds?\n", name);
    scanf("%f", &weight);
    size = sizeof name;         /* 数组大小:40 字节 */
    letters = strlen(name);     /* 字符串长度:不含空字符 */
    volume = weight / DENSITY;
    printf("Well, %s, your volume is %2.2f cubic feet.\n", name, volume);
    printf("Also, your first name has %d letters,\n", letters);
    printf("and we have %d bytes to store it.\n", size);
    return 0;
}
```

## 4.2 字符串简介

**字符串**（character string）是连续的字符序列，C 用**字符数组**存储，以**空字符**（null character，`'\0'`）标记结尾。字面量用双引号：`"hello"`。

### char 类型数组和 null 字符

数组声明 `char name[40]` 表示 40 个 char 的连续空间。`"hello"` 实际占 6 字节：`h e l l o \0`。

### strlen() 和 sizeof 的区别

- `sizeof`：运算符，给出整个数组占多少**字节**（声明时的大小）
- `strlen()`：函数，给出字符串中**实际字符数**（不含 `\0`）

```c
char name[40] = "hello";
sizeof name;    /* 40 */
strlen(name);   /* 5 */
strlen("hello"); /* 5,"hello" 的存储是 6 字节 */
```

### printf() 和 scanf() 处理字符串

- `printf("%s", name)` 打印到空字符为止
- `scanf("%s", name)` 读入一个**单词**（跳过空白，遇空白结束），name 是数组名本身就代表地址，**不需要 `&`**（见第 9/10 章的指针部分）

## 4.3 常量和C预处理器

### 明示常量：#define

预处理器在编译前做文本替换，`#define` 创建**明示常量**（manifest constant，符号常量）：

```c
#define TAXRATE 0.015          /* 末尾不加分号,值是原样替换的记号串 */
#define CM_PER_INCH 2.54
```

宏名全大写是约定俗成；由于是纯文本替换，带表达式的值应加括号。

### const 修饰符

C90 起，`const` 把变量声明为只读：

```c
const int MONTHS = 12;    /* 运行期只读,类型安全,优于 #define */
```

### 明示常量：limits.h 和 float.h

头文件中定义了各类型的取值边界（limits.h 摘录）：

| 常量 | 含义 | 典型值（32 位 int） |
| --- | --- | --- |
| `CHAR_BIT` | char 的位数 | 8 |
| `INT_MAX` / `INT_MIN` | int 的最大/最小值 | 2147483647 / -2147483648 |
| `SCHAR_MAX` | signed char 最大值 | 127 |
| `UCHAR_MAX` | unsigned char 最大值 | 255 |
| `SHRT_MAX` / `LONG_MAX` / `LLONG_MAX` | 各类型最大值 | 32767 / 见平台 / 至少 63 位 |

float.h：`FLT_MANT_DIG`、`FLT_DIG`（float 有效数字，典型 6）、`DBL_DIG`（典型 15）、`FLT_MAX`、`DBL_MIN` 等。

## 4.4 printf() 和 scanf()

### printf() 函数

请求 printf 打印数据的指令称为**转换说明**（conversion specification）。

**转换说明及其含义**（原书 Table 4.3 摘录）：

| 转换说明 | 输出 |
| --- | --- |
| `%a` / `%A` | 浮点数、十六进制记数（C99/C11） |
| `%c` | 单个字符 |
| `%d` / `%i` | 有符号十进制整数 |
| `%e` / `%E` | 浮点数，e 记数法 |
| `%f` | 浮点数，十进制记数 |
| `%g` / `%G` | 根据值自动选择 %f 或 %e（去掉无意义尾随 0） |
| `%o` | 无符号八进制整数 |
| `%p` | 指针 |
| `%s` | 字符串 |
| `%u` | 无符号十进制整数 |
| `%x` / `%X` | 无符号十六进制整数 |
| `%%` | 百分号本身 |

**转换说明的修饰符**：格式为 `%[标志][宽度][.精度][长度修饰符]转换说明`，常用组合：

- 标志：`-` 左对齐、`+` 显示正负号、`0` 前导零填充、`#` 带前缀（0、0x）或保留小数点
- 数字：最小字段宽度；`.` 后跟数字：精度（字符串为最大字符数，浮点为小数位数）
- 长度修饰符：`%hd` short、`%ld` long、`%lld` long long、`%Lf` long double、`%zu` size_t、`%td` ptrdiff_t

```c
printf("%-10d|\n", 42);     /* 左对齐,宽 10 */
printf("%+d\n", 42);        /* +42 */
printf("%010.3f\n", 3.14);  /* 前导零,宽 10,3 位小数 */
printf("%5.3s\n", "abcdef"); /* 取前 3 个字符,右对齐宽 5:  abc */
```

### 能否混合使用 %d 与 %f

不能。转换说明决定 printf 如何解读后续参数的内存，错配会读出垃圾值；`printf("%ld", i)` 在 32 位 int 平台上可能把相邻参数一起读进来。

### printf() 的返回值

返回打印的字符数；输出出错（如重定向到已关闭的流）时返回负值。

### scanf() 函数

`scanf` 把输入的字符串转换成对应的类型存入变量：

- 参数必须是**地址**（普通变量加 `&`，数组名直接用）
- 若成功转换了 n 项，返回 n；读到文件结尾返回 **EOF**（End Of File，通常定义为 -1）；匹配失败返回 0

**scanf 的转换说明**（原书 Table 4.6 摘录）：

| 转换说明 | 含义 |
| --- | --- |
| `%d` / `%i` | 有符号十进制整数（int） |
| `%u` `%o` `%x` | 无符号整数（十/八/十六进制） |
| `%f` `%e` `%g` `%a` | float（注意：`%lf` 才是 double） |
| `%c` | 字符（含空白字符，默认不跳过） |
| `%s` | 单词（跳过前导空白，遇空白结束，自动补 `\0`） |
| `%hd` `%ld` `%lld` | 对应长度整型；`%lf`/`%Lf` double/long double |

格式串中的普通字符必须精确匹配输入；空白字符匹配任意空白（含零个）。`%c` 前加空格（`" %c"`）可跳过空白再读字符。

### printf 与 scanf 的 * 修饰符

`*` 用于把宽度/精度推迟到参数列表指定：

```c
printf("%*d\n", width, num);    /* 宽度由 width 决定 */
scanf("%*d %d", &n);            /* * 表示跳过一个整数 */
```

## 4.5 关键概念

字符串是带 `\0` 结尾的字符数组；`#define`/`const`/limits.h 提供常量；printf/scanf 的格式说明与参数类型必须匹配；scanf 传地址、printf 传值。

### 小结

- 字符串以 `\0` 结尾；`sizeof` 数组总大小，`strlen` 实际长度
- 常量三种来源：`#define`（编译前文本替换）、`const`（运行期只读）、头文件明示常量
- printf 返回打印字符数；scanf 返回成功读取项数或 EOF——利用返回值可做输入验证
- `%*d`、`%*s` 把格式宽度参数化，适合动态对齐输出
