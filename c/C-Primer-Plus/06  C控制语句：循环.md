## 6.1 再探while循环

while 循环的通用形式：

```c
while (表达式)
    语句        /* 或块 */
```

表达式为真（非零）时重复执行语句，为假（0）时退出。**每次循环前先判断条件，是入口条件（entry condition）循环**；循环体内必须有机会改变条件，否则死循环。

## 6.2 while语句

### 终止while循环

while 的每次迭代都包含两步：①判断测试条件；②条件为真时执行循环体。

### 循环何时终止

条件恒真则永不停：`while (i++ < 3) ...` 依赖 `i` 自增改变条件；构建循环时需要关注的三个要素：**初始化计数器、比较测试、更新计数器**。

### while：入口条件循环

条件为假时循环体一次也不执行。

### 语法要点

```c
while (index++ < 10)
    printf("index = %d\n", index);    /* 只有这一句属于循环体 */
    printf("done\n");                 /* 缩进不决定归属,分号才决定 */
```

## 6.3 用关系运算符和表达式比较大小

**关系运算符**（relational operator）：`<` `<=` `>` `>=` `==` `!=`。关系表达式的值是 1（真）或 0（假）。

| 运算符 | 含义 |
| --- | --- |
| `<` | 小于 |
| `<=` | 小于或等于 |
| `==` | 等于（两个等号） |
| `>=` | 大于或等于 |
| `>` | 大于 |
| `!=` | 不等于 |

关系运算符优先级低于算术运算符、高于赋值运算符；`==`/`!=` 低于其他四个关系运算符。

### 什么是真

C 对“真”的定义非常宽松：**非零即为真，零即假**。`while (n)` 等价于 `while (n != 0)`。

### 真值问题

`=` 与 `==` 混用是经典 bug：

```c
/* 原意是比较,误写成赋值 */
int i = 5;
while (i = 3)     /* i 被赋值为 3,非零恒真,死循环 */
    ...
```

好在现代编译器（gcc `-Wall`）会对该用法给出警告。

### _Bool 类型

C99 的 `_Bool` 只存 0/1，配合 `<stdbool.h>` 使用 `bool`、`true`、`false`：

```c
#include <stdbool.h>
bool is_open = true;
```

### 优先级与关系运算符

`x > y + 2` 等价于 `x > (y + 2)`；`x = y > 3` 是把 `y > 3` 的 0/1 赋给 x。

### 不确定循环和计数循环

见 6.4。

## 6.4 不确定循环和计数循环

- **不确定循环**（indefinite loop）：循环次数事先未知，如“读到输入结束”
- **计数循环**（counting loop）：循环次数已知，三要素：初始化、条件、更新

## 6.5 for循环

for 把计数循环三要素集中到一行，是 C 最灵活的循环：

```c
for (initialize; test; update)
    statement

/* 等价的 while 形式 */
initialize;
while (test) {
    statement
    update;
}
```

for 循环的三个表达式都可省略（分号必须保留）：`for (;;) ...` 表示条件恒真。C99 允许在初始化部分声明变量（仅循环内可见）：`for (int i = 0; i < n; i++)`。

## 6.6 其他赋值运算符：+=、-=、*=、/=、%=

复合赋值（combined assignment）运算符：

```c
x *= 3;        /* x = x * 3 */
x += y + z;    /* x = x + (y + z),右侧整体先求值 */
x /= 2 * y;    /* x = x / (2 * y) */
```

还有位运算版本的 `&=`、`|=`、`^=`、`<<=`、`>>=`。

## 6.7 逗号运算符

**逗号运算符**（comma operator）把两个表达式合并为一个，保证**从左往右**求值，整个表达式的值是右边的值：

```c
x = (y = 3, (z = ++y + 2) + 5);   /* y=3, z=6, x=11 */
```

- 逗号是序列点（sequence point）：左侧的副作用在右侧求值前完成
- for 头部常见：`for (secs = 5, count = 1; secs > 0; secs--, count++)`
- 逗号运算符优先级最低，低于赋值；注意与函数参数列表中“分隔用的逗号”区分

## 6.8 出口条件循环：do while

**do while** 先执行循环体、后判断条件，**至少执行一次**，是出口条件（exit condition）循环：

```c
do
    statement
while (condition);    /* 注意结尾的分号 */
```

适合“先做事再检查”的场景，如菜单交互。

## 6.9 如何选择循环

- 已知循环次数、或需要紧凑的计数控制 → `for`
- 至少执行一次 → `do while`
- 其余入口条件场景 → `while`

## 6.10 嵌套循环

循环体内包含另一个循环。原书 `rows1.c` 打印字符矩形：

```c
for (int row = 0; row < 6; row++)          /* 外层:行 */
{
    for (char ch = 'F'; ch >= 'A'; ch--)   /* 内层:每行的字符 */
        printf("%c", ch);
    printf("\n");
}
```

内层循环完整执行一遍，外层才前进一步；嵌套层次不限。经典应用：乘法表、二维遍历、冒泡排序。

## 6.11 数组简介

**数组**（array）是同类型元素的连续序列：

```c
float debts[20];        /* 20 个 float,下标 0~19 */
debts[5] = 32.54;
printf("%f\n", debts[5]);
```

- 下标（index）从 0 开始，有效范围 0 ~ 元素个数-1；C **不检查越界**（编译器不管，行为未定义，可能恰好写坏相邻内存）
- 数组可按元素初始化：`int powers[8] = {1, 2, 4, 6, 8, 16, 32, 64};`，初始化列表比数组短时剩余元素为 0，`int a[5] = {0};` 全零；C99 起可用指定初始化器：`int a[8] = {[5] = 212};`
- 数组与 for 是天然搭档：

```c
const int days[MONTHS] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
for (int index = 0; index < MONTHS; index++)
    printf("Month %2d has %d days.\n", index + 1, days[index]);
```

- `sizeof days / sizeof days[0]` 可算出元素个数
- 求模运算配合数组可实现循环取值：`days[(i++) % 7]`

## 6.12 使用函数返回值的循环示例

原书 `power.c`：用带返回值的函数配合循环计算幂，函数返回值可直接作为表达式的操作数：

```c
double power(double base, int exp)   /* 返回 base 的 exp 次幂 */
{
    double result = 1.0;
    for (int i = 0; i < exp; i++)
        result *= base;
    return result;
}

/* 循环中直接使用返回值 */
while (scanf("%lf %d", &base, &exp) == 2)
    printf("%.2f\n", power(base, exp));
```

### 小结

- while/for 是入口条件循环，do while 是出口条件循环（至少执行一次）
- 真值规则：非零为真；小心 `=` 误作 `==`
- for 集中管理计数三要素，最常用；逗号运算符常用于 for 头部
- 数组下标从 0 起、不查越界；`sizeof a / sizeof a[0]` 求元素个数
- C99 的 `for (int i = 0; ...)` 把循环变量限制在循环作用域内
