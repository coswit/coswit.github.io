## 7.1 if语句

if 的通用形式：

```c
if (expression)
    statement
```

expression 为真（非零）时执行 statement。C89 之前的惯例是与宏比较：

```c
if (score > 89)
    grade = 'A';
```

对返回值做判断同样是 if 的典型用法：

```c
if (scanf("%d", &n) != 1)    /* 读取失败 */
    printf("Invalid input.\n");
```

### 示例程序

原书 `colddays.c`：统计 0℃ 以下的天数占比。

```c
#include <stdio.h>
int main(void)
{
    const int FREEZING = 0;
    float temperature;
    int cold_days = 0;
    int all_days = 0;

    printf("Enter the list of daily low temperatures.\n");
    printf("Use Celsius, and enter q to quit.\n");
    while (scanf("%f", &temperature) == 1)
    {
        all_days++;
        if (temperature < FREEZING)
            cold_days++;
    }
    if (all_days != 0)
        printf("%d days total: %.1f%% were below freezing.\n",
               all_days, 100.0 * (float) cold_days / all_days);
    if (all_days == 0)
        printf("No data entered!\n");
    return 0;
}
```

`while (scanf(...) == 1)` 利用了 scanf 的返回值控制循环，是贯穿全书的惯用法。

## 7.2 if else语句

```c
if (expression)
    statement1
else
    statement2
```

### 简单的示例

原书 `electric.c`（阶梯电价）：条件成立走一个分支，不成立走另一个。

### 字符输入函数 ctype.h 系列

`<ctype.h>` 提供一系列字符分类/转换函数，配合分支逻辑处理字符：

```c
ch = tolower(ch);   /* 转小写 */
if (isdigit(ch))    /* 是数字 */
if (isalpha(ch))    /* 是字母 */
if (isspace(ch))    /* 是空白 */
```

### 多层嵌套的 if else

`else` 总是与它最近未配对的 `if` 配对，必要时用花括号明确：

```c
if (score >= 90)
    grade = 'A';
else if (score >= 80)      /* 实为 else { if ... } 的扁平写法 */
    grade = 'B';
else if (score >= 70)
    grade = 'C';
else
    grade = 'F';
```

### else 与 if 的配对

```c
/* 缩进骗人,编译器不看缩进 */
if (x > 0)
    if (y > 0)
        printf("both positive\n");
else                        /* 实际配对内层 if! */
    printf("x <= 0\n");
```

加花括号可消除歧义。

## 7.3 逻辑运算符

| 运算符 | 含义 | 备选拼写（iso646.h） |
| --- | --- | --- |
| `&&` | 与（and） | `and` |
| `\|\|` | 或（or） | `or` |
| `!` | 非（not） | `not` |

```c
if (ch >= 'a' && ch <= 'z')      /* 小写字母 */
if (n != 0 && sum / n > 5)       /* 先保证 n 非零,再除 */
```

- 逻辑表达式的值是 0 或 1；`!` 的优先级高于 `&&`，`&&` 高于 `||`
- `&&` 与 `||` 是**序列点**，且保证**短路求值**（short-circuit evaluation）：左侧已能决定结果时右侧不再求值。上例中 `n != 0` 失败时 `sum / n` 不会被计算，从而避免除零

### 备选拼写

`<iso646.h>`（C95 修正案引入）为部分运算符提供英文单词形式：`and`、`or`、`not`、`bitand`（`&`）、`bitor`（`|`）等，方便键盘敲不出某些符号的环境。

### 范围比较

数学写法 `3 <= x <= 7` 在 C 中是错误的（`(3 <= x) <= 7` 恒真），应写成 `x >= 3 && x <= 7`。

## 7.4 一个统计单词的程序

原书 `wordcnt.c`：用逻辑运算符统计行数、单词数、字符数。核心思路——读入字符，用 `c != '\n' && c != ' '` 这类组合条件判断单词边界：

```c
bool inword = false;      /* 当前是否在单词内 */
while ((c = getchar()) != EOF)
{
    characters++;         /* 统计字符 */
    if (c == '\n')
        lines++;
    if (!isspace(c) && !inword) {
        inword = true;    /* 进入新单词 */
        words++;
    }
    if (isspace(c) && inword)
        inword = false;   /* 离开单词 */
}
```

## 7.5 条件运算符：?:

C 唯一的**三元运算符**（ternary operator）：

```c
max = (a > b) ? a : b;    /* 条件为真取 a,否则取 b */
```

等价的 if-else：

```c
if (a > b)
    max = a;
else
    max = b;
```

## 7.6 循环辅助：continue和break

### continue语句

跳过本次迭代剩余部分，直接进入下一轮条件判断（for 循环是先执行 update 再判断）：

```c
for (int i = 0; i < 100; i++) {
    if (i % 2 == 0)
        continue;          /* 跳过偶数 */
    printf("%d\n", i);
}
```

### break语句

**终止**所在循环，继续执行循环之后的语句；只跳出**最内层**：

```c
while (scanf("%f", &x) == 1) {
    if (x < 0)
        break;             /* 负数立即退出循环 */
    sum += x;
}
```

## 7.7 多重选择：switch和break

switch 根据整型表达式的值跳转到匹配的标签：

```c
switch (ch)
{
case 'a':
case 'A': printf("argh\n");
          break;
case 'e':
case 'E': printf("eh?\n");
          break;
default:  printf("unknown\n");
          break;
}
```

要点：

- 控制表达式须是整型（含 char）；`case` 标签须是整型常量表达式
- **没有 break 就会“贯穿”（fall through）到下一个 case**——利用贯穿可合并大小写（上例），失误时则是 bug
- `default` 处理所有未匹配情况，建议总是写上
- switch 只能做相等判断，范围判断仍需 if-else

## 7.8 goto语句

```c
top: ch = getchar();      /* 标签 */
...
goto top;                 /* 跳回标签处 */
```

C 完全保留 goto，但**结构化编程几乎不需要它**：break/continue/return 与函数分解能覆盖绝大多数场景。经典合法用法之一是从深层嵌套循环中一次性跳出（多层 break 做不到）：

```c
for (...) {
    while (...) {
        for (...) {
            if (error)
                goto bailout;    /* 一次跳出三层 */
        }
    }
}
bailout: cleanup();
```

除这类场景外应避免使用。

### 小结

- if/else 依真值分支；else 与最近未配对的 if 结合，用花括号消除歧义
- `&&`/`||` 短路求值，是安全组合条件的基石；范围判断必须拆成两个关系式
- continue 跳过本轮，break 跳出本层循环
- switch 适合整型多分支，勿忘 break 与 default
- goto 仅保留给“多层循环一次性跳出”这类罕见场景
