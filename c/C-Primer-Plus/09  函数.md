## 9.1 复习函数

**函数**（function）是完成特定任务的独立代码单元，是结构化编程的基石：把大问题分解成小任务、避免重复代码、隐藏实现细节。

```c
#include <stdio.h>
int imin(int, int);            /* 函数原型 */

int main(void)
{
    printf("The lesser of %d and %d is %d.\n", 3, 5, imin(3, 5));
    return 0;
}

int imin(int n, int m)         /* 函数定义 */
{
    return (n < m) ? n : m;    /* 返回值直接交给调用方 */
}
```

函数使用三要素：**原型（声明）、调用、定义**。return 也可不带值（void 函数）用于提前返回：`if (x < 0) return;`。

## 9.2 ANSI C函数原型

原型（prototype）说明函数的返回类型与参数类型，让编译器在调用点做**类型检查与实参转换**：

```c
int imax(int, int);            /* 只写类型即可 */
int imax(int a, int b);        /* 带形参名,更可读,推荐 */
```

- 省略原型的旧式调用，实参不做检查、默认提升后直接传，极易出错；C99 已把“先用后声明”列为不合规
- 原型可写在文件顶部或头文件中；定义本身若出现在调用之前，也起到原型作用

## 9.3 递归

**递归**（recursion）：函数调用自身。C 允许递归，每层调用都有独立的变量副本（占用栈空间）。

原书 `recur.c`（up_and_down）：

```c
void up_and_down(int n)
{
    printf("Level %d: n location %p\n", n, &n);   /* 1 */
    if (n < 4)
        up_and_down(n + 1);
    printf("LEVEL %d: n location %p\n", n, &n);   /* 2 */
}
/* 输出:语句1按 1→4 顺序执行,语句2按 4→1 逆序执行 */
```

调用链：`up_and_down(1)` 调用 `(2)`…`(4)`，最深一层返回后，各层才依次执行语句 2——**递归的“下降”与“回升”是两条路径**。

### 递归的基本原理

1. 每级调用有自己的变量
2. 每级调用都会执行一次函数体；递归调用“下面”的代码要等递归返回后才执行
3. 位于递归调用之前的语句按调用顺序执行，之后的语句按返回（逆）顺序执行
4. 递归函数必须有**终止条件**，否则无限展开耗尽栈

### 尾递归

**尾递归**（tail recursion）：递归调用是函数的最后一个动作、其返回值直接返回。尾递归最容易被改写为循环，效率更高（避免函数调用开销与栈增长）：

```c
/* 递归版:计算 n 的阶乘 */
long fact(int n)
{
    if (n > 0)
        return n * fact(n - 1);
    else
        return 1;
}

/* 循环版:等价且更高效 */
long fact_r(int n)
{
    long ans;
    for (ans = 1; n > 1; n--)
        ans *= n;
    return ans;
}
```

### 递归的优缺点

- 优点：思路契合问题结构（树、分形、汉诺塔、快排），代码简洁
- 缺点：函数调用开销大、栈空间消耗随深度增长，深度过大导致栈溢出

## 9.4 编译多源代码文件的程序

多文件程序的编译（命令行）：

```bash
gcc file1.c file2.c -o program      # 一次性编译链接
gcc -c file1.c file2.c              # 只编译成 .o,便于增量构建
gcc file1.o file2.o -o program      # 再链接
```

UNIX 习惯用 **make** 管理多文件构建：makefile 声明文件依赖关系，只重编改动的文件，大幅减少大型项目的构建时间。头文件（`.h`）通常存放函数原型与共享声明，`#include` 供各源文件引用。

## 9.5 查找地址：&运算符

一元 `&` 运算符给出变量的**地址**（内存中的位置）：

```c
int pooh = 24;
printf("%p\n", &pooh);    /* 打印地址,如 0x7fff5fbff8ac */
```

C 的普通函数调用是**传值调用**（call by value）：实参的值被拷贝给形参，函数内改形参不影响调用方的变量。

## 9.6 更改主调函数中的变量

要在函数中修改主调函数的变量，必须把**变量的地址**传进去：

```c
void interchange(int * u, int * v)    /* 形参是指针 */
{
    int temp;
    temp = *u;      /* * 解引用:取指针指向的值 */
    *u = *v;
    *v = temp;
}

int x = 5, y = 10;
interchange(&x, &y);    /* 传地址,交换后 x=10, y=5 */
```

指针版本的“传值”传的是**地址值**——形参 `u` 是地址的拷贝，但拷贝的地址仍指向原变量，所以 `*u = ...` 能改到原变量。

## 9.7 指针简介

**指针**（pointer）是存放地址的变量。

### 指针的声明

```c
int * pi;         /* pi 是 pointer to int */
char * pc;
float * pf, * pg; /* 每个指针变量都要带 * */
```

`int * pi;` 读作：“pi 指向的（*pi 的类型）是 int”。`*` 在声明中是指针说明符，在表达式中是解引用运算符，二者不同。

### 使用指针在函数间通信

```c
*pi = 5;          /* 解引用赋值:把 5 写入 pi 指向的对象 */
n = *pi;          /* 读取 pi 指向的对象 */
```

指针四大用途（贯穿后续章节）：

1. 让函数修改主调方的变量（本章 swap）
2. 数组名即指针，高效遍历数组
3. 字符串操作
4. 结构、链表等自定义数据结构

### 小结

- 函数三件套：原型、调用、定义；原型让编译器检查参数
- 递归有下降与回升两条路径，必须有终止条件；尾递归可改写为循环
- `&` 取地址、`*` 解引用；传值调用无法改主调方变量，传地址才可以
- 多文件程序用头文件共享原型，用 make 管理增量构建
