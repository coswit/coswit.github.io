## 10.1 数组

**数组**（array）由同类型元素连续排列而成，通过下标访问：

```c
int days[MONTHS] = {31,28,31,30,31,30,31,31,30,31,30,31};
float rain[YEARS][MONTHS];            /* 二维数组,见 10.2 */
```

### 初始化

```c
int powers[8] = {1,2,4,6,8,16,32,64}; /* 完整初始化 */
int stuff[8] = {1, 2};                /* 其余元素为 0 */
int stuff2[] = {1, 2, 3};             /* 省略长度时,长度由编译器数出来:3 */
```

C99 **指定初始化器**（designated initializer）：

```c
int arr[6] = {[5] = 212};             /* 只初始化下标 5,其余为 0 */
int days[12] = {31, 28, [4] = 31, 30, [1] = 29};  /* 可交错;重复指定以后者为准 */
```

### 赋值与数组边界

- 数组不能整体赋值：`arr2 = arr;` 非法，只能逐元素（或用 memcpy 整块拷贝）
- C **不检查下标越界**：`arr[6]`、`arr[-1]` 编译通过但行为未定义
- `sizeof arr / sizeof arr[0]` 求元素个数

## 10.2 多维数组

```c
float rain[5][12];    /* 5 年 × 12 月的降雨量:5 个"含 12 个 float 的数组" */
```

初始化按行分组：

```c
float rain[YEARS][MONTHS] =
{
    {4.3,4.3,4.3,3.0,2.0,1.2,0.2,0.2,0.4,2.4,3.5,6.6},
    {8.5,8.2,1.2,1.6,2.4,0.0,5.2,0.9,0.3,0.9,1.4,7.3},
    /* ... */
};
```

理解二维数组的关键：`rain[0]` 是第 0 行（本身是个含 12 个 float 的数组），`rain[0][3]` 才是元素。内存上仍是按行连续的 60 个 float。

## 10.3 指针和数组

数组名在表达式中被当作**指向首元素的指针**：

```c
int dates[5] = {10,20,30,40,50};
dates == &dates[0];          /* true */
*dates == 10;                /* 解引用首元素 */
*(dates + 2) == dates[2];    /* true:指针加法按元素大小步进 */
```

`dates + 2` 不是地址加 2 个字节，而是加 2 个 int 的大小——**指针算术以所指类型为单位**。

`*` 与 `++` 的组合是遍历的经典写法：

```c
*dates++;     /* 后缀++优先级高:取 *dates,再 dates++ */
*(dates++);   /* 同上,显式写法 */
*(++dates);   /* 先 ++,再取新指向的元素 */
(*dates)++;   /* 取 *dates,再把元素的值 +1 */
```

## 10.4 函数、数组和指针

数组作为函数参数时，传递的是**首元素地址**（数组退化为指针），所以三种形参写法等价：

```c
int sum(int *ar, int n);       /* 指针 + 元素个数 */
int sum(int ar[], int n);      /* 数组记法,含义相同 */
int sum(int ar[N], int n);     /* N 会被忽略,仍是指针 */
```

```c
int sum(int *ar, int n)
{
    int total = 0;
    for (int i = 0; i < n; i++)
        total += ar[i];        /* 等价于 *(ar + i) */
    return total;
}
```

由于只传地址，函数内**并不知道数组长度**，必须额外传元素个数（或用哨兵值，如字符串的 `\0`）。

另一风格——用两个指针圈定范围：

```c
int sump(int * start, int * end)   /* [start, end) 区间求和 */
{
    int total = 0;
    while (start < end)
        total += *start++;
    return total;
}
/* 调用:answer = sump(ar, ar + SIZE); */
```

## 10.5 指针操作

指针支持的合法操作：

| 操作 | 说明 |
| --- | --- |
| 赋值 | 把地址赋给指针（同类型指针、数组名、&变量、NULL） |
| 解引用 | `*p` 访问指向的对象 |
| 取下标 | `p[i]`，即使 p 不是数组名也成立 |
| 加/减整数 | 按元素大小平移：`p + 1` |
| 指针递增/递减 | `p++` 移动到下一个元素 |
| 指针求差 | 同数组内两指针相减，得元素间隔（ptrdiff_t） |
| 比较 | 同数组内的指针可比较大小 |

**非法/危险**：解引用未初始化的指针、对两个不相关数组的指针求差、越界后解引用。

```c
double * pd;
double arr[5] = {100, 200, 300, 400, 500};
pd = arr;          /* 指向 100 */
*pd = 99;          /* arr[0] 变 99 */
pd++;              /* 指向 200 */
```

## 10.6 保护数组中的数据

传地址意味着函数能改动原数组。若函数只读，用 **const** 保护：

```c
int sum(const int * ar, int n);   /* 承诺不通过 ar 修改数组 */
```

### const 与指针的组合

```c
const int * p;         /* 指向 const 的指针:不能通过 *p 改值,p 本身可改指向 */
int * const p = &x;    /* const 指针:p 不能改指向,可通过 *p 改值 */
const int * const p;   /* 都不能改 */
```

记忆法：**const 在 * 左边修饰“被指向的数据”，在 * 右边修饰“指针本身”**。

```c
int arr[5] = {1,2,3,4,5};
const int * pc = arr;   /* pc[0] += 1 非法;pc++ 合法 */
int * const pc2 = arr;  /* pc2++ 非法;pc2[0] += 1 合法 */
```

## 10.7 指针和多维数组

```c
int zippo[4][2];      /* 4 行 2 列 */
```

- `zippo` ↔ `&zippo[0]`：指向“含 2 个 int 的数组”
- `zippo[0]` ↔ `&zippo[0][0]`：指向第 0 行首元素（int）
- `zippo + 1`：跨过整行（2 个 int）
- `zippo[0] + 1`：跨过 1 个 int

**指向数组的指针**（注意括号，不可省）：

```c
int (* pz)[2];        /* pz 是指针,指向含 2 个 int 的数组 */
pz = zippo;           /* 类型匹配 */
pz[1][1] = 3;         /* 用法同 zippo */

int * pax[2];         /* 对照:pax 是数组,含 2 个"指向 int 的指针" */
```

`int (*pz)[2]` 与 `int *pax[2]` 的区别是笔试高频：`[]` 优先级高于 `*`，加括号让 pz 先与 `*` 结合成为指针。

声明指向二维数组的函数形参：

```c
void sum_rows(int ar[][12], int rows);      /* 首维度可省 */
void sum_cols(int (*ar)[12], int rows);     /* 等价写法 */
/* 变长数组版本见 10.8 */
```

## 10.8 变长数组（VLA）

C99 引入**变长数组**（Variable Length Array, VLA）：维度用运行期变量表达：

```c
int quarters = 4, regions = 5;
double sales[regions][quarters];        /* C99 VLA,长度运行期确定 */

/* 配套的函数声明:维度参数在前 */
double sum2d(int rows, int cols, int ar[rows][cols]);
```

VLA 的“变”指**编译时维度尚未确定**，数组一经创建大小固定、不可动态伸缩。注意：

- VLA 在栈上分配，巨大的 VLA 会栈溢出
- 时效性注解：C11 把 VLA 降级为**可选特性**（`__STDC_NO_VLA__` 为 1 时不可用），gcc/clang 默认支持，MSVC 不支持。生产代码建议谨慎使用

## 10.9 复合字面量

C99 **复合字面量**（compound literal）：匿名数组/结构字面量，可出现在表达式里：

```c
(int [2]) {10, 20}                    /* 一个匿名的含 2 个 int 的数组 */
int * pt = (int [2]) {10, 20};
int total = sum((int []){1,2,3,4}, 4);           /* 直接传给函数 */
sum2d(2, 3, (int [2][3]){{1,2,3},{4,5,6}});      /* 二维 */
```

字面量的类型是“去掉初始化器后剩什么就是什么”；作用于函数实参非常方便，省去先定义临时数组的步骤。

### 小结

- 数组名 = 首元素地址；`*(ar + i)` ≡ `ar[i]`，指针算术按元素大小步进
- 数组传参退化为指针，长度必须另行传递；只读接口用 const 形参
- `int (*p)[2]` 是指向数组的指针，`int *p[2]` 是指针数组——括号决定结合方向
- const 与 `*` 的位置决定保护的是数据还是指针本身
- C99 的指定初始化器、VLA、复合字面量是三个高频现代特性；VLA 在 C11 中为可选
