## 11.1 表示字符串和字符串I/O

字符串的两种表示：

```c
char arr[] = "hello";        /* 字符数组:内容可修改 */
const char * ptr = "hello";  /* 指针:指向字符串字面量(静态存储,不可修改) */
```

字符串字面量（string literal）在静态存储区，程序只读它一次；数组形式会把副本拷贝进数组。

### 字符串数组

存放多个字符串的两种方式：

```c
const char * arr1[5] = {"abc", "def", "ghi", "jkl", "mno"};  /* 指针数组 */
char arr2[5][10] = {"abc", "def", ...};                       /* 二维 char 数组 */
```

- 指针数组：各串长度可以不同，内存紧凑，但串本身不可改（指向字面量时）
- 二维数组：每行等长，浪费空间但每行可修改

## 11.2 字符串输入

### gets()函数（已被废除）

```c
char words[20];
gets(words);    /* 读一行,不检查目标大小 */
```

gets 无法限制读入长度，缓冲区溢出风险极大，**C11 标准已将其废除**。现役代码必须避免，编译器会给出警告。

### fgets()函数（和fputs()）

`fgets` 面向文件，也可用标准输入；第二个参数限制最大读入字符数（含 `\0`），**保留换行符**：

```c
char words[14];
fgets(words, 14, stdin);    /* 最多读 13 个字符 + '\0' */
```

- 读到换行符会一并存入（与 gets 不同）
- 需要去掉行尾 `\n` 时手动处理：

```c
char * find = strchr(words, '\n');
if (find)
    *find = '\0';
```

`fputs(words, stdout)` 对应输出，**不自动加换行**（与 puts 配对关系相反）。

### gets_s()函数（C11 可选）

```c
gets_s(words, 14);    /* 只能用于标准输入;丢弃换行;超长直接失败 */
```

C11 附录 K 的可选函数，目标太小/读到文件尾会调用“约束处理函数”终止程序；MSVC 支持较好，GNU C 库未实现，可移植性差。

### scanf()函数

`scanf("%s", ...)` 读取**一个单词**，遇到空白即止（不读空白，自动补 `\0`）：

```c
scanf("%10s", name);    /* 宽度限制 10,防止溢出 */
```

返回值是成功读取的项数，可与循环配合。取舍：gets 系读整行、scanf 读单词。

## 11.3 字符串输出

| 函数 | 换行 | 说明 |
| --- | --- | --- |
| `puts(s)` | 自动加 `\n` | 遇 `\0` 停止；参数须是有效字符串 |
| `fputs(s, stdout)` | 不加 | puts 的文件版 |
| `printf("%s", s)` | 不加 | 最灵活，可格式化 |

空指针传给 %s 是未定义行为，printf 可先判空：`printf("%s", s ? s : "(null)")`。

## 11.4 自定义输入/输出函数

把 getchar 封装成“读一整行并截断”的自定义函数（原书 s_gets 思路）：

```c
char * s_gets(char * st, int n)
{
    char * ret_val;
    int i = 0;

    ret_val = fgets(st, n, stdin);
    if (ret_val)                                 /* 读到了内容 */
    {
        while (st[i] != '\n' && st[i] != '\0')
            i++;
        if (st[i] == '\n')
            st[i] = '\0';                        /* 把换行替换为空字符 */
        else
            while (getchar() != '\n')            /* 行太长,丢弃剩余部分 */
                continue;
    }
    return ret_val;
}
```

返回 NULL 表示读到文件尾，返回 st 表示成功——调用方据此判断。

## 11.5 字符串函数

`<string.h>` 核心函数（原书 Table 11.3 摘录）：

| 函数 | 原型 | 作用 |
| --- | --- | --- |
| `strlen(s)` | `size_t strlen(const char *s)` | 字符串长度（不含 `\0`） |
| `strcat(s1, s2)` | `char *strcat(char *restrict s1, const char *restrict s2)` | 把 s2 追加到 s1 末尾 |
| `strncat(s1, s2, n)` | 同上带 n | 追加最多 n 个字符，防溢出 |
| `strcmp(s1, s2)` | `int strcmp(const char *s1, const char *s2)` | 按机器排序序列比较 |
| `strncmp(s1, s2, n)` | 同上带 n | 只比较前 n 个字符 |
| `strcpy(s1, s2)` | `char *strcpy(char *restrict s1, const char *restrict s2)` | 把 s2 拷贝到 s1 |
| `strncpy(s1, s2, n)` | 同上带 n | 拷贝最多 n 个字符 |
| `sprintf(s, fmt, ...)` | stdio.h | 格式化写入字符串 |
| `strchr(s, c)` | `char *strchr(const char *s, int c)` | 在 s 中找字符 c，返回指针或 NULL |
| `strrchr(s, c)` | 同上 | 从右往左找 |
| `strstr(s1, s2)` | `char *strstr(const char *s1, const char *s2)` | 找子串 |

要点与陷阱：

- **strcmp 的返回值**：标准只规定负/0/正（依字符比较结果），不能依赖 -1/1；判等用 `strcmp(a,b) == 0`
- **strcpy 第一个参数是目标**：`strcpy(copy, orig)`；目标必须有足够空间——数组整体赋值 `copy = orig` 非法，必须用 strcpy
- **strncpy 不保证补 `\0`**：`strncpy(dest, src, n)` 当 src 长度 ≥ n 时截断后无空字符，稳妥写法：

```c
strncpy(dest, src, SIZE - 1);
dest[SIZE - 1] = '\0';
```

- **sprintf** 常用于拼装字符串：

```c
char formal[30];
sprintf(formal, "%s, %-19s: $%6.2f\n", last, first, prize);
```

## 11.6 字符串示例：字符串排序

指针数组 + strcmp 实现字典序排序（原书 str_sort 思路）：

```c
void stsrt(char *strings[], int num)     /* 选择排序:把最小的换到前面 */
{
    char *temp;
    for (int top = 0; top < num - 1; top++)
        for (int seek = top + 1; seek < num; seek++)
            if (strcmp(strings[top], strings[seek]) > 0)
            {
                temp = strings[top];             /* 只交换指针,不搬字符串 */
                strings[top] = strings[seek];
                strings[seek] = temp;
            }
}
```

排序交换的是**指针**，字符串本体不动——比搬动整串高效得多。

## 11.7 ctype.h字符函数和字符串

`<ctype.h>` 常用函数：

| 函数 | 为真当字符是 | 函数 | 为真当字符是 |
| --- | --- | --- | --- |
| `isalnum()` | 字母或数字 | `ispunct()` | 标点符号 |
| `isalpha()` | 字母 | `isspace()` | 空白 |
| `isblank()` | 标准空白（C99） | `isupper()` | 大写字母 |
| `iscntrl()` | 控制字符 | `isxdigit()` | 十六进制数字 |
| `isdigit()` | 数字 | `tolower()` | 转小写（返回值） |
| `islower()` | 小写字母 | `toupper()` | 转大写（返回值） |

典型用法——统计字符串中指定类别字符、大小写无关比较：逐字符 `tolower` 后再 strcmp。

## 11.8 命令行参数

main 可以接收命令行参数：

```c
int main(int argc, char *argv[])
{
    if (argc < 2) {
        printf("Usage: %s word\n", argv[0]);
        return 1;
    }
    printf("Hello, %s\n", argv[1]);
    return 0;
}
```

```bash
$ ./greet world
Hello, world
```

- **argc**（argument count）：命令行记号数，含程序名本身，最小为 1
- **argv**（argument values）：指向各记号字符串的指针数组；`argv[0]` 通常是程序名，`argv[argc-1]` 是最后一个参数，`argv[argc]` 是空指针
- UNIX shell 展开通配符，Windows CMD 不展开
- 形参名任意，惯例 argc/argv；等价声明：`int main(int argc, char **argv)`

## 11.9 把字符串转换为数字

`atoi`/`atof` 简单但无法报告失败（失败返回 0，与合法输入 "0" 无法区分）；更健壮的是 `strtol`（stdlib.h）：

```c
long strtol(const char * restrict nptr, char ** restrict endptr, int base);
```

```c
char * end;
long val = strtol(line, &end, 10);       /* 按 10 进制转换 */
if (end == line)
    fprintf(stderr, "not a number: %s\n", line);
else if (*end != '\0')
    fprintf(stderr, "trailing junk: %s\n", end);
```

- `endptr` 指向“第一个未转换字符”，据此判断整体是否合法
- `base` 支持 2~36 进制（如 16 进制解析 "0x1A"）
- 同族：`strtoul`（unsigned long）、`strtod`（double）

### 小结

- 字符串 = 以 `\0` 结尾的 char 数组；数组形式可改、指针指向字面量不可改
- **永远不要用 gets**；fgets + 手动去 `\n` 是安全读行的标准做法；scanf 加宽度防溢出
- strcpy/strcat 家族操作的是调用方提供的内存，长度责任在程序员；n 版本（strncpy/strncat）更安全但各有边角（截断无 `\0`）
- 排序字符串应交换指针而非搬数据
- argc/argv 是程序与命令行的接口；数字转换优先 strtol 而非 atoi
