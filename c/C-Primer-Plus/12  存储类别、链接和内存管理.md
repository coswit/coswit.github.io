## 12.1 存储类别

C 从三个维度描述变量：**作用域、链接、存储期**。

### 作用域

**作用域**（scope）：程序中可以访问标识符的区域。

- **块作用域**（block scope）：在 `{}` 内定义，仅块内可见（C99 起 for/while 的控制表达式与循环体同属一个块）
- **函数作用域**（function scope）：仅 goto 标签，标签在其所在函数内任意可见
- **函数原型作用域**（function prototype scope）：原型形参名，到原型声明结束为止
- **文件作用域**（file scope）：函数外定义，从定义处到文件末尾可见，俗称**全局变量**

### 链接

**链接**（linkage）：标识符能否被其他翻译单元（源文件）看见。

- **外部链接**（external linkage）：可被多文件程序的所有文件访问（非 static 的文件作用域变量）
- **内部链接**（internal linkage）：只在本翻译单元内访问（`static` 修饰的文件作用域变量）
- **无链接**（no linkage）：块作用域变量、函数形参

### 存储期

**存储期**（storage duration）：对象在内存中存在的时间。

- **静态存储期**（static storage duration）：程序整个执行期间存在。文件作用域变量天然如此；块内加 `static` 亦是
- **线程存储期**（thread storage duration）（C11）：`_Thread_local` 声明，每个线程一份，线程存活期间存在
- **自动存储期**（automatic storage duration）：块作用域变量默认，进入块分配、退出块释放
- **动态分配存储期**（allocated storage duration）：malloc/free 管理（见 12.4）

### 五种存储类别

| 存储类别 | 存储期 | 作用域 | 链接 | 声明方式 |
| --- | --- | --- | --- | --- |
| 自动 | 自动 | 块 | 无 | 块内（可省 auto，C 中几乎不用） |
| 寄存器 | 自动 | 块 | 无 | 块内 `register`（请求放寄存器，不可取地址；现代编译器自行优化，少用） |
| 静态、无链接 | 静态 | 块 | 无 | 块内 `static` |
| 静态、外部链接 | 静态 | 文件 | 外部 | 所有函数外定义 |
| 静态、内部链接 | 静态 | 文件 | 内部 | 函数外 `static` |

```c
int global = 0;              /* 文件作用域,外部链接 */
static int file_local = 1;   /* 文件作用域,内部链接(其他文件看不到) */

void f(void)
{
    int count = 0;           /* 自动存储期,每次调用重置 */
    static int calls = 0;    /* 静态存储期,跨调用保持值,只初始化一次 */
    calls++;
}
```

### static 的三重含义（易混点）

1. 修饰**文件作用域变量/函数**：内部链接，仅本文件可见（隐藏）
2. 修饰**块作用域变量**：静态存储期，值跨调用保持
3. 与存储类别关键字组合无第三义——见到 static 先看变量在不在函数外

### 外部变量的使用与 extern

多文件共享全局变量：**定义一次**，其他文件用 `extern` **声明**：

```c
/* file1.c */
int giants = 5;             /* 定义(分配存储) */

/* file2.c */
extern int giants;          /* 声明(引用别处定义),不分配存储 */
```

外部变量的初始化必须是常量表达式；未显式初始化时静态存储期变量自动零初始化。

外部变量的问题：任何函数都能改它，数据流向不透明、并发不安全，**仅在真正需要共享时使用**，否则优先传参。

## 12.2 随机数函数和静态变量

`rand()` 内部用静态变量保持**种子**（seed）状态——这是“静态无链接存储类别”的教科书案例：状态要对调用者隐藏、又要跨调用保持：

```c
static unsigned long int next = 1;                    /* 内部静态种子 */

int rand0(void)                                       /* 简化的伪随机算法 */
{
    next = next * 1103515245 + 12345;
    return (unsigned int) (next / 65536) % 32768;
}

void srand0(unsigned int seed) { next = seed; }       /* 重置种子 */
```

标准用法（stdlib.h + time.h）：

```c
#include <stdlib.h>
#include <time.h>
srand((unsigned int) time(0));    /* 用当前时间做种子,每次运行不同 */
int r = rand() % 6 + 1;           /* 1~6 的"骰子" */
```

不调 srand 时 rand 每次运行产生相同序列（默认种子 1）——便于复现，也是“随机数不随机”的常见原因。

## 12.3 掷骰子

原书用多文件示例演示外部链接与内部链接的分工：dice.c 定义 `roll_count`（外部链接，统计总次数）、静态函数 `rollem`（内部链接，仅本文件用）；主文件通过 extern 声明读取统计。要点：**对外只暴露必要接口，内部细节用 static 隐藏**。

## 12.4 分配内存：malloc()和free()

自动变量的生存期由块决定；`malloc`（memory allocation，内存分配）在**运行期按需申请堆内存**，生存期由你掌控（直到 free 或程序结束）：

```c
#include <stdlib.h>
double * ptd;

ptd = (double *) malloc(30 * sizeof(double));   /* 申请 30 个 double */
if (ptd == NULL) {                              /* 分配失败返回 NULL,必须检查 */
    fprintf(stderr, "Memory allocation failed.\n");
    exit(EXIT_FAILURE);
}
ptd[0] = 3.14;          /* 当数组用 */
...
free(ptd);              /* 用完归还;free 的参数必须是 malloc 的返回值 */
```

要点：

- `malloc` 返回 `void *`，C 中**不必强制转换**也能赋给任何指针（书中演示转换是兼容 C++ 的写法）
- 分配失败返回 **NULL**，不检查就解引用会崩溃
- **配对原则**：每个 malloc 对应一个 free；忘记 free → **内存泄漏**（memory leak）
- `free` 之后指针成为**悬空指针**（dangling pointer），不应再解引用；稳妥起见置 NULL：`free(p); p = NULL;`
- `exit()`（stdlib.h）立即终止程序，`EXIT_FAILURE`/`EXIT_SUCCESS` 是可移植的状态码
- ANSI 之前用独立函数分配 char/非 char 内存，已淘汰

### free()的重要性

动态内存不会随块结束自动回收；长生命周期进程（服务、循环）中泄漏会累积直到耗尽内存。

### calloc()函数

```c
long * newarray = calloc(100, sizeof(long));   /* 100 个元素,且全部清零 */
```

`calloc(nmemb, size)` 按“元素个数 × 元素大小”申请并把内存**初始化为 0**；与 malloc 一样需要 free。

### 动态内存与变长数组

VLA 的大小在运行期确定，但生存期仍是块的自动存储期；malloc 版本可在函数返回后继续使用——**需要“活得比函数久”的可变大小数据时用 malloc**。

### 存储期与虚拟内存

普通程序面对的是**虚拟内存**（virtual memory）：OS 维护“逻辑地址 → 物理内存”的映射，程序以为独享连续地址空间。malloc 管理的是进程堆区，与物理内存的细节被 OS 隔离（深入机制属操作系统话题）。

## 12.5 ANSI C类型限定符

### const 类型限定符

只读语义（第 4、10 章已用）。全局 const 常与 static 连用，做成文件私有的只读表格：`static const int days[] = {31, 28, ...};`

### volatile 类型限定符

告知编译器该变量可能被**程序之外的因素**（硬件寄存器、信号处理、其他线程）改变，禁止缓存优化：

```c
volatile int * p_register;    /* 每次都必须真实读写内存 */
```

可以与 const 组合：`const volatile int * port;`——程序不能改（只读），但外部会变。

### restrict 类型限定符

C99 引入。**限定指针**：该指针是其所指数据块的**唯一初始访问途径**，编译器可据此优化：

```c
void * memcpy(void * restrict s1, const void * restrict s2, size_t n);
void * memmove(void * s1, const void * s2, size_t n);   /* 不 restrict:允许重叠 */
```

违反 restrict 承诺（另辟途径修改）是未定义行为。

### _Atomic 类型限定符

C11 并发支持：原子类型不可被线程执行中途打断地访问，配套 `<stdatomic.h>`。并发编程属进阶话题，知道“存在、用于多线程”即可。

### _Thread_local

C11 声明**线程存储期**变量，每个线程一份：`_Thread_local int err_code;`

### 小结

- 三维定位变量：作用域（哪里可见）、链接（跨文件可见否）、存储期（活多久）
- static 一词两义：函数外=内部链接，函数内=静态存储期
- extern 声明引用其他文件的定义；全局变量能少用就少用
- malloc/free 配对，检查 NULL，防悬空指针；calloc 顺带清零
- 限定符四件套：const 只读、volatile 防优化、restrict 允许优化、_Atomic/_Thread_local 服务并发
