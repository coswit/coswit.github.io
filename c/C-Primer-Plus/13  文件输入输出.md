## 13.1 与文件进行通信

C 把文件视为连续的字节流，每个文件以 **EOF**（End Of File）结尾。标准 I/O 通过 **FILE 指针**操作文件：

```c
FILE * fp;                       /* stdio.h 定义的不透明结构指针 */
fp = fopen("hello.txt", "r");    /* 打开文件,失败返回 NULL */
```

**文件模式**（原书 Table 13.1）：

| 模式字符串 | 含义 |
| --- | --- |
| `"r"` | 读 |
| `"w"` | 写（截断已有文件/创建新文件） |
| `"a"` | 追加 |
| `"r+"` | 读写（文件需存在） |
| `"w+"` | 读写（先截断/创建） |
| `"a+"` | 读 + 追加 |
| `b` 后缀（如 `"rb"`、`"wb+"`） | 二进制模式 |

UNIX 不区分文本/二进制；Windows 下文本模式会做 `\n` ↔ `\r\n` 转换，二进制数据（结构体、图像）必须用 `b` 模式。

## 13.2 标准I/O

标准 I/O 的完整流程：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int ch;
    FILE * fp;
    unsigned long count = 0;

    fp = fopen("wacky.txt", "r");
    if (fp == NULL)                       /* 打开失败必须检查 */
    {
        printf("Can't open file. Bye.\n");
        exit(EXIT_FAILURE);
    }
    while ((ch = getc(fp)) != EOF)        /* getc:文件版 getchar */
    {
        putc(ch, stdout);                 /* putc:指定输出流 */
        count++;
    }
    fclose(fp);                           /* 关闭:刷缓冲、释放资源 */
    printf("File has %lu characters.\n", count);
    return 0;
}
```

- `getc(fp)` / `putc(ch, fp)` 是 getchar/putchar 的文件版
- **fclose**：关闭前刷新缓冲区；程序正常结束会自动关闭仍打开的流，但显式关闭是好习惯（尤其写文件）
- 三个自动打开的标准流：`stdin`（标准输入）、`stdout`（标准输出）、`stderr`（标准错误）

fprintf/fscanf 与 printf/scanf 同构，首参数是 FILE 指针：

```c
fprintf(fp, "%s %d\n", word, n);
fscanf(fp, "%s %d", word, &n);
```

## 13.4 文件I/O：fprintf()、fscanf()、fgets()和fputs()

```c
char words[MAX];

fgets(words, MAX, fp);       /* 读一行:遇 '\n'、n-1 个字符或 EOF 停止,保留 '\n' */
fputs(words, fp);            /* 写一行:不额外加 '\n' */
```

fgets/fgets 家族的返回值：成功返回首参数指针，读到 EOF 返回 NULL。写文件示例流程：fgets 从输入读 → fputs 写到目标文件，逐行搬运。

## 13.5 随机访问：fseek()和ftell()

`fseek` 定位文件位置指示符，`ftell` 报告当前位置（返回类型 long）：

```c
int fseek(FILE * fp, long offset, int whence);
long ftell(FILE * fp);
```

**whence 的取值**（原书 Table 13.3）：

| 模式 | 偏移量的起点 |
| --- | --- |
| `SEEK_SET` | 文件开始 |
| `SEEK_CUR` | 当前位置 |
| `SEEK_END` | 文件末尾 |

```c
fseek(fp, 0L, SEEK_SET);     /* 定位到文件开头 */
fseek(fp, 10L, SEEK_CUR);    /* 从当前位置前移 10 字节 */
fseek(fp, 0L, SEEK_END);     /* 定位到文件末尾 */

long last = ftell(fp);       /* 末尾位置的偏移 = 文件大小(字节数) */
```

- fseek 返回 0 成功、-1 失败；超出文件范围的定位可能返回 -1 或行为未定义
- “倒读文件”的惯用法：

```c
fseek(fp, 0L, SEEK_END);
long last = ftell(fp);
for (long count = 1L; count <= last; count++)
{
    fseek(fp, -count, SEEK_END);
    putchar(getc(fp));
}
```

- C99 另有 `fgetpos`/`fsetpos`（fpos_t 类型），面向超大文件（超过 long 表达范围），较少用

## 13.6 标准I/O的机理

标准 I/O 的核心是**缓冲**（buffering）：

- 打开文件时自动创建缓冲区（通常 BUFSIZ 大小或按需），读写先发生在缓冲区，批量与磁盘交换
- 缓冲满或调用 fflush 时**刷新**（flush）到实际文件
- 收益：减少系统调用次数，大幅提升 I/O 效率

```mermaid
flowchart LR
    A["程序 getc/putc"] --> B["流缓冲区"]
    B -- "缓冲满或 fflush/fclose" --> C["内核与磁盘文件" ]
```

这也是“写文件后必须 fclose 或 fflush”的原因：数据可能还躺在缓冲区里。

## 13.7 其他标准I/O函数

### int ungetc(int c, FILE * fp)

把字符“退回”输入流，下一次读取会先读到它（每次只能退一个字符）：

```c
while (isspace(ch = getc(fp)))
    ;
ungetc(ch, fp);      /* 多读了一个,还回去 */
```

### int fflush()函数

`fflush(fp)` 强制刷新输出缓冲；`fflush(NULL)` 刷新所有输出流。

### int fread()和fwrite()

按**二进制块**读写，适合数组与结构体：

```c
size_t fwrite(const void * restrict ptr, size_t size, size_t nmemb, FILE * restrict fp);
size_t fread(void * restrict ptr, size_t size, size_t nmemb, FILE * restrict fp);
/* 例:写入 1 个结构体 */
fwrite(&primer, sizeof(struct book), 1, fp);
/* 例:读入最多 MAXBKS 个结构体,返回实际读到的个数 */
size_t n = fread(library, sizeof(struct book), MAXBKS, fp);
```

返回成功读写的**完整项数**。二进制数据不能用文本函数读写：文本模式会做换行符转换，Windows 下 0x1A 还会被误认为 EOF——二进制内容必须走 `b` 模式 + fread/fwrite。

### 小结

- 文件操作五步：声明 FILE * → fopen 检查 NULL → 读写 → fclose → 处理 EOF/错误
- 文本 I/O：getc/putc、fgets/fputs、fscanf/fprintf；二进制块：fread/fwrite
- fseek/ftell 随机定位，SEEK_SET/CUR/END 三种基准
- 缓冲是标准 I/O 高效的原因，也是必须正确关闭/刷新的原因
- stderr 不受重定向影响，错误信息应走 stderr
