## 14.1 示例问题：创建图书目录

单个变量无法描述“书”这种多属性实体，数组也只能装同类型数据——需要能**把不同类型打包**的类型，这就是**结构**（structure）。

## 14.2 建立结构声明

**结构声明**（structure declaration）描述结构的组成：

```c
struct book {                   /* struct book 是新的类型名 */
    char title[40];
    char author[40];
    float value;
};                              /* 分号不能少 */
```

声明不分配内存，只是创建了“图纸”；`struct` 是关键字，`book` 是**结构标记**（structure tag）。

## 14.3 定义结构变量

```c
struct book library;                        /* 定义:分配内存 */

struct book done = {                        /* 初始化 */
    "The PrawnIdiot Chronicles",
    "Freddy Foon",
    1.95
};

struct book surprise = { .value = 10.99 };  /* C99 指定初始化器,其余为 0 */
```

### 访问结构成员

**成员运算符 `.`（dot operator）：

```c
library.value;              /* 访问 value 成员 */
scanf("%f", &library.value); /* &library.value:先取成员再取地址 */
strcpy(library.title, "xx");
```

### 结构的初始化器与赋值

C 允许结构**整体赋值**（逐成员拷贝），与数组不同：

```c
struct book a = {"T", "A", 1.0};
struct book b = a;          /* 合法:整个结构拷贝 */
b = a;                      /* 合法 */
```

### 嵌套结构

```c
struct names { char first[20]; char last[20]; };
struct guy {
    struct names handle;    /* 嵌套另一个结构 */
    char favfood[30];
    float income;
};
struct guy fellow = { {"Ewen", "Villard" }, "fish", 68112.00 };
fellow.handle.first;        /* 用两个点逐层访问 */
```

## 14.4 结构数组

```c
struct book library[MAXBKS];        /* 数组的每个元素都是一个结构 */

library[0].value = 10.99;           /* 下标在前,成员在后 */
scanf("%s", library[i].title);
```

初始化按元素分组：

```c
struct book library[2] = {
    {"Novel", "Author A", 9.9},
    {"Poem",  "Author B", 8.8}
};
```

内层花括号可省（不推荐，易错）。

## 14.5 嵌套结构

见 14.3 的 names/guy 示例。嵌套结构让“结构套结构”表达复杂实体。

## 14.6 指向结构的指针

**结构指针**是访问结构最高效的方式（避免整体拷贝）：

```c
struct guy fellow = {...};
struct guy * him = &fellow;         /* 指向结构的指针 */

him->income;                        /* 箭头运算符:指针访问成员 */
(*him).income;                      /* 等价写法:先解引用再取成员 */
him->income == (*him).income == fellow.income;
```

- `->`（**箭头运算符**，arrow operator）专用于“指针取成员”
- `him + 1` 指向下一个同类型结构（结构数组中）

## 14.7 向函数传递结构的信息

三种方式，取舍清晰：

| 方式 | 形参 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 传成员 | `double sum(double x, double y)` | 简单 | 只能用单个成员 |
| 传指针 | `double sum(const struct funds * money)` | 高效（只传地址） | 需解引用；const 保护只读 |
| 传整个结构 | `double sum(struct funds money)` | 拷贝形参，原数据安全 | 大结构拷贝开销大 |

```c
struct funds { char bank[20]; double bankfund; };

double sum(const struct funds * money)     /* 指针版 */
{
    return money->bankfund + money->savefund;
}

double sum2(struct funds money)            /* 值传递版 */
{
    return money.bankfund + money.savefund;
}
```

结构也可作为**返回值**（数组做不到这一点）：

```c
struct namect getinfo(void);               /* 返回一个结构 */
```

**结构、指针与数组三者对比**：数组传参退化为指针，结构传参默认拷贝——这是结构与数组在函数调用上的本质差异。

## 14.8 把结构内容保存到文件中

用 `fwrite`/`fread` 按二进制块存取结构：

```c
struct book library[MAXBKS];
size_t size = sizeof(struct book);

/* 追加写 */
FILE * pbooks = fopen("book.dat", "a+b");
fwrite(&library[0], size, 1, pbooks);

/* 读取:返回实际读到的结构个数 */
rewind(pbooks);
size_t count = fread(library, size, MAXBKS, pbooks);
```

注意：结构内含指针时**不能**这样整体落盘——落盘的是指针值，下次运行即失效（俗称“浅存储”问题）。

## 14.9 结构：下一步是什么

结构还支持：指向自身的指针（链表的基础）、复合字面量传参 `(struct point){1, 2}`、伸缩型数组成员（C99：最后一个成员写成 `int arr[];`）等特性。

## 14.10 联合简介

**联合**（union）在**同一块内存**中存储多种类型之一，任意时刻只有一个成员有效：

```c
union hold {
    int digit;
    double bigf;
    char letter;
};

union hold fit;             /* sizeof(union hold) == 最大成员的大小 */
fit.digit = 23;             /* 此时按 int 解释 */
fit.bigf = 2.0;             /* 覆写为 double,digit 的值已失效 */
```

- 用**“记录类型 + 联合”**模式表达“多选一”的数据：

```c
struct owner { ... };
struct leasecompany { ... };

struct data {
    int type;               /* 0 表示个人,1 表示公司 */
    union {
        struct owner ownerinfo;
        struct leasecompany leaseinfo;
    } sd;                   /* 联合嵌进结构 */
};
if (car.type == 0) ... car.sd.ownerinfo ...;
```

## 14.11 枚举类型

**枚举**（enumerated type）为整型常量取有意义的名字：

```c
enum spectrum { red, orange, yellow, green, blue, violet };
enum spectrum color;

color = blue;
if (color == green) ...;
for (color = red; color <= violet; color++)    /* 枚举量就是 int */
    ...
```

- 默认从 0 开始，依次 +1：`red`=0、`orange`=1……
- 可显式指定：`enum levels { low = 100, medium = 500, high = 2000 };`，后续未指定的接着递增
- 枚举常量的类型是 int；枚举变量可参与整数运算
- C 的枚举**不隔离取值范围**（任何 int 都能赋给枚举变量），相比 C++/Java 弱约束

## 14.12 typedef简介

**typedef** 为现有类型起别名：

```c
typedef struct book { ... } Book;    /* 以后直接写 Book */
typedef unsigned char byte;
typedef int (* PFUN)(int, int);      /* 复杂类型的别名,大幅提高可读性 */

Book library;                        /* 等价 struct book library */
```

与 `#define` 的区别：typedef 由**编译器**处理、能正确作用于复杂类型声明；宏只是文本替换。习惯：结构用标记 + typedef 双命名（`struct book` 与 `Book` 都可用）。

## 14.13 高级的特性

- **命名空间**（namespace）C 独有的细分概念：结构标记、成员名、变量名属于不同命名空间，可重名：`struct guy { char guy[20]; };` 合法
- 复杂声明（如函数指针数组）的读法见 14.14；借助 cdecl 工具可以自动解析这类声明

## 14.14 函数和指针

**函数指针**（function pointer）：函数名即函数的入口地址，可存入变量、作参数传递。

```c
void ToUpper(char *);                       /* 普通函数原型 */

void (* pf)(char *);                        /* 函数指针声明:括号必不可少 */
pf = ToUpper;                               /* 赋值:函数名即地址 */
pf(str);                                    /* 调用方式一 */
(*pf)(str);                                 /* 调用方式二,两者等价 */
```

`void (*pf)(char *)` 读法：pf 先与 `*` 结合是指针，指向“带 char* 参数、返回 void 的函数”。对照：`void *pf(char *)` 是“返回 void* 的函数 pf”——括号决定一切。

经典应用——**把“操作”作为参数**：

```c
void show(void (* fp)(char *), char * str)  /* 接收任意 void f(char*) 型函数 */
{
    (*fp)(str);                             /* 对 str 应用该函数 */
    puts(str);
}
show(ToUpper, copy);                        /* 传函数名 */
show(ToLower, copy);
```

函数指针数组（表驱动，替代长 switch）：

```c
void (* pfun[3])(char *) = {ToUpper, ToLower, Transpose};
/* pfun[i](str):按下标调用不同函数 */
```

### 小结

- 结构打包异构数据；`.` 取成员、`->` 指针取成员；结构可整体赋值、可作返回值
- 传结构：指针高效、值传递安全，按需选择；大结构优先指针 + const
- fwrite/fread 二进制存结构；含指针的结构不能直接落盘
- 联合是多选一的共享内存；枚举是命名整型常量；typedef 起类型别名
- `void (*pf)(char *)` 函数指针：函数名即地址，`pf(str)` 与 `(*pf)(str)` 等价
