## 15.1 二进制记数系统

计算机用二进制（bit 0/1）表示一切。$n$ 位无符号数可表示 $0 \sim 2^n - 1$。

### 有符号整数：补码

**补码**（two's complement）是现代平台有符号整数的标准编码：最高位为符号位，负数 = 按位取反加一。

```c
/* 8 位示例:1 = 0000 0001;-1 = 1111 1111 */
signed char a = -1;    /* 位模式 0xFF */
unsigned char b = 255; /* 位模式同为 0xFF,解释不同 */
```

同一位置模式，有无符号只是**解释方式**不同。8 位补码范围 -128 ~ +127。

### 浮点数的二进制表示

浮点数分**符号位、指数、尾数**（如 float 的 1 + 8 + 23）存储，小数部分是 2 的负幂之和，0.1、0.2 这类十进制小数无法精确表示——浮点比较必须用误差容限，位操作也不适用于浮点。

## 15.2 其他进制数

- **八进制**（octal）：C 字面量以 `0` 开头，如 `020` = 16；1 个八进制位对应 3 个二进制位
- **十六进制**（hexadecimal）：以 `0x` 开头，如 `0x10` = 16；1 个十六进制位对应 4 个二进制位

| 十进制 | 二进制 | 八进制 | 十六进制 |
| --- | --- | --- | --- |
| 0 | 0000 | 0 | 0 |
| 8 | 1000 | 10 | 8 |
| 16 | 10000 | 20 | 10 |
| 255 | 11111111 | 377 | FF |

十六进制是描述位模式的事实标准（掩码、寄存器、颜色值）。printf：`%o`/`%#o`、`%x`/`%#x`。

## 15.3 C的按位运算符

按位运算符直接操作整数的位模式：

| 运算符 | 名称 | 规则（逐位） |
| --- | --- | --- |
| `&` | 按位与 AND | 两个都是 1 才是 1 |
| `\|` | 按位或 OR | 至少一个 1 就是 1 |
| `^` | 按位异或 XOR | 相异为 1，相同为 0 |
| `~` | 按位取反 NOT | 0 变 1，1 变 0（一元） |
| `<<` | 左移 | 右边补 0，相当于 ×2 |
| `>>` | 右移 | 无符号左边补 0（逻辑移位）；有符号补符号位（算术移位，实现定义） |

优先级：`~` 与一元负号同级（高）；`<<`/`>>` 介于算术与比较之间；`&` 高于 `^`，`^` 高于 `|`（均低于比较运算符，写复杂表达式建议加括号）。

### 按位与：&（掩码）

**掩码**（mask）是按位与的标配套路——用 1 的位“保留”、0 的位“清零”：

```c
#define MASK 0x02                  /* 0000 0010 */

flags = flags & MASK;              /* 只保留第 1 位,其余清零 */
if ((flags & MASK) == MASK)        /* 检查第 1 位是否为 1 */
    ...
ch &= 0xDF;                        /* 大写化:清除大小写位(ASCII) */
```

### 按位或：|（打开位）

把指定位**置 1**，其余不动：

```c
flags = flags | MASK;    /* 打开第 1 位 */
flags |= MASK;           /* 复合赋值等价 */
```

### 按位异或：^（切换位）

把指定位**取反**（0↔1）：

```c
flags = flags ^ MASK;    /* 第 1 位取反 */
val ^= 0xFF;             /* 整字节取反 */
```

异或性质：`x ^ x == 0`、`x ^ 0 == x`、异或两次还原——用于简单加密、找落单元素等。

### 按位取反：~

一元运算符，翻转所有位：

```c
unsigned char x = ~0;   /* ~0 是 int 的 -1,赋给 unsigned char 截断为 0xFF */
val &= ~MASK;      /* 清除 MASK 对应的位:比手写反掩码更清晰 */
```

`~` 的结果是按提升后的 int 计算的，对 char 用时要留意符号扩展。

### 移位运算：<<和>>

```c
int x = 1;
x << 3;            /* 1→8:左移 n 位 = 乘 2^n */
x >> 2;            /* 右移 2 位:无符号 = 除 2^n(舍余) */

/* 组合出"取字节"的经典写法 */
int color = 0xA1B2C3D4;
int r = (color >> 16) & 0xFF;    /* 取第 2 个字节 */
```

左移超宽（1 << 32 之于 32 位 int）是未定义行为；移位计数应小于位宽。

## 15.4 位字段

**位字段**（bit field）借助结构按位划分存储单元：

```c
struct box_props {
    bool opaque       : 1;    /* 1 位 */
    unsigned int fill_color : 3;    /* 3 位:可存 0~7 */
    unsigned int show_border : 1;
    unsigned int border_color : 3;
    unsigned int border_style : 2;
    unsigned int        : 2;  /* 匿名位字段:占位不用 */
    unsigned int        : 0;  /* 宽度 0:强制对齐到下一个存储单元 */
};
```

```c
struct box_props box = { true, 2, true, 4, 1 };
box.fill_color = 5;        /* 像普通成员一样读写,编译器负责移位与掩码 */
```

- 位字段的实际布局（从低位还是高位开始）**由实现定义**，跨平台序列化/通信协议不要直接依赖位字段布局，应手工移位组包
- 位字段成员的类型应是无符号整型/bool；取地址运算符 `&` 对位字段无效

## 15.5 对齐特性

C11 提供对齐控制：**对齐**（alignment）指数据起始地址须是其大小的倍数（如 double 常要求 8 字节对齐），影响性能与某些硬件的可用性。

```c
#include <stdalign.h>          /* 提供 alignas/alignof 宏 */

size_t d = alignof(double);    /* 通常 8 */

_Alignas(16) char buf[64];     /* 或 alignas(16):让 buf 16 字节对齐 */
```

`_Alignof`（运算符）查询类型的对齐要求；`_Alignas`/`alignas`（说明符）指定变量对齐。典型用途：SSE 等向量化指令、DMA 缓冲区。C11 还提供 `aligned_alloc` 函数（分配指定对齐的动态内存，stdlib.h）。

### 小结

- 补码编码下，位模式相同、符号解释不同；浮点不适合位操作
- 掩码四式：`&` 查/清、`|` 置位、`^` 翻转、`>>`/`<<` 移位取位
- 位字段让“标志位集合”写起来像成员访问，但布局不可移植
- C11 的 alignof/alignas 服务于特殊对齐需求，日常业务代码少见
