## 16.1 翻译程序的第一步

编译前，预处理器（preprocessor）先处理源代码：`#include`、`#define`、条件编译、移除注释，再把**翻译单元**（translation unit）交给编译器。预处理以“记号”（token）做文本处理，不理解 C 语法。

## 16.2 明示常量：#define

```c
#define PX printf("x is %d.\n", x)   /* 宏:对象式宏,无参数 */
```

`#define` 把宏名替换为其后的记号串（注意：**结尾不加分号**，分号会成为替换内容的一部分）。

## 16.3 在#define中使用参数

**函数式宏**（function-like macro）带参数：

```c
#define SQUARE(X) X*X          /* 有缺陷的写法 */
```

### 括号的重要性

宏是**纯文本替换**，不加括号必出事：

```c
#define SQUARE(X) X*X
SQUARE(4)        /* 16 */
SQUARE(x+2)      /* x+2*x+2 = 3x+2,错误! */
100/SQUARE(2)    /* 100/2*2 = 100,错误! */

#define SQUARE(X) ((X)*(X))   /* 正确写法:整体与参数都加括号 */
```

规则：**每个参数加括号、整个表达式加括号**。

### 用宏创建字符串：#运算符

`#` 把宏参数转换为**字符串字面量**：

```c
#define PSQR(X) printf("The square of " #X " is %d.\n", ((X)*(X)))
PSQR(2 + 4);   /* 输出:The square of 2 + 4 is 36 */
```

### 预处理器黏合剂：##运算符

`##`（记号黏合，token pasting）把两个记号拼接为一个：

```c
#define XNAME(n) x ## n
#define PRINT_XN(n) printf("x" #n " = %d\n", x ## n)

XNAME(4)        /* 展开为 x4 */
PRINT_XN(4)     /* 输出:x4 = <x4 的值> */
```

### 变参宏：...

C99 支持可变参数宏，`__VA_ARGS__` 代表省略号部分：

```c
#define PR(...) printf(__VA_ARGS__)
PR("Hello\n");                       /* 展开为 printf("Hello\n") */
```

## 16.4 宏和函数的选择

| 维度 | 宏 | 函数 |
| --- | --- | --- |
| 速度 | 快（无调用开销，内联展开） | 有调用开销 |
| 类型 | 与类型无关（纯文本） | 参数类型固定，编译器检查 |
| 副作用 | 参数被多次求值：`MAX(i++, j++)` 危险 | 每个实参只求值一次 |
| 调试 | 展开后难调试；代码膨胀 | 可单步、可递归 |

宏适用于简单、短小、需要泛型的操作（如容器取元素）；复杂逻辑一律用函数或 C99 inline。

## 16.5 文件包含：#include

- `#include <stdio.h>`：在**系统目录**搜索头文件（标准库）
- `#include "myhead.h"`：先在**当前目录**（或引号指定的路径）搜索，找不到再搜系统目录

头文件典型内容：宏定义、函数原型、结构声明、typedef、inline 定义。**头文件只放声明，不放定义**（否则多文件重复链接冲突）。

## 16.6 其他指令

### #undef指令

```c
#undef PX          /* 取消已定义的宏;已定义的宏可重新定义,先 undef 更清晰 */
```

### 从C预处理器角度看已定义

判断“宏是否已定义”只看名字，不看值：`#define LIMIT 400` 后，`defined(LIMIT)` 为真。

### 条件编译

```c
#ifdef MAVIS
    #include "horse.h"
#else
    #include "cow.h"
#endif

#ifndef SIZE        /* 防止重复包含的经典写法(include guard) */
    #define SIZE 100
#endif

#if SYS == 1
    ...
#elif SYS == 2      /* C89 起;#elifdef/#elifndef 是 C23 才加入的 */
    ...
#else
    ...
#endif
```

`#if` 后接整型常量表达式，非零为真；`defined(名)`（或 `defined 名`）判断宏是否已定义。

### 预定义宏

| 宏 | 含义 |
| --- | --- |
| `__DATE__` `__TIME__` | 编译日期/时间 |
| `__FILE__` `__LINE__` | 当前文件名/行号 |
| `__func__` | C99，当前函数名 |
| `__STDC_VERSION__` | C 标准版本（C99 为 199901L，C11 为 201112L） |

### #line和#error

```c
#line 100 "cool.c"     /* 重置 __LINE__/__FILE__ 的报告值 */
#error It must be C99! /* 编译到此报错,用于早期拦截错误配置 */
```

### #pragma

向编译器传递实现特有的指令（如 `#pragma pack(1)` 结构紧凑布局）；C99 后可配合 `_Pragma` 运算符。

## 16.7 内联函数（C99）

C99 用 **inline** 提示编译器"像宏一样展开、但保持函数语义”：

```c
static inline void eatline(void)    /* 常与 static 连用,避免外部定义问题 */
{
    while (getchar() != '\n')
        continue;
}
```

inline 函数定义通常放头文件；现代编译器会自动内联小函数，inline 更多是许可而非强制。

## 16.8 _Noreturn函数（C11）

C11 新增 `_Noreturn` 关键字，标记**从不返回调用者**的函数（`<stdnoreturn.h>` 提供 `noreturn` 宏作为等价拼写）：

```c
#include <stdnoreturn.h>

_Noreturn void fatal(void);    /* 也可写成 noreturn void fatal(void); */

void fatal(void)
{
    fprintf(stderr, "Fatal error!\n");
    exit(EXIT_FAILURE);        /* 必须以 exit/abort/longjmp 等方式终结 */
}
```

`exit()` 是典型的 _Noreturn 函数。该标记帮助编译器优化代码流、消除“控制流到达函数末尾”的误报警告；若标记了 _Noreturn 的函数实际返回了，行为未定义。

## 16.9 C库

C 标准库（C library）由标准规定的**一组头文件**（接口声明）与各平台提供的**实现**（库文件）组成，覆盖输入输出、字符串、数学、通用工具、断言、变长参数等类别，涵盖 stdio.h、stdlib.h、string.h、math.h 等几十个头文件。使用要点：

- 包含对应头文件即可获得函数原型
- 部分实现需要显式链接，如 UNIX 下使用数学函数要加 `-lm`
- C11 起，标准头文件还包含原子操作（stdatomic.h）、线程（threads.h）等支持

## 16.10 数学库

```c
#include <math.h>
double x = sqrt(9.0);    /* 平方根;链接时需 -lm(部分平台) */
pow(2.0, 10.0);          /* 2^10 */
```

编译数学程序：`gcc usemath.c -lm`。

## 16.11 通用工具库

```c
void signoff(void);
void go_away(void);

atexit(signoff);         /* 注册退出时调用的函数;后进先出(LIFO)顺序执行 */
atexit(go_away);
exit(EXIT_FAILURE);      /* 触发 atexit 注册的函数,再终止 */
```

main 中的 return 等价于 exit；标准保证 atexit 至少能注册 32 个函数。

### qsort()

标准库泛型快排，函数指针的经典应用：

```c
void qsort(void * base, size_t nmemb, size_t size,
           int (* compar)(const void *, const void *));

int mycmp(const void * p1, const void * p2)   /* 比较函数:返回正/0/负 */
{
    const int * a = (const int *) p1;         /* 需先转回具体类型 */
    const int * b = (const int *) p2;
    if (*a > *b) return 1;
    else if (*a == *b) return 0;
    else return -1;
}

qsort(arr, N, sizeof(int), mycmp);
```

## 16.12 断言库

```c
#include <assert.h>
assert(z >= 0);           /* 为假则打印表达式、文件、行号并 abort */

#define NDEBUG            /* 定义 NDEBUG 后 assert 变空操作,用于发布版 */
#include <assert.h>

/* C11 静态断言:编译期检查 */
_Static_assert(sizeof(char) == 1, "char must be 1 byte");
```

## 16.13 string.h库中的memcpy()和memmove()

拷贝任意类型内存块（比 strcpy 更底层）：

```c
void * memcpy(void * restrict s1, const void * restrict s2, size_t n);
void * memmove(void * s1, const void * s2, size_t n);

/* memcpy:不允许重叠;memmove:允许(相当于先备份再拷) */
memmove(ar + 1, ar, 10 * sizeof(double));   /* 同数组内挪动,安全 */
```

## 16.14 可变参数：stdarg.h

自己实现 printf 式可变参数函数：

```c
#include <stdarg.h>

double sum(int lim, ...)
{
    va_list ap;                       /* 参数包对象 */
    double total = 0;

    va_start(ap, lim);                /* 初始化,lim 是最后一个固定参数 */
    for (int i = 0; i < lim; i++)
        total += va_arg(ap, double);  /* 逐个取参数,指定类型 */
    va_end(ap);                       /* 清理 */
    return total;
}
```

至少要有一个固定参数；`va_arg` 的类型必须与实际传入一致（可变参数处 float 会提升为 double、char/short 提升为 int）。

### 小结

- 预处理是纯文本/记号替换：函数式宏**参数与整体都要加括号**；`#` 字符串化、`##` 黏合、`__VA_ARGS__` 变参
- 宏快而险（多次求值、无类型检查），函数稳而慢，inline 兼取两者之意
- 条件编译 + include guard 是多文件项目的地基；`__FILE__`/`__LINE__` 等预定义宏服务调试
- C 库精选：math、exit/atexit、qsort（函数指针驱动泛型）、assert/_Static_assert、memcpy/memmove（重叠区别）、stdarg（可变参数）
