本章的概念全景：**变量**(variables)与**常量**(constants)是程序操纵的基本数据对象；**声明**(declarations)列出要使用的变量并说明其类型与初值；**运算符**(operators)指定对它们进行的操作；**表达式**(expressions)把变量和常量组合起来产生新值。**对象的类型**决定它能取哪些值、能参与哪些运算。

## 2.1 变量名

名字由字母和数字组成，第一个字符必须是字母；下划线 `_` 算作字母，可用于改善长变量名的可读性。但不要用下划线开头——库例程常用这类名字。

- 大小写敏感：x 与 X 是两个不同的名字。传统 C 习惯变量名用小写、符号常量全大写
- `if`、`else`、`int`、`float` 等**关键字**(keywords)是保留字，不能作变量名，且必须小写
- 对局部变量，短名字（循环变量 i、p；字符变量 c、s）是惯例；长名字只在含义关键处使用才有价值

## 2.2 数据类型及长度

C 的几个基本数据类型：

| 类型 | 描述 |
|--|--|
|char | 单字节，可存放本地字符集中的一个字符(character) |
| int | 整数(integer)，通常反映宿主机整数的自然长度 |
| float | 单精度浮点数(single-precision floating point) |
| double | 双精度浮点数(double-precision floating point) |

还有几个限定词：`short` 与 `long` 作用于整数，意图是提供长短不一的长度：

```c
short int sh;    /* short 通常为 16 位 */
long int counter;/* long 通常为 32 位或更长 */
```

int 依机器不同可为 16 位或 32 位。`signed` 与 `unsigned` 限定词可用于 char 或任何整数类型：**无符号数**(unsigned)总是正数或零，并遵循模 `2^n` 的算术法则（n 为该类型的位数）。例如 char 为 8 位时，`unsigned char` 取值 0～255，`signed char` 取值 -128～127（按补码/two's complement 机器）。char 是否带符号依机器而定，但可打印字符总是正的。

`long double` 指定扩展精度浮点数。与整数一样，浮点对象的大小也是实现定义的(implementation-defined)：float、double、long double 可以表示一种、两种或三种不同长度。

`<limits.h>` 与 `<float.h>` 中给出了这些类型的大小与取值范围的符号常量。

## 2.3 常量

整数常量如 1234；int 常量前面加 0 表示八进制(octal)，加 0x 或 0X 表示十六进制(hexadecimal)；这些常量后可再跟 L 表示 long、U 表示 unsigned：

| 常量 | 写法示例 |
|--|--|
| int | 1234 |
| long 常量 | 123456789L、123456789l |
| 无符号常量 | 尾部 u 或 U；ul 或 UL 表示 unsigned long |
| 浮点常量 | 含小数点(123.4)或指数(1e-2)；后缀 f 或 F 表示 float，l 或 L 表示 long double |
| 八进制 | 整数常量前加 0（零） |
| 十六进制 | 前加 0x 或 0X；可再跟 L、U，如 0XFUL 是值为十进制 15 的 unsigned long 常量 |
| 字符常量 | 'x'——单引号内单个字符，是整数 |

**字符常量**(character constant)是整数，如 `'x'`。某些字符可用转义序列表示，如 `\n`（换行）；任意字节大小的位模式可以用

```c
'\ooo'   /* ooo 为 1~3 个八进制数字 0...7 */
'\xhh'   /* hh 为一个或多个十六进制数字 */
```

指定：

```c
#define VTAB '\013' /* ASCII vertical tab —— 八进制写法 */
#define BELL '\007' /* ASCII bell character */

#define VTAB '\xb'  /* ASCII vertical tab —— 十六进制写法 */
#define BELL '\x7'  /* ASCII bell character */
```

完整的转义序列：

| 转义 | 含义 |
|--|--|
|\a | 响铃(alert, bell) |
| \b | 回退(backspace) |
| \f | 换页(formfeed) |
| \n | 换行(newline) |
| \r | 回车(carriage return) |
| \t | 水平制表(horizontal tab) |
| \v | 垂直制表(vertical tab) |
| `\\` | 反斜杠 |
| `\?` | 问号 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| \ooo | 八进制数 |
| \xhh | 十六进制数 |

字符常量 `'\0'` 表示值为 0 的字符，即**空字符**(null character)。写 `'\0'` 而不是 0 是为了强调表达式的字符性质，其数值就是 0。

字符串常量可以在编译时拼接：

```c
"hello, " "world"
```

等价于

```c
"hello, world"
```

从技术上讲，字符串常量是字符数组：内部表示在结尾带一个空字符 `'\0'`，所以物理存储比引号内的字符数**多 1**。这意味着字符串长度没有限制，但程序必须完整扫描字符串才能确定其长度。标准库函数 `strlen(s)` 返回字符串参数 s 的长度（不含结尾的 `'\0'`）：

```c
/* strlen:  return length of s */
int strlen(char s[]) {
    int i;
    while (s[i] != '\0')
        ++i;
    return i;
}
```

注意区分**字符常量**与只含单个字符的**字符串**：`'x'` 不等于 `"x"`——前者是一个整数，值为字母 x 在机器字符集中的数值；后者是含一个字符（字母 x）加一个 `'\0'` 的字符数组。

**枚举**(enumeration)常量是 int 类型的常量列表，是定义符号常量的又一种手段：

```c
enum boolean { NO, YES };
```

enum 中第一个名字值为 0，第二个为 1，依此类推，除非显式指定值；未指定处从最近一个指定值继续递增：

```c
enum escapes { BELL = '\a', BACKSPACE = '\b', TAB = '\t',
                  NEWLINE = '\n', VTAB = '\v', RETURN = '\r' };

enum months { JAN = 1, FEB, MAR, APR, MAY, JUN,
                 JUL, AUG, SEP, OCT, NOV, DEC };
                       /* FEB = 2, MAR = 3, etc. */
```

不同 enum 中的名字互不冲突；#define 与 enum 各有所长——enum 的值自动生成，声明时可以带类型便于调试。

## 2.4 声明

声明指定一个类型，后接一个或多个该类型的变量：

```c
 int  lower, upper, step;
 char c, line[1000];
```

若变量不是自动变量（即外部变量和静态变量），初始化只做一次，概念上在程序开始执行前完成，初值必须是常量表达式；显式初始化的自动变量在每次进入其所在函数或程序块时初始化，初值可以是任意表达式。外部与静态变量默认初始化为 0；未显式初始化的自动变量的值**未定义**(undefined，即垃圾值)。

限定词 `const` 可用于任何变量的声明，指定其值不会被改变；对数组使用 const 表示元素不会被修改：

```c
   const double e = 2.71828182845905;
   const char msg[] = "warning: ";
```

const 也可用于数组参数，表明函数不修改该数组：

```c
int strlen(const char[]);
```

试图修改 const 的结果是实现定义的(implementation-defined)。

## 2.5 算术运算符

二元算术运算符有 `+`、`-`、`*`、`/`，以及取模运算符 `%`。`%` 不能用于 float 或 double。负数运算时，`/` 的截断方向与 `%` 结果的符号依机器而定，上溢/下溢时的处理同样如此。

## 2.6 关系运算符与逻辑运算符

### 关系运算符

```text
>  >=  <  <=
```

关系运算符的优先级低于算术运算符，所以

```c
i < lim-1
// 等同于
i < (lim-1)
```

### 逻辑运算符

`&&` 与 `||` 连接的表达式**从左向右求值，一旦结果的真假确定即停止**（短路求值）。这一点很有用，例如在读入一行时：

```c
 for (i=0; i < lim-1 && (c=getchar()) != '\n' && c != EOF; ++i)
       s[i] = c;
```

先检查 i 是否还有空间，之后才读字符——若先读后判，字符可能在越界时被丢弃。

`&&` 的优先级高于 `||`，两者都低于关系和相等运算符，因此上例中

```c
i < lim-1 && (c=getchar()) != '\n' && c != EOF
```

不需要额外的括号。但由于 **`!=` 的优先级高于赋值 `=`**，`(c=getchar())` 一层括号必不可少。

一元否定运算符 `!` 把非零操作数转换为 0、把零转换为 1。常见用法是

```c
if (!valid)
```

代替可读性差的

```c
if (valid == 0)
```

## 2.7 类型转换

一般规则：自动转换只发生在"窄"操作数转换为"宽"操作数而不丢失信息的场合，比如表达式 `f + i` 中整数转浮点。

**char 就是小整数**，可以自由参与算术运算。把数字字符转成数值的 atoi：

```c
/* atoi:  convert s to integer */
int atoi(char s[]) {
    int i, n;
    n = 0;
    for (i = 0; s[i] >= '0' && s[i] <= '9'; ++i)
        n = 10 * n + (s[i] - '0');
    return n;
}
```

`s[i] - '0'` 得到 s[i] 中字符的数值——'0'、'1'……构成连续递增序列，这一性质是它的前提。大小写转换：

```c
/* lower:  convert c to lower case; ASCII only */
int lower(int c)
{
    if (c >= 'A' && c <= 'Z')
        return c + 'a' - 'A';
    else
        return c;
}
```

它只在 ASCII 下成立：对应的大小写字母数值距离固定，且 A～Z 之间只有字母。标准头 `<ctype.h>` 提供与字符集无关的判断与转换函数族：

```c
 c >= '0' && c <= '9'
 // 可替换为
 isdigit(c)
```

字符转整数有一个微妙之处：语言并未规定 char 是带符号还是无符号。**char 转换为 int 时可能产生负整数吗？** 答案因机器而异——有的机器对最左位为 1 的 char 做**符号扩展**(sign extension)得到负数；有的机器在左端补零，结果总为正。C 的定义保证机器标准打印字符集中的字符绝不为负，所以这些字符在表达式中总是正的；但存进 char 变量的任意位模式在不同机器上可能表现为负或正。要在 char 变量中存放非字符数据时，出于可移植性应显式指定 signed 或 unsigned。

关系表达式和 `&&`、`||` 连接的逻辑表达式定义为：真为 1，假为 0。所以赋值语句

```c
d = c >= '0' && c <= '9'
```

在 c 是数字时把 d 置 1，否则置 0。但 isdigit 这类函数为真时可能返回任意非零值——在 if、while、for 的测试部分，"真"只表示"非零"，所以没有影响。

没有无符号操作数时，下面这组非正式规则够用：

- 任一操作数是 long double，把另一个转换为 long double
- 否则，任一操作数是 double，把另一个转换为 double
- 否则，任一操作数是 float，把另一个转换为 float
- 否则，把 char 和 short 转换为 int
- 然后，任一操作数是 long，把另一个转换为 long

注意 float 在表达式中**不会**自动转换为 double——这是相对 C 早期定义的改变。使用 float 的主要原因是省存储（大数组），其次是在双精度运算特别贵的机器上省时间。

有无符号操作数时规则更复杂：有符号与无符号值之间的比较结果依机器而定，取决于各整数类型的长度。

> 例如，假设 int 是 16 位、long 是 32 位，则 -1L < 1U，因为 unsigned int 的 1U 会被提升为 signed long；而 -1L > 1UL，因为 -1L 被转换为 unsigned long，表现为一个巨大的正数。

**较长整数转换为较短整数或 char 时，直接丢弃多余的高位**：

```c
int i;
char c;
i = c;
c = i;
```

c 的值不变（无论是否涉及符号扩展）；但调换赋值顺序就可能丢失信息。float 与 int 互转（`x=i`、`i=x`）都会发生转换，float 转 int 会截断小数部分；double 转 float 是舍入还是截断由实现定义。

函数调用参数也是表达式，因此传参时同样发生类型转换：没有函数原型时，char 和 short 变为 int、float 变为 double——这就是即使函数以 char、float 调用，参数也声明为 int、double 的原因。

最后，可以用称为**强制类型转换**(cast)的一元运算符在任何表达式中显式转换类型：

```c
(类型名) 表达式
```

标准库包含一个可移植的伪随机数生成器和设置种子的函数，rand 说明了 cast 的用法：

```c
unsigned long int next = 1;

/* rand:  return pseudo-random integer on 0..32767 */
int rand(void) {
    next = next * 1103515245 + 12345;
    return (unsigned int) (next / 65536) % 32768;
}

/* srand:  set seed for rand() */
void srand(unsigned int seed) {
    next = seed;
}
```

## 2.8 自增与自减运算符

C 提供了两个不寻常的运算符：自增 `++` 与自减 `--`：

```c
n++;
n--;
```

它们可用作前缀（先加/减 1 再使用值）或后缀（先用值再加/减 1），如 `++n`、`n++`。第 3 章会频繁见到它们紧凑的用法。

## 2.9 按位运算符

C 提供六个位操作运算符，只能作用于**整型操作数**(integral operands)，即 `char、short、int、long`（带符号或无符号）：

| 运算符 | 含义 | 典型用途 |
|-- |-- | --|
| & | 按位与(bitwise AND) | 屏蔽某些位 |
| `|` | 按位或(bitwise inclusive OR) | 打开某些位 |
| ^ | 按位异或(bitwise exclusive OR) | 两操作数不同的位置 1，相同的位置 0 |
| << | 左移(left shift) | * 2^n |
| >> | 右移(right shift) | / 2^n |
| ~ | 按位取反(one's complement，一元) | 把每个 1 位变 0 位、每个 0 位变 1 位 |

p、q 取 0/1 时的真值表：

| p | q | p & q | p \| q | p ^ q |
| -- | -- | -- | -- | -- |
| 0	| 0 |	0 |	0 |	0 |
| 0	| 1	| 0	| 1	| 1 |
| 1	| 1	| 1 |	1	| 0 |
| 1	| 0	| 0	| 1 |	1 |

注意区分 `&` 与 `&&`：`x = 1; y = 2;` 时 `x & y` 为 0（无公共位），而 `x && y` 为 1（两者都非零）。

```c
// sets to zero all but the low-order 7 bits of n
n = n & 0177;       /* 把 n 除低 7 位外全部清零 */

//sets to one in x the bits that are set to one in SET_ON.
x = x | SET_ON;     /* 把 x 中 SET_ON 为 1 的位置 1 */
```

位运算符应用示例——getbits(x, p, n) 返回 x 中从位置 p 起的（右对齐的）n 位字段。假设第 0 位在最右端，p、n 均为合理的正值，如 getbits(x, 4, 3) 返回第 4、3、2 位上的 3 个位：

```c
/* getbits:  get n bits from position p */
unsigned getbits(unsigned x, int p, int n) {
    return (x >> (p + 1 - n)) & ~(~0 << n);
}
```

`x >> (p+1-n)` 把目标字段移到字的最右端；`~0` 是全 1，`~0 << n` 左移后在最右端留下 n 个 0，再取反 `~` 得到最右端 n 个 1 的掩码(mask)，两者相与即取出该字段。

## 2.10 赋值运算符与表达式

如 `i = i + 2` 这类"变量与自身运算后回写"的表达式可以写成带复合赋值运算符的形式：

```c
i += 2;
```

多数二元运算符都有对应的赋值运算符 `op=`。若 **expr1**、**expr2** 是表达式，则

```c
expr1 op= expr2
```

等价于

```c
expr1 = (expr1) op (expr2)
```

注意 expr2 会整体加括号：

```c
x *= y + 1
// 意为
x = x * (y + 1)
```

统计整数的 1 位个数的 bitcount：

```c
/* bitcount:  count 1 bits in x */
int bitcount(unsigned x) {
    int b;
    for (b = 0; x != 0; x >>= 1)
        if (x & 01)
            b++;
    return b;
}
```

复合赋值更符合人的思维习惯：我们说"把 2 加到 i 上"，而不是"取出 i，加 2，再把结果放回 i"。此外它还把 expr1 只写一遍，对复杂表达式更安全也更高效。

## 2.11 条件表达式

条件表达式语句

```c
if (a > b)
    z = a;
else
    z = b;
```

用于把较大者放入 z。作为提供此项功能的表达式，C 提供：

```c
expr1 ? expr2 : expr3
```

先求 expr1：非零则结果为 expr2 的值，否则为 expr3 的值。上例可写为：

```c
z = (a > b) ? a : b;    /* z = max(a, b) */
```

## 2.12 运算符优先级与求值次序

同行的运算符优先级相同，各行按优先级**递减**排列：

| 运算符 | 结合性 |
|-- |-- |
| ()  []  -> . | 自左向右 |
| ! ~  ` ++ `   -- + - * (type) sizeof | 自右向左 |
| * `/` %  | 自左向右 |
| +  - | 自左向右 |
| << >> | 自左向右 |
| < <= > >= | 自左向右 |
| == != | 自左向右 |
| & | 自左向右 |
| ^ | 自左向右 |
| `|`  | 自左向右 |
| && | 自左向右 |
| `||` | 自左向右 |
| ?: | 自右向左 |
| = += -= *=  `/=`  %= &= ^=  `|=`  <<= >>=  | 自右向左 |
| ,  | 自左向右 |

`->`、`.` 用于访问结构成员；一元的 `+`、`-`、`*`（指针间接寻址）优先级高于二元版本。

注意 `&`、`^`、`|` 的优先级**低于** `==` 和 `!=`。这意味着位测试表达式必须完全加括号：

```c
if ((x & MASK) == 0)
```

写惯了 `==` 优先的直觉，这里容易出错。

C 与大多数语言一样，**不指定运算符操作数的求值顺序**（例外是 `&&`、`||`、`?:` 和 `,`）。例如

```c
x = f() + g();
```

f 可能先于 g 求值，也可能相反——若 f 或 g 修改了另一个依赖的变量，x 的结果就取决于求值顺序。需要特定次序时用临时变量保存中间结果。

类似地，函数参数的求值顺序也不指定：

```c
printf("%d %d\n", ++n, power(2, n)); /* WRONG */
```

不同编译器可能产生不同结果——取决于 n 先于 power 调用还是后自增。解决办法是把副作用拆出来：

```c
++n;
printf("%d %d\n", n, power(2, n));
```

函数调用、嵌套赋值语句、自增自减运算符都会产生**副作用**(side effects)——表达式求值的副产品改变了某些变量。任何含副作用的表达式，其结果都可能微妙地依赖变量更新的顺序。典型的不幸场景：

```c
a[i] = i++;
```

下标用的是 i 的旧值还是新值？不同编译器可以有不同解释、给出不同答案。
