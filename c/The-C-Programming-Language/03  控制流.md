## 3.1 语句与程序块

`x = 0`、`i++`、`printf(...)` 这类表达式后面加分号就成了**语句**(statement)：

```c
   x = 0;
   i++;
   printf(...);
```

C 中**分号是语句结束符**，而不像 Pascal 那样是语句分隔符。

花括号 `{`、`}` 把声明与语句组合成**复合语句**(compound statement)或称**程序块**(block)，语法上等价于一条语句。

## 3.2 if-else 语句

if 语句测试的是表达式的数值，所以有简写形式：

```c
if (expression)
```

代替

```c
if (expression != 0)
```

if-else 的 else 部分可选。嵌套 if 序列中省略某个 else 会产生二义性，C 的解决方式是：**else 与最近一个尚无 else 的 if 配对**：

```c
if (n > 0)
       if (a > b)
          z = a;
       else
          z = b;
```

else 属于内层 if。若这不是本意，必须用花括号强制正确的配对：

```c
if (n > 0) {
    if (a > b)
        z = a;
}
else
    z = b;
```

再看错误示例：

```c
 if (n > 0)
        for (i = 0; i < n; i++)
            if (s[i] > 0) {
                printf("...");
                return i;
            }
    else
        printf("error -- n is negative\n");
```

缩进"明确"表达了意图，但编译器不领情——else 仍然与内层 if 配对。这类 bug 很难发现，嵌套 if 中使用花括号是个好习惯。

## 3.3 else-if 语句

```c
if (expression)
    statement
else if (expression)
    statement
else if (expression)
    statement
else
    statement
```

多路判定写成 else-if 链：从上往下逐对求值，遇到为真的表达式执行对应语句并结束整个链。else-if 链是 C 中书写多路判定的最常用方式。

二分查找——判定 x 是否在已排序数组 v 中，是 Else-if 的三路判定典型：

```c
/* binsearch:  find x in v[0] <= v[1] <= ... <= v[n-1] */
int binsearch(int x, int v[], int n) {
    int low, high, mid;
    low = 0;
    high = n - 1;
    while (low <= high) {
        mid = (low + high) / 2;
        if (x < v[mid])
            high = mid - 1;
        else if (x > v[mid])
            low = mid + 1;
        else    /* found match */
            return mid;
    }
    return -1;   /* no match */
}
```

每轮迭代把范围缩小一半，n 个元素最多比较 log₂n 次。（原摘录此处误写为 `high = mid + 1`，会导致死循环，已按原书修正为 `mid - 1`。）

## 3.4 switch 语句

switch 是多路分支语句，测试一个整型表达式的值是否匹配若干常量整数值之一，每个分支可带多条语句：

```c
#include <stdio.h>

main()  /* count digits, white space, others */
{
    int c, i, nwhite, nother, ndigit[10];
    nwhite = nother = 0;
    for (i = 0; i < 10; i++)
        ndigit[i] = 0;
    while ((c = getchar()) != EOF) {
        switch (c) {
            case '0':
            case '1':
            case '2':
            case '3':
            case '4':
            case '5':
            case '6':
            case '7':
            case '8':
            case '9':
                ndigit[c - '0']++;
                break;
            case ' ':
            case '\n':
            case '\t':
                nwhite++;
                break;
            default:
                nother++;
                break;
        }
    }
    printf("digits =");
    for (i = 0; i < 10; i++)
        printf(" %d", ndigit[i]);
    printf(", white space = %d, other = %d\n",
           nwhite, nother);
    return 0;
}
```

要点：

- `case '0':` 到 `case '3':` 连续罗列，让多个 case 落入同一段代码——'0'～'9' 任一数字都执行 `ndigit[c - '0']++`
- **break 导致立即跳出 switch**。忘写 break 会"贯穿"(fall through)到下一个分支继续执行——1.6 节的数字统计程序用 switch 改写时，贯穿恰是特性；但无意的贯穿是 bug 源
- `default` 分支在其他匹配都不成立时执行，通常放最后（放哪里都行），结尾的 break 纯属惯例

## 3.5 while 与 for 循环

for 与 while 在 C 中直接等价：

```c
for (expr1; expr2; expr3)
    statement
```

等价于

```c
expr1;
while (expr2) {
    statement
    expr3;
}
```

当存在简单的初始化和步进时，for 更好——**循环控制语句集中在一起、在循环顶部可见**。最典型的：

```c
 for (i = 0; i < n; i++)
       ...
```

是处理数组前 n 个元素的 C 惯用法，类似 Fortran 的 DO 循环或 Pascal 的 for。但类比并不完全：for 终止后索引变量 i 保留其值。

for 的三个组成部分都是任意表达式，因此不限于算术级数。不过，把无关的计算塞进 for 的初始化与步进是坏风格——这两处应留给循环控制。

跳过前导空白并转换数字的 atoi 第二版：

```c
#include <ctype.h>

/* atoi:  convert s to integer; version 2 */
int atoi(char s[]) {
    int i, n, sign;
    for (i = 0; isspace(s[i]); i++)  /* skip white space */
        ;
    sign = (s[i] == '-') ? -1 : 1;
    if (s[i] == '+' || s[i] == '-')  /* skip sign */
        i++;
    for (n = 0; isdigit(s[i]); i++)
        n = 10 * n + (s[i] - '0');
    return sign * n;
}
```

标准库提供了功能更完备的 strtol，用于把字符串转换为 long 整数。

循环控制集中化的好处在多重嵌套循环中更明显。希尔排序(Shell sort)——1959 年由 D. L. Shell 发明，先比较相距较远的元素逐步缩小间隔：

```c
/* shellsort:  sort v[0]...v[n-1] into increasing order */
void shellsort(int v[], int n) {
    int gap, i, j, temp;
    for (gap = n / 2; gap > 0; gap /= 2)
        for (i = gap; i < n; i++)
            for (j = i - gap; j >= 0 && v[j] > v[j + gap]; j -= gap) {
                temp = v[j];
                v[j] = v[j + gap];
                v[j + gap] = temp;
            }

}
```

C 还有一个**逗号运算符**，最常见的用处正在 for 语句中：被逗号分隔的一对表达式从左到右求值，结果的类型和值取右操作数。原地反转字符串的 reverse：

```c
#include <string.h>

/* reverse:  reverse string s in place */
void reverse(char s[]) {
    int c, i, j;
    for (i = 0, j = strlen(s) - 1; i < j; i++, j--) {
        c = s[i];
        s[i] = s[j];
        s[j] = c;
    }
}
```

注意区分：分隔函数参数、声明中变量的逗号**不是**逗号运算符，不保证从左到右求值。逗号运算符应节制使用，最合适的场合是强相关的构造，如 reverse 的 for，以及需要把多步计算并成一个表达式的宏。元素交换也可以用逗号表达式写成单一操作：

```c
  for (int i = 0, j = strlen(s) - 1; i < j; i++, j--)
        c = s[i], s[i] = s[j], s[j] = c;
```

## 3.6 do-while 循环

while 与 for 都在**循环顶部**测试终止条件；do-while 在**底部**测试——每轮执行完循环体后才测试，因此**循环体至少执行一次**：

```c
do
    statement
while (expression);
```

先执行 statement，再求 expression：为真则再来一轮，为假则退出。把数字转换为字符串的 itoa：

```c
/* itoa:  convert n to characters in s */
void itoa(int n, char s[]) {
    int i, sign;
    if ((sign = n) < 0)  /* record sign */
        n = -n;          /* make n positive */
    i = 0;
    do {      /* generate digits in reverse order */
        s[i++] = n % 10 + '0'; /*getnextdigit*/
    } while ((n /= 10) > 0);
    if (sign < 0)
        s[i++] = '-';
    s[i] = '\0';
    reverse(s);
}
```

这里必须用 do-while（至少是它最方便）：即使 n 为 0，数组 s 中也至少要生成一个数字。

## 3.7 break 与 continue

**break** 语句提供从 for、while、do 中提前退出的手段（就像从 switch 退出一样），使最内层包围循环或 switch 立即终止：

```c
/* trim:  remove trailing blanks, tabs, newlines */
int trim(char s[]) {
    int n;
    for (n = strlen(s) - 1; n >= 0; n--)
        if (s[n] != ' ' && s[n] != '\t' && s[n] != '\n')
            break;
    s[n + 1] = '\0';
    return n;
}
```

strlen 返回字符串长度，for 循环从末尾向前找第一个非空白字符，break 提前结束循环。注意"半途而废"的循环退出往往说明该用 break；循环底部测试则用 while 更自然。

**continue** 与 break 相关但少用：它让最内层包围的 for、while、do **开始下一轮迭代**（对 while/do 意味着直接跳到测试部分；对 for 跳到步进部分）。continue 只作用于循环，不作用于 switch：

```c
 for (i = 0; i < n; i++)
       if (a[i] < 0)   /* skip negative elements */
           continue;
       ... /* do positive elements */
```

## 3.8 goto 语句与标号

C 提供了人人唾弃却无法弃绝的 goto 及其搭档**标号**(label)。理论上 goto 没有必要，实践中几乎总能写出无 goto 的更清晰的程序。但个别场景 goto 有其一席之地——最常见的是**从深层嵌套中跳出**，比如一次跳出两层循环（break 只能退出最内层）：

```c
for ( ... )
    for ( ... ) {
        ...
        if (disaster)
            goto error;
    }
    ...
error:
    /* clean up the mess */
```

当错误处理代码不简单、且错误可能发生在多处时，这种组织方式很方便。

```c
      for (i = 0; i < n; i++)
           for (j = 0; j < m; j++)
               if (a[i] == b[j])
                   goto found;
       /* didn't find any common element */
...
found:
       /* got one: a[i] == b[j] */
       ...
```

（上例若不用 goto，需要引入额外标志变量并在两处循环中测试。）除此之外，几乎不应使用 goto。
