## 7.1 标准输入/输出

最简单的输入机制是用 `getchar` 每次从**标准输入**(standard input，通常是键盘)读一个字符：

```c
int getchar(void)
```

`getchar` 每次调用返回下一个输入字符，遇到文件结束返回 EOF。符号常量 EOF 定义在 `<stdio.h>`，典型值是 -1，但测试应写成 `EOF` 的形式以便独立于具体值。

许多环境中，用 `<` 约定做**输入重定向**可以让文件代替键盘：若程序 prog 使用 getchar，命令行

```c
prog <infile
```

使 prog 改从 infile 读字符。切换的方式让 prog 对变化毫无察觉——特别是字符串 `<infile` 不出现在命令行参数 argv 中。输入来自另一个程序的**管道**(pipe)机制时同样察觉不到：在有些系统上

```c
  otherprog | prog
```

同时运行两个程序，把 otherprog 的标准输出接入 prog 的标准输入。

输出函数

```c
int putchar(int)
```

把字符 c 放上**标准输出**(standard output)，默认是屏幕。putchar 返回写出的字符，出错返回 EOF。输出通常也可重定向到文件：prog 使用 putchar 时，

```c
prog >outfile
```

把标准输出写进 outfile。支持管道时，

```c
prog | anotherprog
```

把 prog 的标准输出接入 anotherprog 的标准输入。

`printf` 的输出同样进标准输出。putchar 与 printf 的调用可以交错——输出按调用次序产生。引用输入/输出库函数的每个源文件，在首次引用前必须包含：

```c
 #include <stdio.h>
```

名字用尖括号括起时，在标准位置集合中搜索头文件（UNIX 系统通常在 `/usr/include`）。

许多程序只读一个输入流、写一个输出流，对它们来说 getchar、putchar、printf 完全够用——尤其在重定向把一个程序的输出接到下一个程序的输入时。例如把输入转换为小写的程序 lower：

```c
#include <stdio.h>
#include <ctype.h>

main() /* lower: convert input to lower case*/
{
    int c;
    while ((c = getchar()) != EOF)
        putchar(tolower(c));
    return 0;
}
```

`tolower` 定义在 `<ctype.h>`：把大写字母转换为小写，其他字符原样返回。`<stdio.h>` 的 getchar、putchar 与 `<ctype.h>` 的 tolower 这类"函数"常实现为**宏**，避免每字符一次的函数调用开销。不管 `<ctype.h>` 函数在特定机器上如何实现，使用它们的程序都与字符集细节隔离。

## 7.2 格式化输出——printf 函数

输出函数 printf 把内部值转换为字符。前面各章已非正式地用过，这里覆盖多数典型用法（完整描述见附录 B）：

```c
int printf(char *format, arg1, arg2, ...);
```

printf 在**格式串**控制下转换、格式化参数并打印到标准输出，返回打印的字符数。

格式串含两类对象：**普通字符**（原样拷贝到输出流）与**转换说明**（每个引起对下一个参数的转换和打印）。每个转换说明以 `%` 开始、以**转换字符**结束。两者之间按序可以有：

- **减号**：指定转换后的参数左对齐
- **数字**：最小字段宽度。转换后的参数至少打印在这么宽的字段中，不足时左侧（左对齐时为右侧）填充
- **句点**：分隔字段宽度与精度
- **数字（精度）**：字符串的最大打印字符数；浮点数小数点后的位数；整数的最少数字位数
- `h`：整数按 short 打印；`l`（字母 ell）：按 long 打印

转换字符如下。`%` 后若不是转换说明，行为未定义：

| 字符 | 参数类型；打印形式 |
| :---: | --- |
| d,i |int；十进制数 |
| o | int；无符号八进制数（不带前导零）|
| x,X | int；无符号十六进制数（不带前导 0x 或 0X），10～15 用 abcdef 或 ABCDEF |
| u | int；无符号十进制数|
| c | int；单个字符|
| s | `char *`；打印字符串中的字符直到 `'\0'` 或精度指定的字符数|
| f | double；[-]m.dddddd，d 的个数由精度给定（默认 6）|
| e,E | double；[-]m.dddddde+/-xx 或 [-]m.ddddddE+/-xx，d 的个数由精度给定（默认 6）|
| g,G | double；指数小于 -4 或大于等于精度时用 %e 或 %E，否则用 %f；不打印尾随零和尾随小数点|
| p | `void *`；指针（表示形式依赖实现）|
| % | 不转换参数；打印一个 % |

宽度或精度可用 `*` 指定，其值由转换下一个参数（必须是 int）得到。例如从字符串 s 打印**至多 max 个字符**：

```c
 printf("%.*s", max, s);
```

多数格式转换前面各章已演示，例外是**精度对字符串的作用**。下表是打印 "hello, world"（12 个字符）时各种说明的效果，字段两侧加冒号以便看清范围：

```c
   :%s:          :hello, world:
   :%10s:        :hello, world:
   :%.10s:       :hello, wor:
   :%-10s:       :hello, world:
   :%.15s:       :hello, world:
   :%-15s:       :hello, world   :
   :%15.10s:     :     hello, wor:
   :%-15.10s:    :hello, wor     :
```

警告：printf 靠第一个参数决定后面有几个参数、各是什么类型——参数不够或类型不对，它会糊涂、你会得到错误答案。还要注意这两种调用的区别：

```c
   printf(s);         /* FAILS if s contains % */
   printf("%s", s);   /* SAFE */
```

`sprintf` 做与 printf 相同的转换，但把输出存进字符串：

```c
int sprintf(char *string, char *format, arg1, arg2, ...);
```

它按 format 格式化参数后放入 string 而非标准输出；string 必须足够大以容纳结果。

## 7.3 变长参数表

本节实现一个最小版本的 printf，展示如何**以可移植的方式编写处理变长参数表的函数**。主要关注参数处理，minprintf 只解析格式串与参数，格式转换仍交给真正的 printf。

printf 的恰当声明是

```c
int printf(char *fmt, ...)
```

`...` 表示这些参数的个数与类型可变，且只能出现在参数表末尾。minprintf 声明为

```c
void minprintf(char *fmt, ...)
```

（不返回 printf 那样的字符计数）。

棘手之处：参数表连名字都没有，minprintf 怎么沿着它走？标准头 `<stdarg.h>` 含一组宏定义，规定如何遍历参数表。实现因机器而异，但接口统一。

类型 `va_list` 声明一个依次指向各参数的变量——minprintf 中叫 ap（argument pointer，参数指针）。宏 `va_start` 把 ap 初始化为指向**第一个无名参数**，必须在 ap 使用前调用一次；必须至少有一个有名参数，最后那个有名参数被 va_start 用作起点。

每次调用 `va_arg` 返回一个参数并把 ap 推进到下一个；va_arg 靠**类型名**确定返回什么类型、步进多大。最后 `va_end` 做必要的清理，必须在函数返回前调用。

这些性质构成简化版 printf 的基础：

```c
#include <stdarg.h>

/* minprintf: minimal printf with variable argument list */
void minprintf(char *fmt, ...) {
    va_list ap; /* points to each unnamed arg in turn */
    char *p, *sval;
    int ival;
    double dval;
    va_start(ap, fmt); /* make ap point to 1st unnamed arg */
    for (p = fmt; *p; p++) {
        if (*p != '%') {
            putchar(*p);
            continue;
        }
        switch (*++p) {
            case 'd':
                ival = va_arg(ap, int);
                printf("%d", ival);
                break;
            case 'f':
                dval = va_arg(ap, double);
                printf("%f", dval);
                break;
            case 's':
                for (sval = va_arg(ap, char *); *sval; sval++)
                    putchar(*sval);
                break;
            default:
                putchar(*p);
                break;
        }
    }
    va_end(ap); /* clean up when done */
}
```

## 7.4 格式化输入——scanf 函数

`scanf` 是 printf 的输入对偶，反方向提供许多相同的转换设施：

```c
int scanf(char *format, ...)
```

scanf 从标准输入读字符，按 format 中的说明解释它们，并把结果通过其余参数存储。其余参数**每个都必须是指针**，指出转换后的输入存在哪里。

scanf 在格式串用尽、或某段输入与控制说明匹配失败时停止，返回值是**成功匹配并赋值的输入项数**，可用来确定找到了几项；文件结束返回 EOF——注意它与 0 不同，0 表示下一个输入字符与格式串第一个说明不匹配。下一次 scanf 调用从最后一个已转换字符的紧后面继续。

还有从字符串而非标准输入读取的 `sscanf`：

```c
int sscanf(char *string, char *format, arg1, arg2, ...)
```

它按 format 扫描字符串 string，结果通过 arg1、arg2 等存储，这些参数同样必须是指针。

格式串通常含转换说明，控制输入的转换。格式串中可以出现：

- **空白或制表符**：不是被忽略的——它们与输入中的任意空白（包括无）匹配
- **普通字符（非 %）**：期望与输入流的下一个非空白字符匹配
- **转换说明**：字符 %、可选的赋值抑制字符 `*`、可选的最大字段宽度数字、可选的表示目标宽度的 `h、l 或 L`、转换字符

转换说明指挥下一个输入字段的转换。通常结果放入对应参数指向的变量；若用 `*` 指示**赋值抑制**，输入字段被跳过、不赋值。**输入字段**定义为非空白字符的序列，到下一个空白字符、或指定的字段宽度耗尽为止。空白包括空格、制表、换行、回车、垂直制表、换页——这意味着 scanf 会跨行寻找输入。

转换字符指明输入字段的解释方式；对应参数必须是指针——这是 C 传值语义的要求：

| 字符 | 输入数据；参数类型|
| :---: | --- |
| d | 十进制整数；`int *` |
| i | 整数；`int *`。可以是八进制（前导 0）或十六进制（前导 0x 或 0X） |
| o | 八进制整数（带或不带前导零）；int * |
| u | 无符号十进制整数；unsigned int * |
| c | 字符；`char *`。接下来的输入字符（默认 1 个）放入指定位置；通常的跳过空白被抑制，要读下一个非空白字符用 %1s |
| s | 字符串（不带引号）；`char *`，指向足够长的字符数组，结尾自动加 `'\0'` |
| e,f,g| 带可选符号、可选小数点、可选指数的浮点数；float * |
| % | 字面 %；不做赋值 |

转换字符 d、i、o、u、x 前可加 `h` 表示参数表中出现指向 short 的指针，或加 `l`（字母 ell）表示指向 long 的指针。

第一个例子，第 4 章的简陋计算器改用 scanf 做输入转换：

```c
#include <stdio.h>

main()  /* rudimentary calculator */
{
    double sum, v;
    sum = 0;
    while (scanf("%lf", &v) == 1)
        printf("\t%.2f\n", sum += v);
    return 0;
}
```

假设要读形如

```c
25 Dec 1988
```

的日期输入行，scanf 语句为

```c
   int day, year;
   char monthname[20];
   scanf("%d %s %d", &day, monthname, &year);
```

monthname 不用 `&`——数组名本身就是指针。

字面字符可以出现在 scanf 格式串中，必须与输入中的相同字符匹配。读 `mm/dd/yy` 形式的日期：

```c
   int day, month, year;
   scanf("%d/%d/%d", &month, &day, &year);
```

scanf 忽略格式串中的空白和制表符，寻找输入值时还会跳过空白。输入格式不固定时，最好**一次读一行，再用 sscanf 拆解**。比如行可能含上述两种日期形式之一：

```c
  while (getline(line, sizeof(line)) > 0) {
       if (sscanf(line, "%d %s %d", &day, monthname, &year) == 3)
           printf("valid: %s\n", line); /* 25 Dec 1988 form */
       else if (sscanf(line, "%d/%d/%d", &month, &day, &year) == 3)
           printf("valid: %s\n", line); /* mm/dd/yy form */
       else
           printf("invalid: %s\n", line); /* invalid form */
}
```

scanf 可以与其他输入函数混用：任何输入函数的下一次调用都从 scanf 未读的第一个字符开始。

最后的警告：**scanf 与 sscanf 的参数必须是指针**。最最常见的错误是把

```c
 scanf("%d", n);
```

写成（应为）：

```c
 scanf("%d", &n);
```

这个错误编译期一般查不出来。

## 7.5 文件访问

到此为止的例子都读标准输入、写标准输出——它们由本地操作系统自动为程序定义。

下一步是编写访问**未连接到程序**的文件的程序。说明这种需求的程序是 `cat`——**把一组指定文件拼接**到标准输出。cat 用于在屏幕上打印文件，也作为不能按名访问文件的程序的通用输入收集器。命令

```c
cat x.c y.c
```

把文件 x.c 和 y.c 的内容（且仅此）打印到标准输出。

问题是如何安排对指定文件的读取——即如何把用户所知的外部名字与读数据的语句连接起来。

规则很简单。文件读写前必须由库函数 `fopen` **打开**。fopen 接收 x.c、y.c 这样的外部名字，做些与操作系统的内务协商（细节不必关心），返回供后续读写使用的指针。

这个指针称**文件指针**(file pointer)，指向一个含文件信息的结构：缓冲区位置、缓冲区中的当前字符位置、文件在读还是写、是否出错或遇文件结束等。用户无需知道细节——`<stdio.h>` 的定义包含一个叫 `FILE` 的结构声明。文件指针只需这样声明：

```c
   FILE *fp;
   FILE *fopen(char *name, char *mode);
```

说明 fp 是指向 FILE 的指针，fopen 返回指向 FILE 的指针。注意 **FILE 是类型名**（像 int），不是结构标记——它是用 typedef 定义的（fopen 在 UNIX 上的实现细节见 8.5 节）。

程序中调用 fopen 的形式：

```c
fp = fopen(name, mode);
```

第一个参数是含文件名的字符串；第二个是**模式**——同样为字符串，指明打算如何使用文件。允许的模式有**读 "r"**、**写 "w"**、**追加 "a"**。有的系统区分文本与二进制文件，后者要在模式串后加 "b"。

以写或追加方式打开不存在的文件时（可能的话）会创建它；以写方式打开已存在的文件会**丢弃旧内容**，追加方式则保留。读一个不存在的文件是错误，还有其他错误原因（如无权限读取）。任何错误发生时 fopen 返回 NULL。

文件打开后需要读写手段。`getc` 返回文件的下一个字符，它需要文件指针告诉它是哪个文件：

```c
int getc(FILE *fp)
```

getc 返回 fp 所指流的下一个字符，文件结束或出错返回 EOF。putc 是输出函数：

```c
int putc(int c, FILE *fp)
```

putc 把字符 c 写入文件 fp，返回写出的字符，出错返回 EOF。与 getchar、putchar 一样，getc、putc 可以是宏而非函数。

C 程序启动时，操作系统环境负责打开三个文件并提供指针：**标准输入、标准输出、标准错误**；对应文件指针是 `stdin、stdout、stderr`，声明在 `<stdio.h>`。通常 stdin 连键盘、stdout 和 stderr 连屏幕，但 stdin 和 stdout 可按 7.1 节重定向到文件或管道。

getchar 和 putchar 可以用 getc、putc、stdin、stdout 定义：

```c
   #define getchar()    getc(stdin)
   #define putchar(c)   putc((c), stdout)
```

文件的格式化输入输出用 `fscanf` 与 `fprintf`——与 scanf、printf 相同，只是第一个参数是指明读写文件的文件指针，格式串是第二个参数：

```c
   int fscanf(FILE *fp, char *format, ...)
   int fprintf(FILE *fp, char *format, ...)
```

准备就绪，可以写**拼接文件的 cat** 了。设计对许多程序都方便：有命令行参数就按序把它们解释为文件名处理；没有参数就处理标准输入：

```c
#include <stdio.h>

/* cat:  concatenate files, version 1 */
main(int argc, char *argv[]) {
    FILE *fp;
    void filecopy(FILE *, FILE *);
    if (argc == 1) /* no args; copy standard input */
        filecopy(stdin, stdout);
    else
        while (--argc > 0)
            if ((fp = fopen(*++argv, "r")) == NULL) {
                printf("cat: can't open %s\n", *argv);
                return 1;
            } else {
                filecopy(fp, stdout);
                fclose(fp);
            }
    return 0;
}

/* filecopy:  copy file ifp to file ofp */
void filecopy(FILE *ifp, FILE *ofp) {
    int c;
    while ((c = getc(ifp)) != EOF)
        putc(c, ofp);
}
```

`stdin`、`stdout` 是 FILE * 类型的对象，但它们是**常量而非变量**，不能对它们赋值。函数

```c
int fclose(FILE *fp)
```

是 fopen 的逆操作：断开文件指针与外部名字的连接，释放文件指针供其他文件使用。多数操作系统对程序同时打开的文件数有限制，文件指针不再需要时及时释放是好习惯（如 cat 中所做）。对输出文件 fclose 还有另一个理由——**冲刷 putc 收集输出的缓冲区**。程序正常终止时对每个打开的文件自动调用 fclose。（不需要时可以关闭 stdin 和 stdout；它们也可被库函数 freopen 重新指派。）

## 7.6 错误处理——stderr 和 exit

cat 的错误处理不理想：某个文件因故不能访问时，诊断信息出现在拼接输出的末尾。输出到屏幕或许可以接受，进入文件或管道就不行了。

更好地处理这种情形：像 stdin、stdout 一样，为程序分配**第二个输出流 stderr**。即使标准输出被重定向，写到 stderr 的输出通常也出现在屏幕上。

把 cat 改为把错误信息写往标准错误：

```c
#include <stdio.h>

/* cat:  concatenate files, version 2 */
main(int argc, char *argv[]) {
    FILE *fp;
    void filecopy(FILE *, FILE *);
    char *prog = argv[0];  /* program name for errors */
    if (argc == 1) /* no args; copy standard input */
        filecopy(stdin, stdout);
    else
        while (--argc > 0)
            if ((fp = fopen(*++argv, "r")) == NULL) {
                fprintf(stderr, "%s: can't open %s\n",prog, *argv);
                exit(1);
            } else {
                filecopy(fp, stdout);
                fclose(fp);
            }
    if (ferror(stdout)) {
        fprintf(stderr, "%s: error writing stdout\n", prog);
        exit(2);
    }
    exit(0);
}
```

程序以两种方式报告错误。其一，fprintf 的诊断输出进入 stderr，因而到达屏幕而不是消失在管道或输出文件里；信息中带上了来自 `argv[0]` 的程序名，程序与其他程序配合使用时能识别错误来源。

其二，程序用标准库函数 `exit` 终止执行。exit 的参数可供调用本程序的进程使用——本程序的成功或失败可被把它当作子进程的另一个程序检测。惯例：**0 表示一切正常，非 0 表示异常**。exit 对每个打开的输出文件调用 fclose，冲刷缓冲的输出。

main 内 `return expr` 等价于 `exit(expr)`。exit 的优势是**可以从其他函数调用**，而且对它的调用可以用第 5 章那样的模式搜索程序找到。

函数 `ferror` 在流 fp 上发生错误时返回非零：

```c
   int ferror(FILE *fp)
```

输出错误虽少见但存在（如磁盘写满），正式程序应该检查。`feof(FILE *)` 与 ferror 类似，指定文件上遇到文件结束时返回非零：

```c
   int feof(FILE *fp)
```

小型示例程序中我们一般不操心退出状态，但任何严肃的程序都应返回合理、有用的状态值。

## 7.7 行输入与行输出

标准库提供了与前面各章自写的 getline 类似的输入输出例程 `fgets`：

```c
char *fgets(char *line, int maxline, FILE *fp)
```

fgets 从文件 fp 读下一输入行（**含换行符**）到字符数组 line，至多读 maxline-1 个字符，结果以 `\0` 结尾。正常时返回 line，文件结束或出错返回 NULL。（我们自写的 getline 返回行长——更有用的值，0 表示文件结束。）

输出方面，`fputs` 把字符串（不必含换行符）写入文件：

```c
int fputs(char *line, FILE *fp)
```

出错返回 EOF，否则返回非负。

库函数 gets 与 puts 类似 fgets、fputs，但操作于 **stdin 和 stdout**。易混淆的是：gets 删除结尾的 `'\n'`，puts 则添加它。

为说明 fgets、fputs 这类函数没什么特别，下面是从系统标准库拷来的实现：

```c
/* fgets:  get at most n chars from iop */
char *fgets(char *s, int n, FILE *iop) {
    register int c;
    register char *cs;
    cs = s;
    while (--n > 0 && (c = getc(iop)) != EOF)
        if ((*cs++ = c) == '\n')
            break;
    *cs = '\0';
    return (c == EOF && cs == s) ? NULL : s;
}

/* fputs:  put string s on file iop */
int fputs(char *s, FILE *iop) {
    int c;
    while (c = *s++)
        putc(c, iop);
    return ferror(iop) ? EOF : 0;
}
```

不知出于什么原因，标准对 ferror 与 fputs 规定了不同的返回值。用 fgets 实现我们的 getline 很容易：

```c
/* getline:  read a line, return length */
int getline(char *line, int max) {
    if (fgets(line, max, stdin) == NULL)
        return 0;
    else
        return strlen(line);
}
```

### 字符串操作

```c
strrchr(s,c)    return pointer to last c in s, or NULL if not present
```

### 字符类测试与转换

`<ctype.h>` 中若干函数做字符测试与转换。下面 c 是可表示为 unsigned char 或 EOF 的 int，函数返回 int：

```c
isalpha(c) non-zero if c is alphabetic, 0 if not
```

### ungetc

标准库提供了第 4 章自写的 ungetch 的受限版本，叫 ungetc：

```c
int ungetc(int c, FILE *fp)
```

把字符 c 压回文件 fp，返回 c，出错返回 EOF。每个文件**只保证一个字符的回退**。ungetc 可与 scanf、getc、getchar 等任何输入函数配合使用。

### 命令执行

函数 `system(char *s)` 执行字符串 s 中的命令，然后恢复当前程序的执行。s 的内容强烈依赖本地操作系统。UNIX 系统上的一个简单例子：

```c
system("date");
```

运行程序 date，把日期和时间打印到标准输出。system 返回依赖系统的整数状态；UNIX 上该状态就是被执行命令 exit 的返回值。

### 存储管理

函数 `malloc` 与 `calloc` 动态获取内存块：

```c
void *malloc(size_t n)
```

返回指向 n 字节**未初始化**存储的指针，无法满足请求时返回 NULL。

```c
void *calloc(size_t n, size_t size)
```

返回足够存放 n 个指定大小对象的数组的空间指针，无法满足时返回 NULL，**存储初始化为零**。

malloc、calloc 返回的指针对相应对象有恰当的对齐，但必须 cast 成适当的类型：

```c
int *ip;
ip = (int *) calloc(n, sizeof(int));
```

`free(p)` 释放 p 指向的空间，p 必须得自 malloc 或 calloc。释放的次序没有限制，但**释放并非得自 malloc/calloc 的东西是严重错误**；**释放后再使用**同样是错误。释放链表各项的典型错误代码：

```c
   for (p = head; p != NULL; p = p->next) /* WRONG */
       free(p);
```

正确做法是先保存需要的东西再释放：

```c
for (p = head; p != NULL; p = q) {
    q = p->next;
    free(p);
}
```

8.7 节展示类似 malloc、可按任意次序释放已分配块的存储分配器的实现。

### 随机数生成

函数 rand() 产生 0 到 RAND_MAX（定义在 `<stdlib.h>`）范围内的伪随机整数序列。产生大于等于 0 且小于 1 的随机浮点数的一种方法是：

```c
 #define frand() ((double) rand() / (RAND_MAX+1.0))
```

（若库已提供浮点随机数函数，其统计性质多半比这个好。）

函数 srand(unsigned) 为 rand 设置种子。标准建议的 rand 与 srand 的可移植实现见 2.7 节。
