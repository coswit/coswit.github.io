## IO类

C++ 语言不直接处理输入输出，而是通过标准库中的一组类来处理。这些类构成了庞大的类层次结构，其中大多数在 `iostream`、`fstream`、`sstream` 三个头文件中：

| Header   | Type                                                     |
| -------- | -------------------------------------------------------- |
| iostream | istream、ostream、iostream（w 前缀为宽字符版本）          |
| fstream  | ifstream、ofstream、fstream（文件流，w 前缀为宽字符版本） |
| sstream  | istringstream、ostringstream、stringstream（内存流）      |

IO 类型间的继承关系（用虚基类 `ios_base` 统一管理）：

```
        istream          ostream
       ↙      ↘         ↙      ↘
  ifstream  istringstream  ofstream  ostringstream
```

- `ifstream` 和 `istringstream` 都继承自 `istream`，因此可以把 `ifstream`/`istringstream` 的对象当作 `istream` 使用（如 `cin`）。
- `ofstream` 和 `ostringstream` 都继承自 `ostream`。

### IO对象无拷贝赋值

IO 对象不能拷贝（copy）也不能赋值（assign），因此：

- IO 类型的函数形参/返回类型只能是引用（流对象不可按值传递）。
- 读写一个 IO 对象会改变其状态，因此传递和返回的引用不能是 `const` 的。

```cpp
ofstream out1, out2;
out1 = out2;   // error: 不能对流对象赋值
ofstream print(ofstream); // error: 不能拷贝流对象
ostream print(ostream&); // ok: 传引用
```

### 条件状态

IO 操作可能发生错误，如文件不存在、读到文件尾等。IO 类定义了一些**条件状态（condition state）**的成员和函数：

| Member                | Meaning                                              |
| --------------------- | ---------------------------------------------------- |
| strm::iostate         | 机器相关的整型类型名，提供完整的 IO 状态             |
| strm::badbit          | strm::iostate 类型的值，指出流已崩溃（不可恢复）     |
| strm::failbit         | 指出一个 IO 操作失败了                               |
| strm::eofbit          | 指出流到达了文件结束                                 |
| strm::goodbit         | 指出流未处于错误状态，值保证为 0                     |
| s.eof()               | 流 s 的 eofbit 已置位时返回 true                     |
| s.fail()              | 流 s 的 failbit 或 badbit 已置位时返回 true          |
| s.bad()               | 流 s 的 badbit 已置位时返回 true                     |
| s.good()              | 流 s 处于有效状态时返回 true                         |
| s.clear()             | 将流 s 的所有条件状态复位，恢复为有效状态            |
| s.clear(flags)        | 将流 s 的状态置为 flags（iostate 类型）              |
| s.setstate(flags)     | 为流 s 添加指定条件状态                              |
| s.rdstate()           | 返回流 s 的当前状态，类型为 strm::iostate            |

确定流的状态最简单的方法是把流对象当成条件来使用：

```cpp
while (cin >> word) { /* ... */ } // read until end-of-file or error
```

只有流处于有效状态时，才可以继续读写。badbit 表示系统级错误，一旦置位流通常无法再使用；failbit 通常可以修复。

```cpp
auto old_state = cin.rdstate(); // remember the current state of cin
cin.clear();                    // make cin usable
process_input(cin);             // use cin
cin.setstate(old_state);        // now restore cin's state
```

复位 failbit 和 badbit，但保持其他标志不变：

```cpp
cin.clear(cin.rdstate() & ~cin.failbit & ~cin.badbit);
```

### 管理输出缓冲

每个输出流都管理一个**缓冲区（buffer）**，用来保存程序读写的数据。导致缓冲刷新（数据真正写到输出设备）的原因：

- 程序正常结束，作为 `main` 函数 return 操作的一部分，缓冲刷新被执行。
- 缓冲区满。
- 使用 `endl` 等操纵符（manipulator）显式刷新。
- 一个输出流被关联（tie）到另一个流时，读写被关联的流会导致本流刷新。

```cpp
cout << "hi!" << endl;  // 插入换行，然后刷新缓冲区
cout << "hi!" << flush; // 不附加数据，只刷新缓冲区
cout << "hi!" << ends;  // 插入一个空字符，然后刷新缓冲区
```

unitbuf 操纵符：每次输出操作后都刷新缓冲区；nounitbuf 恢复正常：

```cpp
cout << unitbuf;    // 所有输出操作后都会立即刷新缓冲区
// ...
cout << nounitbuf;  // 回到正常的缓冲方式
```

交互式系统通常将 cin 和 cout 关联（tie）在一起，读 cin 会先刷新 cout。tie 可以被解除或重新关联：

```cpp
cin.tie(&cout);  // 仅作说明：库已将 cin 和 cout 关联在一起
cin.tie(nullptr); // 解除关联
```

## 文件输入输出

头文件 `fstream` 定义了三个支持文件 IO 的类型：`ifstream`（读文件）、`ofstream`（写文件）、`fstream`（读写文件）。

fstream 特有操作：

| Operation            | Meaning                                                       |
| -------------------- | ------------------------------------------------------------- |
| fstream fstrm;       | 创建一个未绑定文件的流                                         |
| fstream fstrm(s);    | 创建 fstrm 并打开名为 s 的文件（string 或 C 风格字符串）        |
| fstream fstrm(s, mode) | 按指定模式打开文件                                             |
| fstrm.open(s)        | 打开名为 s 的文件，与 fstrm 绑定                              |
| fstrm.close()        | 关闭与 fstrm 绑定的文件                                        |
| fstrm.is_open()      | 是否成功打开文件且未关闭，返回 bool                            |

### 使用文件流对象

读取文件名为 s 的文件：

```cpp
ifstream in(ifile);  // 构造一个 ifstream 并打开给定文件
ofstream out;        // 输出文件流，未关联任何文件
```

用 ifstream 代替 cin&ofstream 代替 cout，可以像使用标准流一样使用文件流：

```cpp
ifstream input(argv[1]);   // open the file of sales transactions
ofstream output(argv[2]);  // open the output file
Sales_data total;          // variable to hold the running sum
if (read(input, total)) {  // read the first transaction
    Sales_data trans;      // variable to hold data for the next transaction
    while (read(input, trans)) {          // read the remaining transactions
        if (total.isbn() == trans.isbn()) // check isbns
            total.combine(trans);         // update the running sum
        else {
            output << total << endl; // print the results
            total = trans;           // process the next book
        }
    }
    output << total << endl;         // print the last transaction
} else                               // there was no input
    cerr << "No data?!" << endl;
```

### 成员函数open和close

对一个已打开的流再次调用 open 会失败，并使 failbit 置位。若要重用文件流，须先 close 再 open：

```cpp
ofstream out;            // no file associated yet
out.open(ifile + ".copy"); // open the specified file
if (out)                 // check that the open succeeded
    /* use out */;
out.close();             // close the file
out.open("another");     // open another file
```

当一个 fstream 对象被销毁时，close 会自动被调用，因此简单程序不必显式关闭文件。

### 文件模式

每个流都有一个关联的**文件模式（file mode）**：

| Mode   | Meaning                                              |
| ------ | ---------------------------------------------------- |
| in     | 以读方式打开                                         |
| out    | 以写方式打开                                         |
| app    | 每次写操作前均定位到文件末尾                          |
| ate    | 打开文件后立即定位到文件末尾                          |
| trunc  | 截断文件                                             |
| binary | 以二进制方式进行 IO                                   |

默认模式：

- 与 `ifstream` 关联的文件默认以 in 模式打开。
- 与 `ofstream` 关联的文件默认以 out 模式打开（out 通常也意味着 trunc）。
- 与 `fstream` 关联的文件默认以 in 和 out 模式打开。

保留 ofstream 打开时文件中的已有内容：

```cpp
ofstream app("file2", ofstream::app);  // 隐含为输出模式
app << "made it in, no truncation!" << endl;
ofstream app2("file2", ofstream::out | ofstream::app);
```

每次调用 open 时都可以重新指定文件模式，但同一个流只能同时关联一个文件。

## string流

`sstream` 头文件定义了三个类型来支持内存 IO：`istringstream`（读 string）、`ostringstream`（写 string）、`stringstream`（读写 string）。

sstream 特有操作：

| Operation      | Meaning                                          |
| -------------- | ------------------------------------------------ |
| sstream strm;  | strm 是一个未绑定的 stringstream 对象             |
| sstream strm(s)| strm 保存 string s 的一个拷贝（此构造函数 explicit）|
| strm.str()     | 返回 strm 保存的 string 的拷贝                    |
| strm.str(s)    | 将 string s 拷贝到 strm 中，返回 void             |

### 使用istringstream

当需要处理整行文本，又需要处理行内的单词时，通常用 istringstream：

```cpp
// members are name and phone numbers
struct PersonInfo {
    string name;
    vector<string> phones;
};

string line, word;              // will hold a line and word from input, respectively
vector<PersonInfo> people;      // will hold all the records from the input
// read the input a line at a time until cin hits end-of-file (or another error)
while (getline(cin, line)) {
    PersonInfo info;            // create an object to hold this record's data
    istringstream record(line); // bind record to the line we just read
    record >> info.name;        // read the name
    while (record >> word)      // read the phone numbers
        info.phones.push_back(word);
    people.push_back(info);     // append this record to people
}
```

### 使用ostringstream

当需要逐步构造输出、希望最后一起打印时，用 ostringstream：

```cpp
for (const auto &entry : people) { // for each entry in people
    ostringstream formatted, badNums; // objects created on each iteration
    for (const auto &nums : entry.phones) { // for each number
        if (valid(nums))              // string to represent formatted numbers
            badNums << " " << nums;    // writes to formatted's string
        else                           // string to hold numbers in bad form
            formatted << " " << nums;  // writes to badNums' string
    }
    if (badNums.str().empty())         // there were no bad numbers
        os << entry.name << " "        // print the name
           << formatted.str() << endl; // and reformatted numbers
    else                               // otherwise, print the name and bad numbers
        cerr << "input error: " << entry.name
             << " invalid number(s) " << badNums.str() << endl;
}
```
