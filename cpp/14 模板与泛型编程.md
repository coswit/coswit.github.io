面向对象编程（OOP）和泛型编程（generic programming）都能处理在编写程序时不知道具体类型的情况。不同之处在于：OOP 能处理类型在程序运行之前都未知的情况；而泛型编程中，在编译时就能获知类型了。

容器、迭代器和算法是泛型编程的典型例子：当我们编写一个泛型程序时，是独立于任何特定类型来编写代码的。当使用一个泛型程序时，我们提供具体类型或值，程序实例可在这些类型或值之上运转。

模板（template）是 C++ 中泛型编程的基础。一个模板就是一个创建类或函数的蓝图或者说公式。

## 定义模板

### 函数模板

一个函数模板（function template）就是一个公式，可用来生成针对特定类型的函数版本。compare 的模板版本可能像下面这样：

```cpp
template <typename T>
int compare(const T &v1, const T &v2) {
    if (v1 < v2) return -1;   // 比较 v1 和 v2
    if (v2 < v1) return 1;
    return 0;
}
```

模板定义以关键字 template 开始，后跟**模板参数列表（template parameter list）**，这是一个逗号分隔的一个或多个**模板参数**的列表，用 `<` 和 `>` 包围起来。

模板参数表示在类或函数定义中用到的类型或值。当使用模板时，我们（隐式或显式地）指定**模板实参（template argument）**，并将其绑定到模板参数上。

**实例化函数模板**：当调用一个函数模板时，编译器（通常）用函数实参的类型来为我们推断模板实参。编译器用推断出的模板参数来为我们**实例化（instantiate）**一个特定版本的函数：

```cpp
cout << compare(1, 0) << endl;       // T 为 int
// 实例化出 int compare(const int&, const int&)
vector<int> vec1{1, 2, 3}, vec2{4, 5, 6};
cout << compare(vec1, vec2) << endl; // T 为 vector<int>
// 实例化出 int compare(const vector<int>&, const vector<int>&)
```

这些编译器生成的版本通常被称为**模板的实例（instantiation）**。

**模板类型参数**：类型参数前必须使用关键字 class 或 typename（两者含义相同，可以互换使用）：

```cpp
template <typename T, class U> calc(const T&, const U&);
```

**非类型模板参数（nontype parameter）**：表示一个值而非一个类型。非类型参数可以是整型、指向对象或函数类型的（左值）指针或（左值）引用：

```cpp
template <unsigned N, unsigned M>
int compare(const char (&p1)[N], const char (&p2)[M]) {
    return strcmp(p1, p2);
}
compare("hi", "mom"); // 编译器使用字面常量的大小代替 N 和 M，N=3，M=4
```

函数模板可以声明为 inline 或 constexpr 的，说明符放在模板参数列表之后、返回类型之前：

```cpp
template <typename T> inline T min(const T&, const T&);
```

**编写类型无关的代码**：泛型代码的两个重要原则：

- 模板中的函数参数是 const 引用（保证类型无关，且支持不能拷贝的类型）。
- 函数体中的条件判断仅使用 `<` 比较运算（减少了对类型的要求。如果真想用 >，可以定义为 `if (v2 < v1)` 的形式）。

模板程序应该尽量减少对实参类型的要求。

**模板编译**：当编译器遇到一个模板定义时，并不生成代码。只有当我们实例化出模板的一个特定版本时，编译器才会生成代码。这一特性影响了我们如何组织代码以及错误何时被检测到。

为了保证生成代码的正确性，编译器必须能够看到模板的定义和使用的特定类型。因此模板的头文件通常既包括它的声明也包括它的定义。**函数模板和类模板成员函数的定义通常放在头文件中。**

### 类模板

类模板（class template）是用来生成类的蓝图。与函数模板不同之处是，编译器不能为类模板推断模板参数类型。使用类模板时，必须在模板名后的尖括号中提供额外信息：

```cpp
template <typename T> class Blob {
    // Blob 中的每个类型 T 的实例都是一个类型
public:
    typedef T value_type;
    typedef typename std::vector<T>::size_type size_type;
    // 构造函数
    Blob();
    Blob(std::initializer_list<T> il);
    // Blob 中的元素数目
    size_type size() const { return data->size(); }
    bool empty() const { return data->empty(); }
    // 添加和删除元素
    void push_back(const T &t) { data->push_back(t); }
    void push_back(T &&t) { data->push_back(std::move(t)); }
    void pop_back();
    // 元素访问
    T& back();
    T& operator[](size_type i);
private:
    std::shared_ptr<std::vector<T>> data;
    // 若 data[i] 无效，则抛出 msg
    void check(size_type i, const std::string &msg) const;
};
```

**实例化类模板**：

```cpp
Blob<int> ia;                // 空 Blob<int>
Blob<int> ia2 = {0,1,2,3,4}; // 有 5 个元素的 Blob<int>
vector<int> v1(10, 1), v2{1, 2, 3};
// 错误: 一个 Blob<int> 不能初始化为 vector<int>
// Blob<int> ia3 = v1;
Blob<string> names;          // 空 Blob<string>
```

一个类模板的每个实例都形成一个独立的类。`Blob<string>` 与 `Blob<int>` 或其他任何 Blob 类型都没有关联，也不会对任何其他 Blob 类型的成员有特殊访问权限。

类模板中成员的名字不是一个类型时（如 Blob 中的 data），必须显式告诉编译器这个名字是一个类型，这是通过关键字 typename 来完成的：

```cpp
// 正确: typename 告诉编译器 size_type 是一个类型
typename Blob<T>::size_type Blob<T>::size() const { /* ... */ }
```

**类模板的成员函数**：可以在类模板内部也可以在类模板外部定义成员函数，且定义在类内的成员函数被隐式声明为内联函数。类外定义成员函数必须以关键字 template 开始，后接类模板参数列表：

```cpp
template <typename T>
void Blob<T>::check(size_type i, const std::string &msg) const {
    if (i >= data->size())
        throw std::out_of_range(msg);
}

template <typename T>
T& Blob<T>::back() {
    check(0, "back on empty Blob");
    return data->back();
}

template <typename T>
T& Blob<T>::operator[](size_type i) {
    // 如果 i 太大，check 会抛出异常
    check(i, "subscript out of range");
    return (*data)[i];
}

template <typename T>
void Blob<T>::pop_back() {
    check(0, "pop_back on empty Blob");
    data->pop_back();
}

template <typename T>
Blob<T>::Blob(): data(std::make_shared<std::vector<T>>()) { }

template <typename T>
Blob<T>::Blob(std::initializer_list<T> il):
    data(std::make_shared<std::vector<T>>(il)) { }
```

默认情况下，对于一个实例化了的类模板，其成员函数只有在使用时才被实例化。这一特性使得即使某种类型不能完全符合模板操作的要求，我们仍然能用该类型实例化一个类模板。

**类模板和友元**：当一个类包含一个友元声明时，类与友元各自是否是模板是相互无关的：

```cpp
// 前置声明，在 Blob 中声明友元时需要
template <typename> class BlobPtr;
template <typename> class Blob; // 运算符 == 中的参数需要
template <typename T>
    bool operator==(const Blob<T>&, const Blob<T>&);

template <typename T> class Blob {
    // 每个 Blob 实例将访问权限授予用相同类型实例化的 BlobPtr 和相等运算符
    friend class BlobPtr<T>;
    friend bool operator==<T>(const Blob<T>&, const Blob<T>&);
    // ...
};
```

一对一友好关系：Blob<char> 的友元是 BlobPtr<char> 和 `operator==<char>`。

通用和特定的模板友好关系：一个模板可以把另一个模板的每个实例都声明为自己的友元，或者只声明特定实例为友元。

**模板类型别名**：类模板的一个实例定义了一个类类型，可以定义一个 typedef 来引用其实例：

```cpp
typedef Blob<string> StrBlob;
```

由于模板不是一个类型，我们不能定义一个 typedef 引用 Blob。但新标准允许我们为类模板定义一个**类型别名（type alias）**：

```cpp
template <typename T> using twin = pair<T, T>;
twin<string> authors;     // authors 是一个 pair<string, string>
twin<int> win_loss;       // win_loss 是一个 pair<int, int>
twin<double> area;        // area 是一个 pair<double, double>
```

当我们定义一个模板类型别名时，也可以固定一个或多个模板参数：

```cpp
template <typename T> using partNo = pair<T, unsigned>;
partNo<string> books;  // books 是一个 pair<string, unsigned>
partNo<Vehicle> cars;  // cars 是一个 pair<Vehicle, unsigned>
```

**类模板的 static 成员**：类模板可以像任何其他类一样声明 static 成员。每个 Blob<T> 实例（即每种元素类型的 Blob）都有自己的 static 成员实例：

```cpp
template <typename T>
class Foo {
public:
    static std::size_t ctr() { return ++count; }
private:
    static std::size_t count;
};
// 每个实例化的 Foo<T> 都有各自的 static 成员 count
template <typename T>
size_t Foo<T>::count = 0;  // 定义并初始化 count
```

### 模板参数与函数模板的默认实参

我们可以为类模板和函数模板提供默认实参（default template argument）：

```cpp
// compare 函数的另一个版本，使用 less<T> 进行比较
template <typename T = int> // T 的默认实参是 int
auto compare5(const T &v1, const T &v2) -> int { /* ... */ }
```

类模板的默认模板实参：

```cpp
template <class T = int> class Numbers { // 默认情况下 T 是 int
public:
    Numbers(T v = 0): val(v) { }
    // 对 T 的各种操作
private:
    T val;
};
Numbers<long double> lots_of_precision;
Numbers<> average_precision; // 空 <> 表示使用默认实参
```

## 模板实参推断

对于函数模板，编译器利用调用中的函数实参来确定其模板参数，这个过程称为**模板实参推断（template argument deduction）**。

### 类型转换与模板类型参数

与非模板函数一样，我们在一次调用中传递给函数模板的实参被用来初始化函数的形参。与非模板函数不同的是，在模板调用中会发生很少的转换：编译器通常只对函数实参进行两种转换：

- **const 转换**：可以将一个非 const 对象的引用（或指针）传递给一个 const 引用（或指针）形参。
- **数组或函数到指针的转换**：如果函数形参不是引用类型，则数组实参转换为一个指向其首元素的指针，函数实参转换为函数指针。

其他转换（如算术转换、派生类到基类的转换等）在模板调用中都不会执行：

```cpp
template <typename T> T fobj(T, T);        // 实参被拷贝
template <typename T> T fref(const T&, const T&); // 引用

string s1("a value");
const string s2("another value");
fobj(s1, s2);   // 正确: 调用 fobj(string, string)，const 被忽略
fref(s1, s2);   // 正确: 调用 fref(const string&, const string&)
                // （将 s1 转换为 const 是允许的）
int a[10], b[42];
fobj(a, b);   // 正确: 调用 f(int*, int*)（数组到指针的转换）
// fref(a, b); // 错误: 数组大小不同，形参是引用时数组不会转换为指针
```

使用相同模板参数类型的函数形参，其实参必须类型完全一致。如果推断出的类型不匹配但兼容，则转换不会自动执行：

```cpp
long lng = 1024;
compare(lng, 1024);      // 错误: 不能实例化 compare(long, int)
// 解决方案: 显式指定模板实参或定义两个类型参数
```

### 函数模板显式实参

某些情况下编译器无法推断出模板实参的类型，此时我们必须显式指定模板实参：

```cpp
// 编译器无法推断 T1，它未出现在函数参数列表中
template <typename T1, typename T2, typename T3>
T1 sum(T2, T3);
auto val3 = sum<long long>(i, lng); // 显式指定 T1 为 long long，T2 和 T3 由编译器推断
```

显式模板实参按从左至右的顺序与对应模板参数匹配，只有尾部（最右）参数的显式模板实参才可以忽略（且前提是它们可以从函数参数推断）。因此 `sum<long long>(i, lng)` 指定 T1，剩余参数由推断完成。

正常类型转换应用于显式指定的实参：对于用普通类型定义的函数参数，允许进行正常的类型转换：

```cpp
template <typename T, typename F = less<T>>
bool compare2(const T &v1, const T &v2, F f = F()) {
    if (f(v1, v2)) return -1;
    if (f(v2, v1)) return 1;
    return 0;
}
bool i = compare2(0, 42); // 使用 less<int>，i 为 -1
// 错误: 两个实参类型不同
// bool j = compare2("hi", "world"); // T 推断冲突（const char[3] 和 const char[6]）
bool k = compare2<string>("hi", "world"); // T 显式指定为 string，实参进行正常转换
```

### 尾置返回类型与类型转换

当函数的返回类型依赖于模板参数时，可以让编译器通过尾置返回类型来推断：

```cpp
// 尾置返回允许我们在参数列表之后声明返回类型
template <typename It>
auto fcn(It beg, It end) -> decltype(*beg) {
    // 处理整个范围
    return *beg; // 返回序列中第一个元素的引用
}
```

此例中，`decltype(*beg)` 返回元素类型的引用。当我们解引用一个迭代器时，得到的是一个指向该迭代器所表示元素的引用，因此函数返回类型是引用类型。如果想要返回元素的值而非引用，可以使用标准库的类型转换模板 remove_reference（定义在 type_traits 头文件中）：

```cpp
// 为了使用模板参数的成员，必须使用 typename
template <typename It>
auto fcn2(It beg, It end) ->
    typename remove_reference<decltype(*beg)>::type {
    // 处理整个范围
    return *beg; // 返回序列中第一个元素的拷贝
}
```

标准库在 type_traits 中定义了一组转换模板，成员 type 表示转换后的类型：

| 模板                        | 转换效果                          |
| --------------------------- | --------------------------------- |
| remove_reference<T>         | 去掉引用，得到 T 本身              |
| remove_const<T>             | 去掉 const                        |
| add_const<T>                | 得到 const T                      |
| add_lvalue_reference<T>     | 得到 T&                           |
| add_rvalue_reference<T>     | 得到 T&&                          |
| remove_pointer<T>           | 得到 T（去掉指针）                 |
| add_pointer<T>              | 得到 T*                           |
| make_signed<T>              | 得到对应的带符号类型               |
| make_unsigned<T>            | 得到对应的无符号类型               |
| decay<T>                    | 得到「按值传递」的退化类型          |

### 函数指针和实参推断

当我们用一个函数模板初始化一个函数指针或为一个函数指针赋值时，编译器使用指针的类型来推断模板实参：

```cpp
template <typename T> int compare(const T&, const T&);
// pf1 指向 compare(const int&, const int&)
int (*pf1)(const int&, const int&) = compare;
// pf2 中，T 的类型无法确定，推断失败
// func 的重载版本必须都唯一匹配某个 compare 实例
```

如果从函数指针的类型中无法确定模板实参，则推断失败。

### 模板实参推断和引用

为了理解如何从引用类型的函数参数推断类型，必须理解「间接引用」的两条规则：

**引用折叠和右值引用参数**：

```cpp
template <typename T> void f(T &);  // T 的类型被推断为 int
template <typename T> void f2(const T&); // T 的类型被推断为 int
template <typename T> void f3(T&&); // T 的类型可以是 int&、int&& 等
```

- 当我们传递一个左值（如变量 i）给 f(T&) 时，T 被推断为 int。
- 当传递一个 const 对象给 f2(const T&) 时，T 被推断为「底层 const 被忽略」的类型。
- 传递右值引用时，如果实参是一个左值，则 T 被推断为左值引用类型（引用折叠发生）。

**引用折叠规则（reference collapsing）**（仅用于模板推断、typedef、auto&&、decltype）：

- X& &、X& &&、X&& & 都折叠为 X&
- X&& && 折叠为 X&&

**接受左值和右值的转发引用**：函数参数是一个指向模板参数类型的右值引用（T&&）时，若实参是左值，则 T 被推断为左值引用类型，函数参数经引用折叠变为左值引用。因此，`template <typename T> void f(T&&)` 既能接受左值也能接受右值，这样的参数称为转发引用（forwarding reference）：

```cpp
template <typename T> void f(T&& val) { /* ... */ }
f(42);   // 42 是右值，T 为 int，val 的类型是 int&&
int i = 42;
f(i);    // i 是左值，T 为 int&，val 的类型是 int&（引用折叠）
```

**理解std::move**：标准库 move 函数是使用转发引用和引用折叠的一个绝佳例子：

```cpp
// std::move 的简化实现
template <typename T>
typename remove_reference<T>::type&& move(T&& t) {
    // static_cast 的结果是一个右值引用，从而实现「移动」语义
    return static_cast<typename remove_reference<T>::type&&>(t);
}
```

move 的工作机制：

- 传递一个左值 string s 时，推断 T 为 string&，`remove_reference` 得到 string，返回 `string&&`。
- 传递一个右值（如 string 的字面值或临时对象）时，推断 T 为 string，返回 `string&&`。

从一个左值 static_cast 到一个右值引用是允许的，这是 move 的核心。

**从左值 static_cast 到一个右值引用是允许的**，因此我们可以显式地将一个左值转换为一个右值引用。

### 转发

某些函数需要将其一个或多个实参连同类型不变地转发给其他函数。在此情况下，我们需要保持被转发实参的所有性质，包括实参类型是否是 const 的以及实参是左值还是右值：

```cpp
// 接受一个可调用对象和另外两个参数的模板
// 对 flip 而言，「翻转」可调用对象的参数
template <typename F, typename T1, typename T2>
void flip1(F f, T1 t1, T2 t2) {
    f(t2, t1);
}
void f(int v1, int &v2) { /* ... */ } // 注意: v2 是引用
int i = 0;
f(42, i);   // f 改变了 i
flip1(f, 42, i); // f 通过 flip1 调用，但 flip1 拷贝了 i，f 不会改变 i
```

flip1 的问题是 t1、t2 是按值传递的，丢失了引用语义。将参数定义为引用可以解决：

```cpp
template <typename F, typename T1, typename T2>
void flip2(F f, T1 &&t1, T2 &&t2) {
    f(t2, t1);
}
flip2(f, 42, i); // 正确: i 被 f 改变
```

flip2 适用于接受左值引用的函数，但如果 f 的参数是右值引用，flip2 传给 f 的（通过命名变量 t2）是左值，仍不完美。新标准库中定义了 forward 函数（定义在 utility 中）来解决这个问题：

```cpp
template <typename F, typename T1, typename T2>
void flip(F f, T1 &&t1, T2 &&t2) {
    f(std::forward<T2>(t2), std::forward<T1>(t1));
}
```

当用于一个指向模板参数类型的右值引用的函数参数（T&&）时，forward 会保持实参类型的所有细节：

- 如果实参是右值，forward<T> 返回 T&&（右值引用）。
- 如果实参是左值，forward<T> 通过引用折叠返回 T&（左值引用）。

与 move 不同，必须通过显式模板实参的形式调用 forward。使用 forward 通常意味着传递给其他函数的实参是通过「转发引用」接收的。

## 重载与模板

函数模板可以被另一个模板或一个普通非模板函数重载。如果设计恰当，重载的函数集合可以混合使用模板函数与非模板函数。

名字与作用域：与往常一样，如果重载函数集合中的某个名字对应的函数都是模板，则选择「最特化（more specialized）」的版本，而非最通用的版本：

```cpp
template <typename T> string debug_rep(const T &t) {
    ostringstream ret;
    ret << t; // 使用 T 的输出运算符打印 t 的一个表示形式
    return ret.str(); // 返回 ret 绑定的 string 的一个拷贝
}
// 打印指针的版本，比上一个版本更特化
template <typename T> string debug_rep(T *p) {
    ostringstream ret;
    ret << "pointer: " << p;      // 打印指针自身的值
    if (p)
        ret << " " << debug_rep(*p); // 打印 p 指向的值
    else
        ret << " null pointer";   // 或指出 p 为空
    return ret.str();             // 返回 ret 绑定的 string 的一个拷贝
}
string s("hi");
cout << debug_rep(s) << endl;      // 调用第一个版本（T 为 string）
cout << debug_rep(&s) << endl;     // 调用第二个版本（T 为 string*），比第一个更特化
```

当存在多个同样匹配的版本时，编译器选择更特化的版本；如果与非模板函数同样匹配，则优先选择非模板版本。

模板重载与类型转换：需要注意的是，重载解析规则在「实参需要转换」时更为复杂，尤其是涉及指针转换和 C 风格字符串时，容易出现意想不到的匹配结果。编写重载模板时，应确保对任意一组实参最多只有一个模板与之匹配。

## 可变参数模板

**可变参数模板（variadic template）**就是接受可变数目参数的模板函数或模板类。可变数目的参数被称为**参数包（parameter packet）**：

- **模板参数包（template parameter packet）**：表示零个或多个模板参数。
- **函数参数包（function parameter packet）**：表示零个或多个函数参数。

使用一个省略号（ellipsis）来指出一个模板参数或函数参数表示一个包：

```cpp
// Args 是一个模板参数包；rest 是一个函数参数包
// Args 表示零个或多个模板类型参数
// rest 表示零个或多个函数参数
template <typename T, typename... Args>
void foo(const T &t, const Args&... rest);
```

声明一个表示零个或多个特定类型的模板参数包：

```cpp
template <typename... Args> void g(Args... args); // Args... 表示零个或多个类型参数
```

```cpp
int i = 0; double d = 3.14; string s = "how now brown cow";
foo(i, s, 42, d);    // 包中有三个参数
foo(s, 42, "hi");    // 包中有两个参数
foo(d, s);           // 包中有一个参数
foo("hi");           // 空包
```

### sizeof...运算符

当我们需要知道包中有多少元素时，可以使用 sizeof... 运算符：

```cpp
template<typename ... Args> void g(Args ... args) {
    cout << sizeof...(Args) << endl;   // 类型参数的数目
    cout << sizeof...(args) << endl;   // 函数参数的数目
}
```

sizeof... 返回一个常量表达式，而且不会对实参求值。

### 编写可变参数函数模板

可以用一个递归的技巧来展开参数包：首先定义一个终止递归的函数，然后在可变参数函数中递归调用自身：

```cpp
// 用来终止递归并打印最后一个元素的函数
// 此函数必须在可变参数版本的 print 定义之前声明
template <typename T>
ostream &print(ostream &os, const T &t) {
    return os << t;           // 包中最后一个元素之后不打印分隔符
}
// 包中除了最后一个元素之外的其他元素都会调用这个版本的 print
template <typename T, typename... Args>
ostream &print(ostream &os, const T &t, const Args&... rest) {
    os << t << ", ";           // 打印第一个实参
    return print(os, rest...); // 递归调用，打印其他实参
}
```

```cpp
print(cout, i, s, 42); // print(cout, i, s, 42) 中有两个包参数
// 递归展开过程:
// print(cout, i, s, 42) -> print(cout, s, 42) -> print(cout, 42)（两个参数版本）
```

每个递归调用中，包中第一个实参被打印，剩余实参构成一个更小的包，继续传给下一次递归调用。当包中只剩一个元素时，调用两个参数的非可变参数版本，递归终止。

对于最后一次调用 `print(cout, 42)`，两个版本的 print 都可行（可变参数版本的包为空），但非可变参数版本更特化，因此被选择。

### 包扩展

对于一个参数包，除了获取其大小外，唯一能做的事情就是**扩展（expand）**它。当扩展一个包时，我们还要提供用于每个扩展元素的模式（pattern）：

```cpp
template <typename T, typename... Args>
ostream &print(ostream &os, const T &t, const Args&... rest) {
    os << sizeof...(Args) << " ";
    os << sizeof...(rest) << endl;
    // 扩展 Args
    return print(os, rest...); // 扩展 rest
}
```

扩展一个包就是将它分解为构成的元素，对每个元素应用模式，用逗号分隔。`print(os, rest...)` 中的模式是 `rest` 本身，它扩展为由包中所有元素构成的、逗号分隔的列表。

我们还可以用扩展模式（expanded pattern）为包中每个元素调用 debug_rep：

```cpp
template <typename... Args>
ostream &errorMsg(ostream &os, const Args&... rest) {
    // print(os, debug_rep(a1), debug_rep(a2), ..., debug_rep(an))
    return print(os, debug_rep(rest)...);
}
```

### 转发参数包

在新标准下，我们可以组合使用可变参数模板与 forward 机制来编写函数，实现将实参原封不动地传递给其他函数：

```cpp
// fun 的目的是将其实参转发给另一个可调用对象
// 通过组合可变参数模板与转发机制实现
template <typename... Args>
void foolish(Args&&... args) {
    // 将 Arg 扩展为右值引用的模式，将每个实参以原封不动的方式转发
    work(std::forward<Args>(args)...);
}
```

标准库容器的 emplace_back 成员函数就是可变参数模板与转发机制的典型应用（参见第 9 章和第 13 章）。

## 模板特例化

编写单一模板，使之对任何可能的模板实参集合进行合适的实例化，是编写泛型代码的核心思想。但有时，通用的模板定义对特定类型是不适合的：通用定义可能编译失败或做得不正确。

当我们不能（或不希望）使用模板版本时，可以定义类或函数模板的一个特例化版本：

```cpp
// 比较 const char* 的 compare 函数的第一个版本
// 通用模板定义使用 < 运算符，对 const char* 而言比较的是指针地址
template <typename T>
int compare(const T &v1, const T &v2) {
    if (v1 < v2) return -1;
    if (v2 < v1) return 1;
    return 0;
}
```

为 const char* 提供函数模板的一个特例化版本（特例化版本必须为每个模板参数都提供显式具体类型实参）：

```cpp
// compare 的特例化版本，处理字符数组的指针
template <>
int compare(const char* const &p1, const char* const &p2) {
    return strcmp(p1, p2);
}
```

当特例化一个函数模板时，必须为原模板中的每个模板参数都提供实参。关键字 template 后跟一个空尖括号列表 `<>`，指出我们将为原模板的所有模板参数提供实参。

上述特例化版本中，函数参数是 `const char* const &`（指向 const char 的 const 指针的引用）。调用 compare 时传给它字符数组的指针：

```cpp
const char *p1 = "hi", *p2 = "world";
compare(p1, p2); // 调用特例化版本（strcmp 比较），而非通用模板（指针比较）
compare("hi", "world"); // 同样调用特例化版本
```

**一个特例化版本本质上是一个实例**，而非函数名的重载版本。特例化不影响函数匹配。

我们只能特例化（全特化）模板，不能部分特例化函数模板（类模板可以偏特化）。

特例化的本质是「为一个特殊的模板实参集合定制模板的实现」。当我们特例化一个模板时，必须确保原模板的声明（而不仅是定义）是可见的。与往常一样，最好在定义任何特例化版本之前，先声明特例化版本，以避免与其他使用发生冲突：

```cpp
// 在此之前，模板 compare 的通用版本必须已经声明
template <> int compare(const char* const&, const char* const&);
```

### 类模板特例化

除了特例化函数模板，我们还可以特例化类模板。作为一个例子，我们为标准库 hash 模板定义一个特例化版本，可以用它来生成 Sales_data 的哈希值：

```cpp
// 打开 std 命名空间，以便特例化 std::hash
namespace std {
    template <> struct hash<Sales_data> {
        // 用于散列容器的类型
        typedef size_t result_type;
        typedef Sales_data argument_type;
        size_t operator()(const Sales_data& s) const;
        // 我们的使用调用 hash，因此这里没有相关数据成员
    };
    size_t hash<Sales_data>::operator()(const Sales_data& s) const {
        return hash<string>()(s.bookNo) ^
               hash<unsigned>()(s.units_sold) ^
               hash<double>()(s.revenue);
    }
} // 关闭 std 命名空间，注意: 右花括号后没有分号
```

为了让特例化版本可见，必须在实例化 hash<Sales_data> 之前，将这个特例化版本的声明放在包含 Sales_data 声明的头文件中。

### 类模板部分特例化

与函数模板不同，类模板可以**部分特例化（partial specialization）**。类模板的部分特例化本身是一个模板，使用时用户还必须为剩余的模板参数提供实参：

```cpp
// 通用版本
template <class T> struct remove_reference {
    typedef T type;
};
// 部分特例化版本，将用于左值引用和右值引用
template <class T> struct remove_reference<T&> {  // 左值引用
    typedef T type;
};
template <class T> struct remove_reference<T&&> { // 右值引用
    typedef T type;
};

int i;
// decltype(42) 为 int，使用通用模板
remove_reference<decltype(42)>::type a;
// decltype(i) 为 int&，使用第一个（T&）部分特例化版本
remove_reference<decltype(i)>::type b;
// decltype(std::move(i)) 为 int&&，使用第二个（T&&）部分特例化版本
remove_reference<decltype(std::move(i))>::type c;
```

a、b、c 三个变量的类型都是 int。

### 特例化成员而不是类

我们可以只特例化特定的成员函数而不是特例化整个模板：

```cpp
template <typename T> struct Foo {
    Foo(const T &t = T()): mem(t) { }
    void Bar() { /* ... */ }
    T mem;
};
// 特例化 Foo<int> 的成员 Bar
template <>
void Foo<int>::Bar() {
    // 对 int 特例化处理
}
```

当我们特例化一个成员函数时，只须特例化该成员（而无需特例化整个类模板或声明其他成员）：

```cpp
Foo<string> fs; // 实例化 Foo<string>::Foo()
fs.Bar();       // 实例化 Foo<string>::Bar()
Foo<int> fi;    // 实例化 Foo<int>::Foo()
fi.Bar();       // 使用我们特例化的 Foo<int>::Bar() 版本
```
