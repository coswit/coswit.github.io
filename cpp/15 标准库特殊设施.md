## tuple类型

不同的工具类有时需要返回多个值，tuple 是一种类似 pair 的模板，但一个 tuple 可以有任意数量的成员（每个 pair 恰好有两个成员）。tuple 定义在头文件 `tuple` 中。

每个 tuple 的成员类型都可以不同，但每个确定 tuple 类型的对象，其成员数量是固定的：

```cpp
tuple<size_t, size_t, size_t> threeD;         // 所有成员都执行值初始化，为 0
tuple<string, vector<double>, int, list<int>>
    someVal("constants", {3.14, 2.718}, 42, {0,1,2,3,4,5});
```

tuple 的构造函数是 explicit 的，必须使用直接初始化形式：

```cpp
tuple<size_t, size_t, size_t> threeD = {1,2,3}; // 错误
tuple<size_t, size_t, size_t> threeD{1,2,3};    // 正确
// 使用 make_tuple
auto item = make_tuple("0-999-78345-X", 3, 20.00);
// item 的类型是 tuple<const char*, int, double>
```

### 访问tuple的成员

使用 get 标准库函数模板访问 tuple 的成员，返回指定成员的引用：

```cpp
auto book = get<0>(item);      // 返回 item 的第一个成员
auto cnt = get<1>(item);       // 返回 item 的第二个成员
auto price = get<2>(item)/cnt; // 返回 item 的第三个成员，并除以 cnt
get<2>(item) *= 0.8;           // 修改第三个成员
```

get 中尖括号内的值必须是一个整型常量表达式。与往常一样，我们从 0 开始计数。

### 关系和相等运算符

tuple 的关系运算符（==、!=、<、>、<=、>=）逐对比较成员，只有当两个 tuple 的成员数量相同时才能比较：

```cpp
tuple<string, string> duo("1", "2");
tuple<size_t, size_t> twoD(1, 2);
// bool b = (duo == twoD); // 错误: 不能比较 size_t 和 string
tuple<size_t, size_t, size_t> threeD(1, 2, 3);
// bool b = (twoD < threeD); // 错误: 成员数量不同
tuple<size_t, size_t> origin(0, 0);
bool b = (origin < twoD); // 正确: < 为 true（字典序比较）
```

由于 tuple 定义了 < 和 == 运算符，我们可以将 tuple 序列传递给算法，以及在无序容器中使用 tuple 作为关键字类型。

### 使用tuple返回多个值

tuple 的一个常见用途是从一个函数返回多个值：

```cpp
// matches 有三个成员: 第一个 vector 中包含匹配索引的 vector、
// 匹配数量和文件总数
typedef tuple<vector<Sales_data>::size_type,
              unsigned, unsigned> matches;

// 对于每家书店，保存 vector<Sales_data> 中所有匹配记录的索引的 vector
vector<matches> findBook(const vector<vector<Sales_data>> &files,
                         const string &book) {
    vector<matches> ret;
    // 遍历每家书店
    for (auto it = files.cbegin(); it != files.cend(); ++it) {
        // 查找具有相同 ISBN 的书籍的索引
        auto found = equal_range(it->cbegin(), it->cend(), book, compareIsbn);
        if (found.first != found.second)
            ret.push_back(make_tuple(it - files.cbegin(),
                                     found.second - found.first,
                                     it->size()));
    }
    return ret;
}
```

tuple_size 和 tuple_element 两个类模板（与 get 一样定义在 tuple 头文件中），可以用来查询 tuple 的成员数量和成员类型：

```cpp
typedef decltype(item) trans; // trans 是 item 的类型
// 返回 trans 类型对象中成员的数量
size_t sz = tuple_size<trans>::value; // 返回 3
// cnt 的类型与 item 中第二个成员相同
tuple_element<1, trans>::type cnt = get<1>(item); // cnt 是一个 int
```

## bitset类型

标准库定义了 bitset 类，使得位运算的使用更容易，并且能够处理超过最长整型类型大小的位集合。bitset 定义在头文件 `bitset` 中。bitset 的大小在编译时是已知的，定义 bitset 时必须指定大小：

```cpp
bitset<32> bitvec(1U); // 32 位，低位为 1，其他位为 0
```

值用 unsigned long long 或 string 来初始化。用整数值初始化时，将整数值转换为二进制，多余的位被丢弃，不足的高位补 0；位序与二进制表示一致（最低位对应值的最右一位）：

```cpp
// 在 bitvec2 中，0xbeef 的二进制表示为 1011111011101111
bitset<13> bitvec2(0xbeef);   // bitvec2 比 0xbeef 的位数少，高位被丢弃
bitset<20> bitvec3(0xbeef);   // bitvec2 比 0xbeef 的位数多，高位补 0
bitset<128> bitvec4(~0ULL);   // 低 64 位为 1，高 64 位为 0
```

用 string 初始化：

```cpp
bitset<32> bitvec5("110000");       // 前面补 0，最高两位为 11
bitset<32> bitvec6("1100000", 2);   // 从下标 2 开始的字符
bitset<32> bitvec7("1100000", 2, 3);// 取从下标 2 开始的 3 个字符
```

注意：从 string 初始化 bitset 时，string 中下标最小的字符对应 bitset 的高位。

### bitset操作

| Operation          | Meaning                                              |
| ------------------ | ---------------------------------------------------- |
| b.any()            | b 中是否存在置位的二进制位                            |
| b.none()           | b 中是否没有置位的二进制位                            |
| b.count()          | b 中置位的位数，返回 size_t                          |
| b.size()           | b 中二进制位的个数，返回 size_t                      |
| b.test(pos)        | pos 处的二进制位是否置位                              |
| b.set(pos) / b.set(pos, v) | 将 pos 处的二进制位置位 / 置为 v              |
| b.set()            | 将 b 中所有二进制位都置位                             |
| b.reset(pos) / b.reset() | 将 pos 处 / 所有二进制位复位                   |
| b.flip(pos) / b.flip() | 改变 pos 处 / 所有二进制位的状态                  |
| b[pos]             | 访问 b 中 pos 处的二进制位（b.test(pos) 等价）        |
| b.to_ulong() / b.to_ullong() | 返回 b 的 unsigned long / unsigned long long 表示 |
| b.to_string(zero, one) | 返回 b 的 string 表示                             |
| os << b / is >> b | 将 b 中的位集输出到流 / 从流读取到 b                 |

```cpp
bitset<32> bitvec(1U); // 32 位，低位为 1，其他位为 0
bool is_set = bitvec.any();      // true，有二进制位被置位
bool is_not_set = bitvec.none(); // false
bool all_set = bitvec.count();   // 返回 long，本例返回 1
size_t sz = bitvec.size();       // 返回 32
bitvec.flip();     // 翻转 bitvec 中的所有位
bitvec.reset();    // 复位所有位
bitvec.set();      // 置位所有位
```

下标运算符可以对 bit 读写。对于 const 对象，返回 bool 值；对于非 const 对象，返回 bitset 定义的一个特殊类型，允许为位赋值：

```cpp
// 逐个检查 bitvec 的每一位是否置位
for (int i = 0; i != 32; ++i)
    if (bitvec[i])
        cout << i << " " << endl; // 打印置位位置
```

对 bitset 进行 IO 操作时，输入运算符从一个输入流读取字符，遇到不是 0/1 的字符时（或读取完毕），读取停止：

```cpp
bitset<16> bits;
cin >> bits;       // 从 cin 读取最多 16 个 0 或 1
cout << "bits: " << bits << endl;
```

## 正则表达式

正则表达式（regular expression）是一种描述字符序列的方式，标准库定义在 `regex` 头文件中，组件都位于命名空间 std 中。regex 库的主要组件：

| 组件              | 含义                                               |
| ----------------- | -------------------------------------------------- |
| regex             | 表示一个正则表达式的类                              |
| regex_match       | 将一个字符序列与一个正则表达式匹配                  |
| regex_search      | 寻找第一个与正则表达式匹配的子序列                   |
| regex_replace     | 使用给定格式替换一个正则表达式                      |
| sregex_iterator   | 迭代器适配器，调用 regex_search 来遍历一个 string 中所有匹配的子串 |
| smatch            | 容器类，保存在 string 中搜索的结果                  |
| ssub_match        | string 中匹配的子表达式的结果                       |

regex_match 和 regex_search 的参数（其他操作类似）：

```cpp
// 查找不是 c 后跟 ei 的情况: 此规则在美国英语中是常见的拼写规则
string pattern("[^c]ei");
// 我们想要包含 pattern 的全部单词
pattern = "[[:alpha:]]*" + pattern + "[[:alpha:]]*";
regex r(pattern, regex::icase); // 在匹配时忽略大小写，进行「不区分大小写」的查找
string test_str = "receipt freind theif receive";
// 在 test_str 中查找与 r 匹配的子串
if (regex_search(test_str, r))
    cout << r << endl;
```

正则表达式的语法默认遵循 ECMAScript（即 JavaScript）的正则表达式语法。regex（和 wregex）选项允许指定其他语法：basic、extended、awk、grep 和 egrep。

### regex迭代器类型

sregex_iterator 可以获得所有匹配：

```cpp
// 将输出: friend thief
for (sregex_iterator it(test_str.begin(), test_str.end(), r), end_it;
     it != end_it; ++it)
    cout << it->str() << endl;
```

当定义一个 sregex_iterator 时，构造函数调用 regex_search 在给定 string 中查找第一个匹配。递增迭代器时，调用 regex_search 从上一次匹配结束的位置开始查找下一个匹配。尾迭代器是 sregex_iterator()。

### 使用match数据类型

smatch 类型（以及 cmatch、wsmatch 等）是表示匹配结果的类，允许访问匹配的上下文以及匹配的各个子表达式：

```cpp
string phone =
    "(\\()?(\\d{3})(\\))?([-. ])?(\\d{3})([-. ])?(\\d{4})"; // 电话号码的格式
regex r(phone);
smatch m;
string s;
// 从输入文件中读取并统计与电话号码模式匹配的记录
while (getline(cin, s)) {
    // 对每个匹配的电话号码，输出其结构化形式
    for (sregex_iterator it(s.begin(), s.end(), r), end_it; it != end_it; ++it) {
        // 输出匹配的电话号码中的一部分（子表达式）
        cout << it->format("$2.$5.$7") << endl;
    }
}
```

ssub_match 类型的对象表示一个子表达式的匹配结果，smatch 提供诸如 prefix()（匹配之前的序列）和 suffix()（匹配之后的序列）等成员。

### 使用正则表达式进行替换

regex_replace 操作用给定格式的字符串替换匹配的子串：

```cpp
string fmt = "$2.$5.$7"; // 将号码改为 ddd.ddd.dddd 的格式
// 输出所有匹配的电话号码，格式化为 ddd.ddd.dddd
cout << regex_replace(s, r, fmt) << endl;
```

format 标志（如 format_no_copy、format_first_only）可以控制替换输出的细节。正则表达式中的字符串通常包含反斜杠，建议使用原始字符串字面值（raw string literal）：`R"(\\d{3})"` 以避免双重转义。

### 正则表达式指示错误

如果我们编写的正则表达式存在语法错误，标准库在运行时会抛出 regex_error 类型的异常。正则表达式的编写和验证最好在开发阶段完成。

## 随机数

在新标准出现之前，C 和 C++ 都依赖于一个简单的 C 库函数 rand 来生成随机数，其问题是：即使大多数场景需要的是不同范围的随机数、浮点数随机数或非均匀分布的随机数，rand 生成的整数范围也很小。

新标准库定义在 `random` 头文件中的随机数库通过一组协作的类来解决这些问题：**随机数引擎类（random-number engines）**和**随机数分布类（random-number distribution classes）**。

- 引擎类生成 unsigned 随机整数序列。
- 分布类使用引擎生成指定类型、指定范围内、指定分布的随机数。

C++ 程序不应该使用库函数 rand，而应使用 default_random_engine 和恰当的分布类对象。

### 随机数引擎和分布

随机数引擎是函数对象类，它们定义了调用运算符来接受零实参并返回一个随机 unsigned 整数：

```cpp
default_random_engine e;  // 生成随机无符号数
for (size_t i = 0; i < 10; ++i)
    cout << e() << " ";   // 打印随机数
```

标准库定义了多个引擎类，它们的区别在于性能和随机性的质量不同。每个引擎类都定义了一个名为 result_type 的静态成员，保存引擎生成的随机数的类型。

大多数场合下，直接使用引擎生成的数值是不合适的（范围太大），需要通过分布类来获得指定范围内的随机数：

```cpp
// uniform_int_distribution 的构造函数接受两个值，表示生成的随机数的闭区间范围
uniform_int_distribution<unsigned> u(0, 9); // 均匀分布的随机无符号整数，范围 0 到 9（包含）
default_random_engine e;  // 生成无符号随机整数
for (size_t i = 0; i < 10; ++i)
    // u 作为随机数源；每个调用返回一个指定范围内且满足均匀分布的值
    cout << u(e) << " ";
```

类似地，我们可以生成均匀分布的随机浮点数：

```cpp
// 0 到 1（包含）范围的均匀分布
uniform_real_distribution<double> u2(0, 1);
```

分布类型的对象也是函数对象，将一个引擎作为参数进行调用。

### 引擎生成一个数值序列

随机数发生器有一个重要特性（同时也是常见的错误来源）：给定的发生器生成的数值序列是固定的。一个给成的随机数发生器一直会生成相同的随机数序列。一个函数如果定义了随机数发生器为局部变量，则每次函数调用都会产生相同的序列：

```cpp
// 几乎肯定是错误的: 每次调用都会生成相同的 100 个数
vector<unsigned> bad_randVec() {
    default_random_engine e;
    uniform_int_distribution<unsigned> u(0, 9);
    vector<unsigned> ret;
    for (size_t i = 0; i < 100; ++i)
        ret.push_back(u(e));
    return ret;
}
// 正确: 将发生器和分布定义为 static 的
vector<unsigned> good_randVec() {
    // 由于我们希望 e 和 u 保持状态，因此应该将它们定义为 static 的，
    // 从而每次调用生成新的数
    static default_random_engine e;
    static uniform_int_distribution<unsigned> u(0, 9);
    vector<unsigned> ret;
    for (size_t i = 0; i < 100; ++i)
        ret.push_back(u(e));
    return ret;
}
```

### 设置随机数发生器种子

生成随机数序列的另一个技巧是用不同的种子来定义发生器。种子就是一个数值，发生器用它作为生成新随机数的起点：

```cpp
default_random_engine e1;      // 使用默认种子
default_random_engine e2(2147483646); // 使用给定的种子
// e3 和 e4 将生成相同的序列，因为它们使用了相同的种子
default_random_engine e3;
e3.seed(32767);                // 调用 seed 设置为新种子
default_random_engine e4(32767);
```

常用的种子设置方法是用系统函数 time（定义在 ctime 中）返回的当前时间作为种子：

```cpp
default_random_engine e1(time(0));
```

由于 time 返回以秒计的时间，因此这种方法只适合作为种子生成的来源。

### 其他随机数分布

生成随机实数（如 0 到 1 之间的随机 double）：

```cpp
default_random_engine e;        // 生成无符号随机整数
uniform_real_distribution<double> u(0, 1); // 均匀分布的随机 double
```

生成非均匀分布的随机数：

```cpp
default_random_engine e;        // 生成无符号随机整数
normal_distribution<> n(4, 1.5); // 正态分布，均值 4，标准差 1.5
vector<unsigned> vals(9);
for (size_t i = 0; i != 200; ++i) {
    unsigned v = lround(n(e)); // 取整到最近的整数
    if (v < vals.size())       // 只统计范围内的值
        ++vals[v];
}
```

bernoulli_distribution 类是普通类（非模板），总是返回一个 bool 值，返回 true 的概率默认为 0.5：

```cpp
string resp;
bernoulli_distribution b;       // 默认是 50/50 的机会
default_random_engine e;        // 生成无符号随机整数
bool first = b(e);              // 如果为 true，程序先走
```

注意：分布类返回 bool 的概率可以调整：`bernoulli_distribution b(.55);` 返回 true 的概率是 0.55。

## IO库再探

前面介绍了 IO 库的基本内容，这里介绍一些更高级的格式控制以及未格式化的 IO 操作。

### 格式化输入与输出

除了条件状态外，每个 iostream 对象还维护一个格式状态（format state），控制格式化输入输出的细节。标准库定义了一组**操纵符（manipulator）**来修改对象的格式状态。

**控制布尔值的格式**：

```cpp
cout << "default bool values: " << true << " " << false
     << "\nalpha bool values: " << boolalpha
     << true << " " << false << endl;
// 输出:
// default bool values: 1 0
// alpha bool values: true false
```

boolalpha 操纵符使后续的 bool 值以 true/false 形式输出，noboolalpha 恢复默认格式。

**指定整型值的进制**：

```cpp
cout << showbase << uppercase << hex // 输出 0X 前缀的十六进制
     << "printed in hexadecimal: " << 20 << " " << 1024
     << nouppercase << dec << noshowbase << endl;
// 输出: printed in hexadecimal: 0X14 0X400
```

操纵符 hex、oct、dec 改变进制；showbase 显示进制前缀（0x 前缀十六进制、0 前缀八进制）；uppercase 控制十六进制中 a-f 与前缀 x 的大小写。

**控制浮点数格式**：

```cpp
// cout.precision 返回当前精度
cout << "Precision: " << cout.precision()
     << ", Value: " << sqrt(2.0) << endl;
// cout.precision(12) 将打印精度设置为 12 位数字
cout.precision(12);
cout << "Precision: " << cout.precision()
     << ", Value: " << sqrt(2.0) << endl;
// 恢复默认精度
cout.precision(6);
```

浮点数操纵符：scientific（科学计数法）、fixed（定点十进制）、hexfloat（十六进制浮点数）、defaultfloat（恢复默认）。

```cpp
cout << "default format: " << 100 * sqrt(2.0) << '\n'
     << "scientific: " << scientific << 100 * sqrt(2.0) << '\n'
     << "fixed decimal: " << fixed << 100 * sqrt(2.0) << '\n'
     << "hexadecimal: " << hexfloat << 100 * sqrt(2.0) << '\n'
     << "use defaults: " << defaultfloat << 100 * sqrt(2.0) << "\n\n";
```

一个常用的格式化输出手段：setw 指定下一个数字或字符串值的最小空间，setfill 指定填充字符（需要 include iomanip）：

```cpp
#include <iomanip>
int i = -16;
double d = 3.14159;
// 补白第一列，使用显示位置 12
cout << "i: " << setw(12) << i << "next col" << '\n'
     << "d: " << setw(12) << d << "next col" << '\n';
// 补白第一列，左对齐所有列
cout << left
     << "i: " << setw(12) << i << "next col" << '\n'
     << "d: " << setw(12) << d << "next col" << '\n'
     << right;           // 恢复正常的右对齐格式
// 补白第一列，右对齐所有列
cout << right
     << "i: " << setw(12) << i << "next col" << '\n'
     << "d: " << setw(12) << d << "next col" << '\n';
// 补白第一列，但补在域的内部
cout << internal
     << "i: " << setw(12) << i << "next col" << '\n'
     << right;           // 恢复右对齐
// 补白第一列，用 # 作为填充字符
cout << setfill('#')
     << "i: " << setw(12) << i << "next col" << '\n'
     << "d: " << setw(12) << d << "next col" << '\n'
     << setfill(' ');    // 恢复正常的填充字符
```

注意：setw 只影响下一个输出，其他大多数操纵符的效果会持续到被覆盖为止。

### 未格式化的输入/输出操作

标准库还提供了一组低层操作，支持**未格式化 IO（unformatted IO）**操作，将流当作未解释的字节序列处理。

单字节操作：

```cpp
char ch;
while (cin.get(ch))
    cout.put(ch);
```

get 有多个版本：`get()` 无参版本从流中读取一个字节并返回（遇到文件尾返回 EOF）；`get(ch)` 版本读取下一个字节存入 ch；peek 在输入流中保留字节但返回其值；unget 和 putback 将字节放回流中。

多字节操作：

```cpp
char buf[50];
cin.read(buf, 50);         // 读取 50 个字节
ofstream out("somefile");
out.write(buf, 50);        // 写入 50 个字节
cout << "cin.gcount(): " << cin.gcount() << endl; // 上次 read 读取的字节数
```

getline（iostream 的成员函数版本）读取直到换行符为止，注意与标准库 string 的 getline 函数的区别。

### 流随机访问

不同的流一般来说都支持随机访问（事实上有些流不支持），ifstream 和 stringstream 类型的流（以及对应的 ofstream 和 ostringstream）支持随机访问（但 cin 和 cout 等标准流不支持随机访问）。可以使用 seek 和 tell 函数在流中来回移动：

```cpp
// seek 定位流，tell 返回位置
// inOut 打开以便进行读写，定位到文件末尾（ate 模式）
fstream inOut("copyOut", fstream::ate | fstream::in | fstream::out);
ofstream::pos_type end_mark = inOut.tellg(); // 记住原文件结束位置
inOut.seekg(0, fstream::beg);                // 定位到文件开始
size_t cnt = 0;                              // 字节数
// 读取到文件末尾时停止
while (inOut && inOut.tellg() != end_mark && !inOut.eof()) {
    // ...
}
```

seek 的两个版本：`seekg(pos)`（绝对定位）和 `seekg(off, from)`（相对定位，from 可以是 beg、cur、end）。tellg/tellp 返回标记的当前位置。带 g 的函数用于输入流（istream），带 p 的用于输出流（ostream）。

由于流缓冲区的状态在读写之间切换时可能需要刷新，建议在读写之间调用 seek 定位操作。
