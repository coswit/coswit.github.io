## 1. 不可变的 String(Immutable Strings)

**String 对象是不可变的(immutable)**:String 类中每个"看起来会修改 String 值"的方法,实际上都是创建并返回一个**全新的 String 对象**,原对象原封不动。

```java
public class Immutable {
    public static String upcase(String s) {
        return s.toUpperCase();   // 返回的是新对象
    }

    public static void main(String[] args) {
        String q = "howdy";
        String qq = upcase(q);
        System.out.println(qq);   // HOWDY
        System.out.println(q);    // howdy —— q 没有被修改
    }
}
```

`q` 传给 `upcase()` 时,实际传递的是**引用的拷贝**。`upcase()` 返回的引用指向一个新对象,原来的 `q` 始终指向 "howdy"。

不可变带来的好处:**任何别名(alias)对一个 String 的引用都不可能改变这个 String**,因为它是只读的。这一特性是 String 可以安全地字面量共享、作为 HashMap 键的基础。

## 2. '+' 重载与 StringBuilder(Overloading '+' vs. StringBuilder)

Java 不允许程序员重载运算符,唯一例外是 String 的 `+` 和 `+=`(重载意味着为运算符赋予与特定类结合时的额外含义):

```java
String mango = "mango";
String s = "abc" + mango + "def" + 47;   // abcmangodef47
```

如果 `+` 每拼接一次就创建一个中间 String 对象,会产生大量需要回收的垃圾。用 `javap -c` 反汇编可以看到实际情况——编译器自动使用了 **StringBuilder**:

```java
// javap -c Concatenation 的等价代码:
StringBuilder sb = new StringBuilder();
sb.append("abc");
sb.append(mango);
sb.append("def");
sb.append(Integer.toString(47));
String s = sb.toString();
```

但编译器的优化有边界。**循环中的拼接**不会自动复用同一个 builder:

```java
public class Concatenation {
    public String implicit(String[] fields) {
        String result = "";
        for (String field : fields)
            result += field;   // 每次循环都 new 一个 StringBuilder
        return result;
    }

    public String explicit(String[] fields) {
        StringBuilder result = new StringBuilder();
        for (String field : fields)
            result.append(field);   // 全程复用一个 builder
        return result.toString();
    }
}
```

`implicit()` 在每次循环里创建一个新的 StringBuilder、append 再 toString,产生大量中间对象。结论:**简单拼接交给编译器;循环里自己显式用 StringBuilder**。

StringBuilder 是 Java SE5 引入的;在此之前用 StringBuffer,后者是线程安全的(代价是开销),如今只在需要线程安全时才用。

## 3. 无意的递归(Unintended recursion)

在 `toString()` 里用 `this` 做 `+` 拼接是一个经典陷阱:

```java
public class InfiniteRecursion {
    @Override
    public String toString() {
        // return "InfiniteRecursion address: " + this;
        // 错误写法:this 会被自动调用 toString(),又进入本方法,无限递归
        // StackOverflowError
        return "InfiniteRecursion address: " + super.toString();
        // 正确写法:用 Object 的 toString() 拿到地址
    }
}
```

`"..." + this` 会触发编译器调用 `this.toString()`,而当前正在这个方法里——于是无限递归、栈溢出。想要对象地址信息,应该调用 `super.toString()`。

## 4. String 的操作(Operations on Strings)

String 携带的方法是最常用的工具,每个"修改"操作都返回新对象:

| 方法                             | 作用(参数为 int 时返回 char)                     |
| -------------------------------- | -------------------------------------------------- |
| `length()`                       | 字符个数                                           |
| `charAt(int i)`                  | 取第 i 个字符                                      |
| `getChars()` / `getBytes()`      | 复制字符到数组 / 转为字节数组                      |
| `toCharArray()`                  | 转为 char 数组                                     |
| `equals()` / `equalsIgnoreCase()`| 内容比较(不区分大小写)                           |
| `compareTo()`                    | 按字典序比较                                       |
| `contains()`                     | 是否包含参数序列                                   |
| `startsWith()` / `endsWith()`    | 前缀 / 后缀判断                                    |
| `indexOf()` / `lastIndexOf()`    | 查找字符或子串的位置(从后往前)                   |
| `substring(int begin[, int end])`| 截取子串                                           |
| `concat()`                       | 拼接                                               |
| `replace()`                      | 替换字符或字符序列                                 |
| `toLowerCase()` / `toUpperCase()`| 大小写转换                                         |
| `trim()`                         | 删除两端空白符                                     |
| `split()`                        | 按正则拆分                                         |
| `valueOf()`                      | 静态方法:任意类型转 String                        |
| `format()`                       | 静态方法:格式化(见下节)                         |
| `intern()`                       | 返回字符串常量池中的规范实例                       |

打印一个对象数组时 `Arrays.toString()`;打印基本类型数组要 `Arrays.toString(a)`,否则输出的是类似 `[I@3e25a5` 的类型+地址。

> 提示:Java 11 起 String 新增 `isBlank()`、`strip()`、`repeat()` 等方法;Java 15 起支持文本块(text block,三引号字符串)。原书成书于 Java 5/8 时代,未覆盖这些。

## 5. 格式化输出(Formatting output)

Java SE5 借鉴 C 的 `printf()` 引入格式化输出。

### printf() 与 System.out.format()

`printf()` 与 `format()` 等价,后者更符合 Java 命名习惯:

```java
System.out.printf("Row 1: [%d %f]%n", x, y);
System.out.format("Row 1: [%d %f]%n", x, y);
```

### Formatter 类

格式化的真正核心是 **Formatter** 类:把"格式字符串 + 参数"翻译成期望的输出。printf/format 都是其便捷封装。Formatter 可写入的目标不限于控制台(也可写文件等):

```java
Formatter f = new Formatter(System.out);
f.format("%-15s %5d %10.2f%n", "item", 3, 3.14159);
```

### 格式说明符(Format specifiers)

抽象语法:

```text
%[argument_index$][flags][width][.precision]conversion
```

| 组成部分         | 含义                                                       |
| ---------------- | ---------------------------------------------------------- |
| argument_index   | 参数位置,如 `1$`、`2$`(用于重排参数)                    |
| flags            | `-` 左对齐、`+` 显示正号、`0` 补零、`,` 千分位、`(` 负数括号 |
| width            | 最小宽度(不足补空格)                                     |
| .precision       | 精度;对 String 是最大字符数,对浮点是小数位数             |
| conversion       | 转换类型(见下表)                                         |

常用转换类型:

| 转换符 | 类型与含义                              | 典型输出        |
| ------ | --------------------------------------- | --------------- |
| d      | 整数(decimal integral)                 | 200             |
| c      | Unicode 字符                            | X               |
| b      | Boolean 值                              | true            |
| s      | String                                  | Hello           |
| f      | 浮点数(floating point)                 | 3.141593        |
| e      | 浮点数,科学计数法                      | 3.141593e+00    |
| x      | 整数,十六进制                          | cf              |
| h      | 整数,十六进制的 hashCode               | 7a9e88          |

```java
// 精度与宽度:
System.out.format("[%f]%n", 3.14159);    // [3.141590]
System.out.format("[%.3f]%n", 3.14159);  // [3.142]  精度 3 位小数
System.out.format("[%10.3f]%n", 3.14159);// [     3.142] 宽度 10,右对齐
System.out.format("[%-10.3f]%n", 3.14159);// [3.142     ] 左对齐
```

### String.format()

`String.format()` 静态方法返回格式化后的 String,常用在 `toString()` / 异常信息里:

```java
public class Turtle {
    private String name;

    @Override
    public String toString() {
        return String.format("Turtle %s", name);
    }
}
```

## 6. 正则表达式(Regular expressions)

Java 的正则相比 Perl 等语言"更啰嗦":String 内置了一部分正则功能(`matches()`、`split()`、`replaceFirst()`、`replaceAll()`),完整能力在 `java.util.regex` 的 Pattern/Matcher 中。

### 基础(Basics)

```java
System.out.println("-1234".matches("-?\\d+"));     // true:可选负号 + 多个数字
System.out.println("5678".matches("-?\\d+"));      // true
System.out.println("+911".matches("(-|\\+)?\\d+"));// true:可选 + 或 -
```

注意 Java 字符串里反斜杠要转义:`\\d` 表示一位数字。

### 构建正则表达式(Creating regular expressions)

| 字符       | 匹配                        |
| ---------- | --------------------------- |
| B          | 指定字符 B                  |
| \xhh       | 十六进制为 hh 的字符        |
| \t \n \r \f \e | 制表/换行/回车/换页/转义 |

| 字符类           | 匹配                                  |
| ---------------- | ------------------------------------- |
| .                | 任意字符                              |
| [abc]            | a、b 或 c                             |
| [^abc]           | 除 a、b、c 之外的任意字符(取反)     |
| [a-zA-Z]         | a 到 z 或 A 到 Z(范围)              |
| [abc[hij]]       | 并集:任意 a/b/c/h/i/j                 |
| [a-z&&[hij]]     | 交集:h、i 或 j                       |
| \s \S            | 空白符 / 非空白符                    |
| \d \D            | 数字 / 非数字                        |
| \w \W            | 词字符 [a-zA-Z0-9_] / 非词字符       |

| 逻辑运算符 | 含义                       |
| ---------- | -------------------------- |
| XY         | X 后跟 Y                   |
| X\|Y       | X 或 Y                     |
| (X)        | 捕获组(capturing group)  |

| 边界匹配符 | 含义              |
| ---------- | ----------------- |
| ^ $        | 行首 / 行尾       |
| \b         | 词边界            |

| 贪婪量词  | 勉强量词(懒惰) | 占有量词  | 含义                              |
| --------- | ---------------- | --------- | --------------------------------- |
| X?        | X??              | X?+       | X 出现 0 次或 1 次                |
| X*        | X*?              | X*+       | X 出现 0 次或多次                 |
| X+        | X+?              | ++        | X 出现 1 次或多次                 |
| X{n}      | X{n}?            | X{n}+     | X 恰好出现 n 次                   |
| X{n,}     | X{n,}?           | X{n,}+    | X 至少出现 n 次                   |
| X{n,m}    | X{n,m}?          | X{n,m}+   | X 出现 n 到 m 次                  |

三组量词的差别:贪婪——尽可能多匹配;勉强——尽可能少匹配;占有——像贪婪一样匹配但不回溯(backtracking),失败即终止,性能更好。

### Pattern 与 Matcher

导入 `java.util.regex.*`,先 `Pattern.compile()` 编译正则,再用 pattern 得到绑定了输入串的 **Matcher**,常用方法:`matches()`(整个串匹配)、`find()`(寻找下一个匹配,可循环)、`group()`(本次匹配到的内容)、`start()`/`end()`(匹配的起止位置)、`lookingAt()`(从开头匹配):

```java
import java.util.regex.*;

public class TestRegularExpression {
    public static void main(String[] args) {
        String input = "abcabcabcdefabc";
        Pattern p = Pattern.compile("(abc)+");   // 编译一次,可复用
        Matcher m = p.matcher(input);
        while (m.find())
            System.out.println("Match \"" + m.group()
                    + "\" at positions " + m.start() + "-" + (m.end() - 1));
    }
}
/* Output:
Match "abcabcabc" at positions 0-8
Match "abc" at positions 9-11
*/
```

**组(group)**是用括号划分的子表达式,`group(0)` 是整个匹配,`group(n)` 是第 n 组。命名组语法 `(?<name>...)`。matcher 的 `reset()` 可以把同一个 Matcher 换一个输入串继续用。

Pattern 的编译标志(flags):

| 标志                  | 作用                                       |
| --------------------- | ------------------------------------------ |
| Pattern.CASE_INSENSITIVE | 忽略大小写                              |
| Pattern.MULTILINE     | `^`/`$` 匹配每一行的行首/行尾             |
| Pattern.COMMENTS      | 忽略正则中的空白与 `#` 注释               |

### split()

`split()` 按正则把字符串拆成数组,第二个参数限制拆分次数:

```java
String input = "This!!unusual use!!of exclamation!!points";
System.out.println(Arrays.toString(input.split("!!")));       // 按 !! 拆
System.out.println(Arrays.toString(input.split("!!", 3)));    // 最多拆 3 份
```

### 替换操作(Replace operations)

正则替换的专用方法(普通 `replace()` 只处理字面量):

```java
Matcher m = Pattern.compile("[aeiou]").matcher("apple");
while (m.find())
    m.appendReplacement(sbuf, m.group().toUpperCase());  // 逐个替换
m.appendTail(sbuf);                                      // 补上尾部
// 简便: "apple".replaceAll("[aeiou]", "-")
```

### 正则与扫描(Regular expressions and Java I/O)

典型应用:逐行读文件,对每行做正则匹配筛选——把文件读入 String 再用 Matcher 遍历,可以在整篇文本中跨行查找(而不是一行一行处理)。

## 7. 扫描输入(Scanning input)

Java SE5 之前读输入要手工拆分 StringTokenizer/手工 parse 数字;SE5 的 **Scanner** 大大简化(构造参数可以是 File、InputStream、String 等):

```java
import java.util.*;

public class SimpleRead {
    public static void main(String[] args) {
        Scanner stdin = new Scanner(System.in);
        System.out.print("What is your name? ");
        String name = stdin.nextLine();
        System.out.print("How old are you? ");
        int age = stdin.nextInt();
        System.out.println(name + ", " + age);
    }
}
```

`nextInt()` 等方法按"下一个 token 是对应类型"读取,类型不符抛 InputMismatchException。

**自定义分隔符**:默认按空白分隔,可用 `useDelimiter()` 指定正则:

```java
scanner.useDelimiter(",\\s*");          // 逗号 + 可选空白
```

也可以直接用 `hasNext(pattern)` / `next(pattern)` 按正则扫描匹配。

## 8. StringTokenizer

StringTokenizer 是 Java 1.0/1.1 的拆分工具,功能被正则取代,**已过时**——新代码应使用 `String.split()`、Scanner 或正则:

```java
// 旧写法:
StringTokenizer st = new StringTokenizer("a b c");
while (st.hasMoreTokens())
    System.out.println(st.nextToken());

// 新写法:
String[] parts = "a b c".split(" ");
```
