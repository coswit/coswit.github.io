## 1. 简单泛型（Simple generics）

泛型的核心动机之一是**让容器记住它装的是什么类型**。没有泛型的容器把元素当作 Object,取出来必须强转,放错类型编译器毫无察觉——"把 Dog 放进 Cat 列表"只能在运行时爆炸。

```java
// 前泛型时代:
List cats = new ArrayList();
cats.add(new Dog());          // 编译通过!问题被推迟到运行期
Cat c = (Cat) cats.get(0);    // ClassCastException

// 泛型之后:
List<Cat> cats = new ArrayList<>();
// cats.add(new Dog());       // 编译错误:类型安全前移到编译期
Cat c = cats.get(0);          // 无需强转
```

### 一个元组库（A tuple library）

**元组（tuple）**:将一组对象打包成单一对象的对象。元组允许读取但不允许修改（数据传输对象）。泛型让元组能"记住"每个位置的类型:

```java
class Tuple2<A, B> {           // 二元组;可依次扩展三元组、四元组
    public final A first;
    public final B second;

    public Tuple2(A a, B b) { first = a; second = b; }
}
```

类型参数的命名惯例:`T` 表 type、`V` 表 value、`K` 表 key、`E` 表 element。多个参数时 `A, B, C` 或 `T1, T2, T3`。

### 一个栈类（A stack class）

内部类 + 泛型实现链式栈,展示了泛型类里再套泛型:

```java
public class LinkedStack<T> {
    private static class Node<U> {        // 节点本身也是泛型
        U item;
        Node<U> next;

        Node() { item = null; next = null; }
        Node(U item, Node<U> next) { this.item = item; this.next = next; }
        boolean end() { return item == null && next == null; }
    }

    private Node<T> top = new Node<>();   // 哨兵:栈底标记

    public void push(T item) {
        top = new Node<>(item, top);
    }

    public T pop() {
        T result = top.item;
        if (!top.end())
            top = top.next;
        return result;
    }

    public static void main(String[] args) {
        LinkedStack<String> lss = new LinkedStack<>();
        for (String s : "Phasers on stun!".split(" "))
            lss.push(s);
        String s;
        while ((s = lss.pop()) != null)
            System.out.println(s);
    }
}
/* Output:
stun!
on
Phasers
*/
```

### RandomList

一个"随机取一个元素"的持有器,演示泛型与随机选择结合:

```java
public class RandomList<T> {
    private ArrayList<T> storage = new ArrayList<>();
    private Random rand = new Random(47);

    public void add(T item) { storage.add(item); }
    public T select() {
        return storage.get(rand.nextInt(storage.size()));
    }

    public static void main(String[] args) {
        RandomList<String> rs = new RandomList<>();
        for (String s : ("The quick brown fox jumped over " +
                "the lazy brown dog").split(" "))
            rs.add(s);
        for (int i = 0; i < 11; i++)
            System.out.print(rs.select() + " ");
    }
}
```

## 2. 泛型接口（Generic interfaces）

泛型也可用于接口,典型例子是**生成器（Generator）**——一种特殊的工厂:无需参数、每次调用产生一个新对象:

```java
public interface Generator<T> {
    T next();
}
```

实现一个"斐波那契数生成器":

```java
public class Fibonacci implements Generator<Integer> {
    private int count = 0;

    @Override
    public Integer next() { return fib(count++); }

    private int fib(int n) {
        if (n < 2) return 1;
        return fib(n - 2) + fib(n - 1);
    }
}
```

基本类型不能做类型参数,所以这里用 `Integer` 做**自动装箱（autoboxing）**。

要进一步把生成器用在 foreach 循环里,需要实现 `Iterable<T>`——用**匿名内部类**实现 iterator():

```java
public class IterableFibonacci implements Iterable<Integer> {
    private Fibonacci fibonacci = new Fibonacci();
    private int n;

    public IterableFibonacci(int count) { n = count; }

    @Override
    public Iterator<Integer> iterator() {
        return new Iterator<Integer>() {     // 匿名内部类
            @Override
            public boolean hasNext() { return n > 0; }
            @Override
            public Integer next() {
                n--;
                return fibonacci.next();
            }
            @Override
            public void remove() { throw new UnsupportedOperationException(); }
        };
    }

    public static void main(String[] args) {
        for (int i : new IterableFibonacci(18))
            System.out.print(i + " ");
    }
}
```

## 3. 泛型方法（Generic methods）

泛型方法**独立于类**是否泛型:可以在普通类里定义,也可以在泛型类里定义。类型参数列表放在返回值之前:

```java
public class GenericMethods {
    public <T> void f(T x) {                 // <T> 在返回类型 void 之前
        System.out.println(x.getClass().getName());
    }

    public static void main(String[] args) {
        GenericMethods gm = new GenericMethods();
        gm.f("");          // java.lang.String
        gm.f(1);           // java.lang.Integer
        gm.f(1.0F);        // java.lang.Float
        gm.f('c');         // java.lang.Character
    }
}
```

调用时**不必显式指明类型参数**——编译器根据实参推断出确切类型,这叫**类型参数推断（type argument inference）**。

### 杠杆化类型参数推断（Leveraging type argument inference）

泛型方法 + 类型推断可以消除重复的泛型声明噪音。写 `Map<Person, List<? extends Pet>> petPeople = new HashMap<Person, List<? extends Pet>>()` 这样的代码时,创建侧的类型可以交给工具方法推断:

```java
public class New {
    public static <K, V> Map<K, V> map() {
        return new HashMap<K, V>();
    }
}

// 使用侧大大简化:
Map<Person, List<? extends Pet>> petPeople = New.map();
// Java 7 的钻石操作符 <> 也能达到类似效果:
Map<Person, List<? extends Pet>> petPeople2 = new HashMap<>();
```

### varargs 与泛型方法

泛型方法与可变参数列表配合,可以写"任意数量同类型参数"的实用方法:

```java
public class GenericVarargs {
    // 返回任意数量参数组成的 List,类型由调用方推断
    @SafeVarargs
    static <T> List<T> makeList(T... args) {
        List<T> result = new ArrayList<>();
        for (T item : args)
            result.add(item);
        return result;
    }

    public static void main(String[] args) {
        List<String> ls = makeList("A");
        System.out.println(ls);
        ls = makeList("A", "B", "C");
        System.out.println(ls);
    }
}
```

### 一个通用的 Generator

泛型方法可以进一步抽"生成器工厂"——为任意具有无参构造器的类生成 Generator:

```java
public class BasicGenerator<T> implements Generator<T> {
    private Class<T> type;

    public BasicGenerator(Class<T> type) { this.type = type; }

    @Override
    public T next() {
        try {
            return type.getDeclaredConstructor().newInstance();  // 反射创建
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    // 静态泛型方法:类型推断让调用方无需指明类型
    public static <T> Generator<T> create(Class<T> type) {
        return new BasicGenerator<>(type);
    }
}

// 使用:
Generator<CountedObject> gen = BasicGenerator.create(CountedObject.class);
```

### 简化元组使用

静态泛型方法让元组的创建不需要重复类型声明:

```java
public class Tuple {
    public static <A, B> Tuple2<A, B> tuple(A a, B b) {
        return new Tuple2<>(a, b);
    }
}

// 使用:String 和 Integer 自动推断:
Tuple2<String, Integer> f() {
    return Tuple.tuple("hi", 47);
}
```

### 一个 Set 工具

泛型方法表达集合运算,类型推断使调用简洁:

```java
public class Sets {
    public static <T> Set<T> union(Set<T> a, Set<T> b) {
        Set<T> result = new HashSet<>(a);
        result.addAll(b);
        return result;
    }

    public static <T> Set<T> intersection(Set<T> a, Set<T> b) {
        Set<T> result = new HashSet<>(a);
        result.retainAll(b);
        return result;
    }

    public static <T> Set<T> difference(Set<T> superset, Set<T> subset) {
        Set<T> result = new HashSet<>(superset);
        result.removeAll(subset);
        return result;
    }
}
```

## 4. 匿名内部类（Anonymous inner classes）

泛型还能作用于**内部类与匿名内部类**。下一节"构建复杂模型"的各个类都可以用匿名生成器产生:

```java
public class BankTeller {
    public static void serve(Teller t, Customer c) {
        System.out.println(t + " serves " + c);
    }

    public static void main(String[] args) {
        RandomList<Customer> customers = new RandomList<>();
        // 匿名内部类实现 Generator:
        Generator<Customer> gen = new Generator<Customer>() {
            @Override
            public Customer next() { return new Customer(); }
        };
        for (int i = 0; i < 10; i++)
            customers.add(gen.next());
    }
}
```

> Java 8 之后,单方法接口的实现通常直接用 lambda 表达:`Generator<Customer> gen = Customer::new;` 匿名内部类写法在理解框架源码时仍常见。

## 5. 构建复杂模型（Building complex models）

泛型的价值在**多层嵌套的容器模型**中最为突出——类型信息层层携带,编译器全程检查:

```java
// 一栋"零售店 + 咖啡厅"的建筑模型:
public class Building {}
public class Retail extends Building {}

class Product {
    private final int id;
    private String description;

    @Override
    public String toString() { return description; }
}

class Shelf extends ArrayList<Product> {}
class Aisle extends ArrayList<Shelf> {}          // 货架组成通道
class Store extends ArrayList<Aisle> {}          // 通道组成商店

public class StoreModel {
    public static void main(String[] args) {
        Store store = new Store();
        // 填充货架、通道……
        // List<Collection<String>> 等更复杂的模型同理:
        List<String> shelf1 = Arrays.asList("a", "b", "c");
        List<List<String>> aisles = new ArrayList<>();
        aisles.add(shelf1);
        System.out.println(aisles);
    }
}
```

再看一个类型更"重"的例子——`Map` 嵌套:

```java
// 每个人养的各种宠物:
static Map<String, List<? extends Pet>> petPeople = new HashMap<>();
// String 是人名,List 装的是 Pet 的子类

static {
    petPeople.put("Dawn", Arrays.asList(new Cymric("Molly"), new Mutt("Spot")));
    petPeople.put("Kate", Arrays.asList(new Cat("Shackleton"), new Dog("Margrett")));
}

public static void main(String[] args) {
    System.out.println("People: " + petPeople.keySet());
    System.out.println("Pets: " + petPeople.values());
    for (String person : petPeople.keySet()) {
        System.out.println(person + " has:");
        for (Pet pet : petPeople.get(person))
            System.out.println("    " + pet);
    }
}
```

泛型模型可以嵌套到任意深度,类型参数沿结构一路传递——这正是泛型带来的"表达力"而不只是类型安全。
