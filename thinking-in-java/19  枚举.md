## 1. 基本 enum 特性(Basic enum features)

enum 的实例是编译期常量,用类名直接引用。创建时编译器自动添加 `values()`(全部实例)、`ordinal()`(声明顺序,从 0 起)、`name()` 等方法;enum 都继承自 `java.lang.Enum`:

```java
public enum Spiciness {
    NOT, MILD, MEDIUM, HOT, FLAMING
}

for (Spiciness s : Spiciness.values())
    System.out.println(s + ", ordinal " + s.ordinal());
/* Output:
NOT, ordinal 0
MILD, ordinal 1
...
*/
```

**static import** 配合 enum 可以少写类名:

```java
import static Spiciness.*;

Spiciness howHot = MEDIUM;   // 不必写 Spiciness.MEDIUM
```

enum 已内置 `equals()`/`hashCode()`,可以直接用于 Set/Map;`toString()` 返回名字;`Enum.valueOf(Class, name)` 按名字反查;`compareTo()` 按声明顺序比较。

## 2. 在 enum 中添加方法(Adding methods to an enum)

enum 可以有自己的字段、构造器(构造器必须是 private/package-private,且在实例列表**之后**)、方法:

```java
public enum OzWitch {
    // 实例必须最先出现,之后才允许其他元素:
    WEST("Miss Gulch, aka the Wicked Witch of the West"),
    NORTH("Glinda, aka the Witch of the North"),
    EAST("Wicked Witch of the East, wearer of the Ruby " +
            "Slippers, crushed by Dorothy's house"),
    SOUTH("Good by inference, but missing");   // 分号结束实例列表

    private String description;

    OzWitch(String description) {              // 构造器
        this.description = description;
    }

    public String getDescription() { return description; }

    public static void main(String[] args) {
        for (OzWitch witch : OzWitch.values())
            System.out.println(witch + ": " + witch.getDescription());
    }
}
```

### 覆盖 enum 的方法

可以覆盖 `toString()` 等,给每个常量生成自己的描述:

```java
public enum SpaceShip {
    SCOUT, CARGO, TRANSPORT;

    @Override
    public String toString() {
        String id = name();
        String lower = id.substring(1).toLowerCase();
        return id.charAt(0) + lower;
    }
}
```

## 3. switch 中的 enum(enums in switch statements)

switch 正是为 enum 准备的:case 里**只写常量名,不写类名**(编译器从 switch 表达式推断类型):

```java
public class Burrito {
    Spiciness degree;

    public Burrito(Spiciness degree) { this.degree = degree; }

    public void describe() {
        System.out.print("This burrito is ");
        switch (degree) {
            case NOT:    System.out.println("not spicy at all."); break;
            case MILD:
            case MEDIUM: System.out.println("a little hot.");     break;
            case HOT:
            case FLAMING:
            default:     System.out.println("maybe too hot.");
        }
    }
}
```

enum 的一个重要设计意图:**消除 switch 的"魔法数字"散落**。方法的返回值是 enum 时,switch 可以直接覆盖全部分支。

## 4. values() 的神秘之处(The mystery of values())

`values()` 很特殊:它是编译器**合成(synthesized)**的静态方法,`Enum` 类里根本没有它——所以把 enum 向上转型为 `Enum` 后就调不到 values() 了。绕过办法:通过 Class 对象查询:

```java
Enum e = Spiciness.MEDIUM;
// e.values();                  // 编译错误:Enum 里没有这个方法
for (Spiciness s : e.getClass().getEnumConstants())   // 反射路径可用
    System.out.println(s);

// 另一个静态工厂:得到全部实例
// 探究实现:编译器生成的 $VALUES 数组 + clone
```

values() 的实现是返回内部 `$VALUES` 数组的**拷贝**(防止外部修改)。`getEnumConstants()` 是等价的反射入口。

## 5. 实现,而非继承(Implements, not inherits)

enum 已经隐式继承 `java.lang.Enum`,Java 单继承因此**不能再 extends 别的类**;但可以实现任意多个接口:

```java
enum CartoonCharacter implements Generator<CartoonCharacter> {
    SLAPPY, SPANKY, PUNCHY, SILLY, BOUNCY, NUTTY, STUPID;

    private Random rand = new Random(47);

    @Override
    public CartoonCharacter next() {           // 实现生成器接口
        return values()[rand.nextInt(values().length)];
    }
}
```

## 6. 随机选择(Random selection)

配合接口可以做出"随机 enum 工具":

```java
class Enums {
    private static Random rand = new Random(47);

    public static <T extends Enum<T>> T random(Class<T> ec) {
        return random(ec.getEnumConstants());
    }

    public static <T> T random(T[] values) {
        return values[rand.nextInt(values.length)];
    }
}

// 使用:
Activity activity = Enums.random(Activity.class);
```

## 7. 用接口组织(Using interfaces for organization)

一个接口里放"一组相关的 enum"(接口的嵌套 enum 天然 public static),再把多个这样的接口装进一个大接口,形成**分类体系**:

```java
public interface Food {
    enum Appetizer implements Food {
        SALAD, SOUP, SPRING_ROLLS;
    }

    enum MainCourse implements Food {
        LASAGNE, BURRITO, PAD_THAI, LENTILS, HUMMOUS, VINDALOO;
    }

    enum Dessert implements Food {
        TIRAMISU, GELATO, BLACK_FOREST_CAKE, FRUIT;
    }
}

// 一个方法同时接受所有种类(Food 是共同接口):
public static void main(String[] args) {
    for (Course course : Course.values()) {   // Course 里也用 enum 关联 Food 子类型
        Food food = course.randomSelection();
        System.out.println(food);
    }
}
```

## 8. 用 EnumSet 替代标志(Using EnumSet instead of flags)

要求"一组标志"(多个状态同时成立)时,C 时代的做法是 int 位标志;Java 的答案 **EnumSet**——与 enum 配套的 Set 实现,内部用**位向量**(long 数组)表示,极快且类型安全:

```java
import java.util.EnumSet;

public enum AlarmPoints {
    STAIR1, STAIR2, LOBBY, OFFICE1, OFFICE2, OFFICE3, OFFICE4, BATHROOM,
    UTILITY, KITCHEN
}

EnumSet<AlarmPoints> points1 = EnumSet.noneOf(AlarmPoints.class); // 空
points1.add(AlarmPoints.BATHROOM);
points1.addAll(EnumSet.of(AlarmPoints.STAIR1, AlarmPoints.STAIR2));

EnumSet<AlarmPoints> points2 = EnumSet.allOf(AlarmPoints.class);        // 全部
EnumSet<AlarmPoints> points3 = EnumSet.range(AlarmPoints.OFFICE1, AlarmPoints.OFFICE4); // 区间
EnumSet<AlarmPoints> points4 = points3.complementOf(points2);           // 补集
EnumSet<AlarmPoints> points5 = EnumSet.copyOf(points3);                 // 拷贝
```

EnumSet 的设计哲学:**先按"是否需要集合语义"选择 Set;再因元素是 enum 而免费获得位运算般的性能**。工厂方法风格(noneOf/allOf/of/range)是因为 EnumSet 是抽象类,返回的是内部 CompactEnumSet/JumboEnumSet 实现。

## 9. EnumMap

键为 enum 的专用 Map,内部是**按 ordinal 索引的数组**,查找即数组访问:

```java
interface Command {
    void action();
}

EnumMap<AlarmPoints, Command> em = new EnumMap<>(AlarmPoints.class);
em.put(AlarmPoints.KITCHEN, () -> System.out.println("Kitchen fire!"));
em.put(AlarmPoints.BATHROOM, () -> System.out.println("Bathroom alert!"));

for (Map.Entry<AlarmPoints, Command> e : em.entrySet()) {
    System.out.print(e.getKey() + ": ");
    e.getValue().action();
}
```

与 EnumSet 同理:**命令分发/状态映射,键是 enum 时必选 EnumMap**,又快又不会"键序散乱"。

## 10. 常量相关的方法(Constant-specific methods)

enum 的每个常量可以**各自带方法体**——为每个实例提供不同行为,"让数据带上行为":

```java
public enum ConstantSpecificMethod {
    DATE_TIME {
        String getInfo() {
            return DateFormat.getDateTimeInstance().format(new Date());
        }
    },
    CLASSPATH {
        String getInfo() {
            return System.getenv("CLASSPATH");
        }
    },
    VERSION {
        String getInfo() {
            return System.getProperty("java.version");
        }
    };

    abstract String getInfo();   // 常量相关方法的"接口"

    public static void main(String[] args) {
        for (ConstantSpecificMethod csm : values())
            System.out.println(csm.getInfo());
    }
}
```

这本质是**每个常量一个匿名子类**。它比"switch 分发"更彻底:添加常量时行为就地定义,不用改远处的 switch。

> 代价:行为定义在 enum 内部,若行为较大则可读性下降。Java 8 后"enum 常量 + lambda 字段"是更轻的替代。

### 责任链(Chain of Responsibility with enums)

用常量相关方法实现责任链:每个常量尝试处理输入,处理不了交给 next:

```java
enum MailHandler {
    GENERAL_DELIVERY {
        boolean handle(Mail m) { return /* 普通信处理 */ false; }
    },
    MACHINE_SCAN {
        boolean handle(Mail m) { return /* 机器扫描 */ false; }
    },
    VISUAL_INSPECTION {
        boolean handle(Mail m) { return /* 人工检查 */ false; }
    };

    abstract boolean handle(Mail m);

    static void handle(Mail m) {
        for (MailHandler handler : values())     // 依次尝试:责任链
            if (handler.handle(m))
                return;
        System.out.println("Dead letter: " + m);
    }
}
```

### 状态机(State machines with enums)

enum 天然适合表达**状态**:输入 enum + 状态 enum,按"当前状态 × 输入"转移:

```java
public enum Input {
    NICKEL(5), DIME(10), QUARTER(25), DOLLAR(100),
    TOOTHPASTE(200), CHIPS(75), SODA(100), SOAP(50),
    ABORT_TRANSACTION {                          // 无金额的输入
        public int amount() { throw new RuntimeException(); }
    };

    int value;

    Input() {}
    Input(int value) { this.value = value; }

    int amount() { return value; }               // 常量相关方法 + 字段
}
```

原书用这套输入实现了自动售货机状态机(类别 Category enum + 状态转移),骨架即"enum 表状态、EnumMap 表转移、switch/常量方法表动作"。

## 11. 多路分发(Multiple dispatching)

"一次方法调用**根据两个对象的类型**决定行为"就是**多路分发(multiple dispatch)**。Java 的方法绑定是单路的:调用 `a.process(b)`,只会依据 a 的静态类型(重载)与动态类型(覆盖)选择方法,b 的类型不参与分发。要实现双路分发,得手动补第二路。

例:石头剪刀布,`Item.compete(Item)` 的结果取决于**双方**的类型。

### 用 enum 分发(Dispatching with enums)

第一路靠动态绑定,第二路在方法体里 switch 对方:

```java
public enum RoShamBo {
    ROCK, PAPER, SCISSORS;

    Outcome compete(RoShamBo opponent) {         // 第一路:this 的类型
        switch (opponent) {                      // 第二路:switch 对方
            case ROCK:
                return this == ROCK ? Outcome.DRAW : (this == PAPER ? Outcome.WIN : Outcome.LOSE);
            // ...
        }
        return null;
    }
}
```

### 用常量相关方法(Using constant-specific methods)

每个常量各自实现 ` compete `,内部再 switch 对方——第一路由常量方法完成:

```java
public enum RoShamBo2 implements Competitor<RoShamBo2> {
    PAPER {
        public Outcome compete(RoShamBo2 it) {
            switch (it) {
                case PAPER: return Outcome.DRAW;
                case SCISSORS: return Outcome.LOSE;
                default: return Outcome.WIN;
            }
        }
    },
    SCISSORS { /* ... */ },
    ROCK { /* ... */ };
}
```

### 用 EnumMap 分发(Dispatching with EnumMaps)

把"我 → 对手 → 结果"的二维表拆成 EnumMap 嵌套,数据驱动、无 switch:

```java
private static EnumMap<RoShamBo, EnumMap<RoShamBo, Outcome>>
        table = new EnumMap<>(RoShamBo.class);

static {
    for (RoShamBo it : RoShamBo.values())
        table.put(it, new EnumMap<>(RoShamBo.class));
    table.get(RoShamBo.ROCK).put(RoShamBo.SCISSORS, Outcome.WIN);
    table.get(RoShamBo.ROCK).put(RoShamBo.PAPER, Outcome.LOSE);
    // ...
}

public Outcome compete(RoShamBo opponent) {
    return table.get(this).get(opponent);   // 两次数组级查表完成双路分发
}
```

### 用二维数组(Using a 2-D array)

最极端的优化:预先算好 `Outcome[我.ordinal][对方.ordinal]` 二维表,`compete()` 只做一次数组访问。查表最快,但表与枚举顺序强耦合、可读性最差。

四种方案的取舍:switch 简单直接;常量方法把行为收进常量;EnumMap 数据驱动、可读且快;二维数组极致性能。**优先 EnumMap**,性能敏感处再降级到数组。
