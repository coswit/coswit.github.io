# 第3章 插入模式（Insert mode）

> 插入模式只有一个用途：**输入文本**。本章技巧围绕两件事：怎么更正错误、怎么少在两种模式间来回折腾。

## 在插入模式中即时更正错误

| 按键 | 用途 |
| ---- | ---- |
| `<C-h>` | 删除前一个字符（同退格） |
| `<C-w>` | 删除前一个单词 |
| `<C-u>` | 删除到行首 |

- 这三个键不仅在插入模式有效，在 Vim 命令行（`:` `/` `?`）以及 bash 中同样可用，值得形成肌肉记忆。

## 不用 Esc 键返回普通模式

- `<C-[>` 是 Esc 的原生等价键（更顺手）；
- 常见做法：映射连续按键退出插入模式：

```bash
inoremap jk <Esc>
```

## 插入-普通模式（Insert-Normal 模式）

- `<C-o>`：**执行一条普通模式命令后自动返回插入模式**。
- 典型用法：输入过程中想把屏幕居中——`<C-o>zz`，然后继续输入，无需离开插入模式。

## 不离开插入模式，粘贴寄存器内容

- `<C-r>{register}`：把指定寄存器内容插入光标处。

```bash
<C-r>"    " 插入无名寄存器（上次删除/复制的文本）
<C-r>0    " 插入复制专用寄存器（上次 y 的内容）
```

- `<C-r><C-p>{register}`：按原义粘贴，避免自动缩进捣乱（适合代码片段）。
- **表达式寄存器 `=`**：执行一段 Vim 脚本并把结果插入文本：

```bash
<C-r>=6*35<CR>      " 插入 210
<C-r>=@%<CR>        " 插入当前文件名
```

## 插入不常使用的字符（insert unusual characters）

| 按键 | 用途 |
| ---- | ---- |
| `<C-v>{三位数字}` | 按十进制编码插入，如 `<C-v>065` → `A` |
| `<C-v>u{四位十六进制}` | 插入 Unicode，如 `<C-v>u00bf` → `¿` |
| `<C-v>{字符}` | 按原义插入下一个字符（如插入 `<Tab>` 本身） |
| `<C-q>` | Windows 上 `<C-v>` 被占用时用它替代 |
| `ga` | 显示光标字符的十进制/十六进制/八进制编码（普通模式，用于反查） |

## 用二合字母（digraph）插入特殊字符

- `<C-k>{char1}{char2}`：用两个字符"拼"出一个特殊字符：

| 输入 | 结果 |
| ---- | ---- |
| `<C-k>?I` | `¿` |
| `<C-k>12` | `½` |
| `<C-k>e'` | `é` |

- `:digraphs` 查看全部对照表。

## 用替换模式（Replace mode）修改现有文本

- `R` 进入**替换模式**：输入的每个字符覆盖原有字符（而不是插入），退格恢复原字符；
- `gR` 进入**虚拟替换模式**（Virtual Replace mode）：把制表符当成一串空格对待，逐字符替换，处理带 Tab 的行时行为更直观。
- 场景：固定宽度的表格/表单数据中"对位覆盖"比插入更合适；日常大多数修改仍是删除 + 插入（`c`/`s`）更高效。

## 进入插入模式命令一览（便于构造可重复修改）

| 命令 | 用途 | 等效 |
| ---- | ---- | ---- |
| `i` / `a` | 光标前 / 后插入 | |
| `I` / `A` | 行首第一个非空字符前 / 行尾插入 | `^i` / `$a` |
| `o` / `O` | 下方 / 上方新开一行插入 | `A<CR>` / `ko` |
| `s` / `S` | 删除字符 / 整行后插入 | `cl` / `^C` |
| `C` | 删除到行尾后插入 | `c$` |
