# 第4章 可视模式（Visual mode）

> 可视模式 = **先选高亮选区，再执行操作**（点菜式）。它直观，但通常"操作符 + 动作命令"（报菜名式）更高效、更可重复。

## 深入理解可视模式

三种子模式：

| 命令 | 子模式 | 用途 |
| ---- | ------ | ---- |
| `v` | 面向字符的可视模式（characterwise） | 精确选字符 |
| `V` | 面向行的可视模式（linewise） | 整行整行地选 |
| `<C-v>` | 面向列块的可视模式（blockwise） | 矩形块（列）编辑 |

- `o`：切换高亮选区的活动端（active end，从头跳到尾、尾跳到头）；
- `gv`：重选上一次的高亮选区；
- 可视模式下按 `V`/`v`/`<C-v>` 可在子模式间切换；再按同一种则取消返回普通模式。
- 选好选区后：操作符（`d` `y` `c` `r` `>` `<` `gu` …）直接作用其上，执行完自动回到普通模式。

## 选择高亮选区：动作命令扩展选区

- 进入可视模式后，动作命令（`w` `e` `}` `/text<CR>` …）不再是移动，而是**扩展/收缩选区**；
- 例：`vi"` 选中一对双引号内的文本（不含引号）——`i"`/`a"` 等文本对象同样用于选区。

## 重复执行面向行的可视命令

可视模式命令同样可以被 `.` 重复，**面向行的命令**重复效果最稳定：

```bash
Vj      " 选中两行
>       " 增加缩进
.       " 再缩进一级（仍作用于两行）
```

## 尽可能用操作符命令，而不是可视命令

对比删除一个单词：`diw` vs `viwd`

- `diw` 的 `.`：作用于下一个完整单词（语义稳定）；
- `viwd` 的 `.`：作用于"与上次选区**同样大小**的文本"（从当前光标起算字符数），行为不可控。

结论：**当打算用 `.` 重复时，优先用"操作符 + 文本对象"而不是可视模式**。可视模式适合"一次性、需要眼见为实"的选择。

## 用面向列块的可视模式编辑表格

例：把表格中某几行的分隔符统一替换为 `|`：

```bash
<C-v>3j   " 从当前行向下选一个字符宽的列块
r|        " 整列同时替换为 |
```

- `r` 对列块整体替换；`x`/`d` 整列删除。

## 修改列文本

- `<C-v>` 选中矩形块后按 `c`：只删除选中块并进入插入模式；
- 输入新文本，按 `<Esc>`——**这段文本会同时插入到每一行的相同位置**；
- 同理 `I`（块前行插入）和 `A`（块后追加）也是块级生效。

## 在长短不一的高亮块后添加文本

关键点：**`$` 会让列块的右边界扩展到每行的行尾**（即使各行长度不一）。

```bash
<C-v>jj$   " 选三行的"到行尾"块
A;         " 在块（=每行行尾）后输入
<Esc>      " 分号出现在三行行尾
```

反过来在行首插入注释：

```bash
<C-v>jjI#<Esc>   " 三行行首同时加 #
```
