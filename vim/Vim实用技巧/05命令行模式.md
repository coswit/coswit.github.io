# 第5章 命令行模式

> 命令行模式（Command-Line mode，即 Ex 命令）的杀手锏是**范围（range）**：一条命令即可作用于多行、可视选区甚至整个文件，批量处理时远比普通模式高效。`:h ex-cmd-index` 可查全部命令。

## 结识命令行模式

- `:` 进入命令行，`<CR>` 执行，`<Esc>` 取消；
- 输入过程中：`<C-w>` 删前一个词、`<C-u>` 删到行首、`<C-r>{register}` 插入寄存器内容（同插入模式）。

## 在一行或多个连续行上执行命令

地址与范围语法：

| 地址/范围 | 含义 |
| --------- | ---- |
| `1` / `$` / `0` | 第 1 行 / 最后一行 / 第一行之前的虚拟行 |
| `.` | 当前行 |
| `m`（`'m`） | 标记 m 所在行 |
| `'<` / `'>` | 上次可视选区的首行/末行 |
| `%` | 整个文件（= `1,$`） |
| `2,5` / `.,$` / `.,+2` | 行号组合与偏移 |

常用 Ex 命令速览：

| 命令 | 全名 | 用途 |
| ---- | ---- | ---- |
| `:p` | print | 回显行 |
| `:d` | delete | 删除行 |
| `:m` | move | 移动行 |
| `:co`/`:t` | copy | 复制行 |
| `:j` | join | 连接行 |
| `:nor` | normal | 对每行执行普通模式命令 |
| `:s` | substitute | 替换（第14章） |
| `:g` | global | 对匹配行执行命令（第15章） |

## 用 `:t` 和 `:m` 命令复制、移动行

`:[range]t{address}`：把 range 各行复制到 address 之后；`:m` 同理但为移动。

| 命令 | 效果 |
| ---- | ---- |
| `:6t.` | 把第 6 行复制到当前行下方 |
| `:t6` | 把当前行复制到第 6 行下方 |
| `:t$` | 把当前行复制到文件末尾 |
| `:'<,'>t0` | 把高亮选区复制到文件开头 |
| `:m$` | 把当前行移到文件末尾 |
| `:m+2` | 把当前行下移两行（`:+2m-1` 等价思路） |

- 交换相邻两行的思路：`:m-1`（把下一行上移）或 `ddp`。

## 用 `:normal` 在指定范围上执行普通模式命令

`:[range]normal {commands}`——对范围内**每一行**执行同一串普通模式命令：

```bash
:%normal A;       " 每行行尾加分号
:%normal i//      " 每行行首加 //
:2,5normal @a     " 第2~5行执行寄存器 a 中的宏
:%normal .        " 对每行重复上次修改
```

- 如果包含特殊字符（如 `<Esc>`），可用 `:execute "normal! ..."` 转义；批量执行宏的细节见第11章。

## 重复上次的 Ex 命令

- `@:` 重复上一次执行的命令行命令（之后还可用 `@@` 连续重复）；
- 对照普通模式：`.` 重复修改、`;`/`n` 重复查找、`@:` 重复 Ex 命令。

## 自动补全命令行

- `<C-d>`：显示可用的补全候选（如 `:col<C-d>` 列出所有 col 开头的命令）；
- `Tab`：补全并可在候选间前进（`<S-Tab>` 后退）。

## 把光标下的单词插入命令行

- `<C-r><C-w>`：把光标下的单词插入命令行——先定位再构造命令，天然适合 `:s` 或 `/`：

```bash
" 光标停在 foo 上：
:s/<C-r><C-w>/bar/g    " 等价于 :s/foo/bar/g（只打三个词）
```

## 回顾命令行历史：命令行窗口（command-line window）

- `q:` 打开**命令行窗口**（可编辑的历史列表）：像编辑文本一样修改历史命令，`<CR>` 执行所在行；
- `q/`、`q?` 分别打开查找历史窗口；
- 已在命令行中时按 `<C-f>` 可切换到命令行窗口继续编辑。

## 不离开 Vim 执行 shell 命令

| 命令 | 用途 |
| ---- | ---- |
| `:shell` | 进入子 shell（`exit` 返回 Vim） |
| `:!{cmd}` | 执行一次外部命令，如 `:!ls`、`:!mkdir %:h` |
| `:read !{cmd}` | 把命令**输出**读入当前缓冲区下方 |
| `:write !{cmd}` | 把缓冲区内容作为命令的**标准输入** |
| `:[range]!{filter}` | 用外部命令**过滤**指定范围 |

```bash
:2,$!sort -t',' -k2    " 第2行到末尾按第2列排序（CSV 排序）
:read !date            " 把 date 输出插入下一行
```

普通模式的 `!{motion}` 等价于范围过滤，如 `!ipsort` 对段落排序。

## 批处理模式（batch mode）

用 `-c` 链式执行命令，可脚本化处理文件（`-e -s` 静默、`-u NONE` 跳过配置）：

```bash
$ vim *.txt -c 'argdo %s/aaa/bbb/ge | update' -c 'qa!'
```

- 思路：`args` 圈定文件 → `:argdo` 逐个执行替换 → `update` 只回写有改动的文件（详见第6、14章）。
