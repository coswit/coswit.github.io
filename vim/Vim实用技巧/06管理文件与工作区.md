# 第6~7章 管理文件与工作区：buffer、窗口、标签页与打开保存

> Vim 用**缓冲区（buffer）**承载文件内容，窗口/标签页只是缓冲区的"视口"。理清 **buffer / window / tab page** 三层模型是用 Vim 管理多文件的基础；本章同时覆盖打开与保存文件（含 netrw 文件管理器与 sudo 救场）。

## 用缓冲区列表管理文件（buffer list）

每打开一个文件，就创建一个缓冲区：

| 命令 | 用途 |
| ---- | ---- |
| `:ls` | 查看缓冲区列表 |
| `:bprev` / `:bnext` / `:bfirst` / `:blast` | 前/后/首/末缓冲区 |
| `:buffer {N或文件名}` | 跳到指定缓冲区 |
| `:bdelete {N}`（`:bd!`） | 删除缓冲区（`!` 丢弃修改） |
| `<C-^>` | 在当前与"轮换缓冲区"（alternate buffer，`#`）间快速切换 |

`:ls` 常见标志：

| 标志 | 含义 |
| ---- | ---- |
| `%` | 当前缓冲区（current） |
| `#` | 轮换缓冲区（alternate，`<C-^>` 的切换目标） |
| `a` | 活动缓冲区（active，显示在窗口中） |
| `h` | 隐藏缓冲区（hidden，有修改但未显示） |
| `u` | 未列入列表的缓冲区（unlisted） |
| `+` | 有未保存的修改 |
| `=` | 只读缓冲区 |

**隐藏缓冲区与 'hidden'**：默认情况下，放弃未保存的缓冲区会被阻止；设置后可在缓冲区间自由切换而无需先保存：

```bash
:set hidden
```

## 用参数列表管理文件（argument list）

参数列表是比缓冲区列表更简单、更稳定的"文件集合"（跨会话可控，适合批量操作）：

| 命令 | 用途 |
| ---- | ---- |
| `:args` | 查看参数列表（`[file]` 标出当前项） |
| `:args a.txt b.txt` | 重新指定 |
| `:args *.txt` | 通配符展开 |
| `:args **/*.txt` | `**` 递归匹配子目录 |
| `:argdo {cmd}` | 对列表中每个文件执行命令 |

```bash
:args **/*.html
:argdo %s/<header>/<header class="header">/ge | update
:args! *.c        " args! 覆盖列表
```

## 用分割窗口组织工作区（split windows）

| 命令/按键 | 用途 |
| --------- | ---- |
| `<C-w>s` / `:split {file}` | 水平分割（上下） |
| `<C-w>v` / `:vsplit {file}` | 垂直分割（左右） |
| `<C-w>w` | 在窗口间轮换 |
| `<C-w>h/j/k/l` | 到左/下/上/右窗口 |
| `<C-w>H/J/K/L` | 把当前窗口移到最左/下/上/右侧 |
| `<C-w>=` | 所有窗口等分 |
| `<C-w>_` / `<C-w>|` | 当前窗口最大化（高/宽） |
| `{N}<C-w>_` | 高度设为 N 行 |
| `:clo[se]` | 关闭当前窗口 |
| `:on[ly]` | 只保留当前窗口 |

## 用标签页组织工作区（tab pages）

**标签页 ≠ 文件，而是容纳一组（可分割）窗口的工作区**——把不同任务的窗口布局分装到不同标签页：

| 命令/按键 | 用途 |
| --------- | ---- |
| `:tabedit {file}` | 在新标签页打开文件 |
| `<C-w>T` | 把当前窗口移到新标签页 |
| `:tabclose` / `:tabonly` | 关闭当前 / 只留当前标签页 |
| `{N}gt` / `gT` / `:tabnext {N}` | 切换标签页 |
| `:tabmove {N}` | 移动标签页位置（0 为最左） |

## 用 `:edit` 打开文件

- `:e{dit} {file}` 打开文件（相对当前工作目录）；`%:h` 展开为当前文件所在目录：

```bash
:e %:h/            " 打开当前文件所在目录
:e!                " 丢弃修改，重新载入当前文件
:e#                " 回到轮换缓冲区（同 <C-^>）
```

## 用 `:find` 打开文件（不必输入完整路径）

`:f[ind] {文件名片段}` 依据 `'path'` 选项搜索并打开：

```bash
:set path=app/**           " 把工程目录加进搜索路径（** 递归）
:find user_model.rb        " 直接按文件名打开，Tab 补全
```

- `:find` 与 `gf`（第9章）共享 `'path'`，是把 Vim 当 IDE 用的重要配置。

## 使用 netrw 管理文件系统

`:e .`（或 `:e {dir}`）打开内置文件管理器 **netrw**：

| 按键 | 用途 |
| ---- | ---- |
| `<CR>` | 打开文件/目录 |
| `-` | 到上级目录 |
| `%` | 新建文件 |
| `d` | 新建目录 |
| `R` | 重命名 |
| `D` | 删除 |

- netrw 既是文件浏览器，也是资源管理器（改名/删除/建目录），减少切换终端。

## 把文件保存到磁盘

| 命令 | 用途 |
| ---- | ---- |
| `:w` | 保存 |
| `:w {file}` | 另存为新文件（当前缓冲区不变） |
| `:sav[eas] {file}` | 另存并**切换**到新文件名的缓冲区 |
| `:w >> {file}` | 追加写入已有文件 |
| `:wall` / `:wqa` | 保存全部 / 保存并退出全部 |

## 以超级用户权限保存文件（忘记 sudo 的救场）

以普通用户打开了 root 文件，改完才发现没权限：

```bash
:w !sudo tee % > /dev/null
```

- 原理：`%` 展开为当前文件路径；`:w !cmd` 把缓冲区内容作为 stdin 交给命令；`sudo tee` 以 root 身份写回原文件。

## 三层模型总结

- **缓冲区（buffer）**：文件在内存中的副本（`:ls`）——内容的容器；
- **窗口（window）**：缓冲区的视口（可多窗口显示同一缓冲区）；
- **标签页（tab page）**：窗口的集合（工作区切换器）。

批量处理文件：缓冲区用 `:bufdo`，文件集合用 `:argdo`（推荐先 `:args` 圈定再 `:argdo`）。
