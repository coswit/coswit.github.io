# 第8~9章 移动与跳转：motion、text object 与跳转列表

> 动作命令（**motion**）既是"移动"，又是操作符的"宾语"——掌握越多动作命令，`d`/`y`/`c` 的威力越大。跳转列表（**jumplist**）与变更列表（**changelist**）则记住了你"去过哪里、改过哪里"。

## 按文件行还是屏幕行移动（file line / screen line）

一行很长被折行显示时，存在两套移动：

| 文件行（file line） | 屏幕行（screen line） |
| ------------------- | --------------------- |
| `j` / `k` | `gj` / `gk` |
| `0` / `^` | `g0` / `g^` |
| `$` | `g$` |

- 文件行 = 缓冲区里的真实行；屏幕行 = 折行后看到的一行；
- 编辑长段落文本时用 `g` 家族更符合直觉。

## 区分单词（word）与字串（WORD）

- **word**：由字母/数字/下划线构成，或"非空白字符连续串"（标点各自成词）；
- **WORD**：以空白分隔的连续非空白文本（字串）。

| 正向 | 反向 | 到词尾 |
| ---- | ---- | ------ |
| `w` 下一 word 首 | `b` 上一 word 首 | `e` 当前/下一 word 尾 |
| `W` 下一 WORD 首 | `B` 上一 WORD 首 | `E` 到 WORD 尾 |
| | `ge` 上一 word 尾 | `gE` 上一 WORD 尾 |

- 例：光标在 `(4)` 中的 `(` 上，`dw` 只删 `(`，`dW` 删 `(4)`——按需选择。

## 行内快速定位：`f`/`t`/`;`/`,`

| 按键 | 用途 | 重复/回退 |
| ---- | ---- | --------- |
| `f{char}` / `F{char}` | 行内下一个/上一个 char | `;` / `,` |
| `t{char}` / `T{char}` | 到 char 前/后 | `;` / `,` |

- `dt)` 删除到 `)` 之前；`ct"` 修改到 `"` 之前——配合 `;` 与 `.` 构成 `.` 范式（第1章）。

## 文本对象：按"语义单元"编辑（text object）

语法：`[i|a]{对象}`——`i` = inside（内部，不含分隔符/空白），`a` = around（含分隔符或一个尾随空格）。

| 文本对象 | 覆盖范围 |
| -------- | -------- |
| `iw` / `aw` | 单词（a 含尾随空格） |
| `iW` / `aW` | 字串（WORD） |
| `is` / `as` | 句子（sentence） |
| `ip` / `ap` | 段落（paragraph） |
| `i"` `a"` `i'` `` a` `` | 引号串（a 含引号） |
| `i(` `a(` `ib` `ab`（同 `[` `{`） | 括号块 |
| `i<` `a<` | 尖括号块 |
| `it` / `at` | HTML/XML 标签块 / 含标签 |

```bash
ci"      " 修改双引号内的内容
ci(      " 修改括号内表达式
dat      " 删除整个 <div>...</div>
yas      " 复制一整个句子
```

- 文本对象可独立于光标位置定位"最近的"单元，是构造可重复修改的首选（第2章）。

## 设置位置标记（mark）

- `m{a-z}`：当前缓冲区标记；`m{A-Z}`：跨缓冲区的全局标记；
- `'{mark}` 跳到标记所在行首，`` `{mark} `` 跳到精确位置。

常用**自动标记**：

| 标记 | 位置 |
| ---- | ---- |
| `` `` `` | 上一次跳转之前的位置 |
| `` `. `` | 上一次修改的位置 |
| `` `^ `` | 上一次插入模式退出的位置 |
| `` `[ `` / `` `] `` | 上次修改/粘贴的起止位置 |
| `'<` / `'>` | 上次可视选区首/末行 |

## 在匹配的括号间跳转

- `%`：在 `(` `)`、`[` `]`、`{` `}` 配对间跳转（光标需在括号上）；
- 扩展匹配对：

```bash
:set matchpairs+=<:>    " 让 % 也配对尖括号
```

- 技巧：把光标移到某括号后按 `%` 再按 `` `` `` 可回到原位。

## 遍历跳转列表（jumplist）

任何"大跨度移动"都会记入跳转列表（`:jumps` 查看）：

| 按键 | 用途 |
| ---- | ---- |
| `<C-o>` | 后退到上一个跳转位置 |
| `<C-i>`（Tab） | 前进到下一个跳转位置 |
| `` `` `` | 在最近两个跳转位置间往返 |

构成跳转的典型命令：`'mark` `` `mark ``、`G`、`gg`、`{N}G`、`%`、`(`/`)`、`{`/`}`、`H`/`M`/`L`、`/` `?` `n` `N`、以及打开新文件。
**不构成跳转**的：`j` `k` `w` `e` 等日常小幅移动——它们不污染跳转列表。

## 遍历变更列表（changelist）

| 按键/命令 | 用途 |
| --------- | ---- |
| `g;` | 跳到上一个修改位置 |
| `g,` | 跳到下一个修改位置 |
| `:changes` | 查看变更列表 |

- 典型场景：刚在某处改完又跳走，`g;` 直接回去；
- `` `. `` 等价于跳到"最后一次修改"的精确位置；`'.` 为其行首版本。

## 跳转到光标下的文件（`gf`）

- `gf`：打开光标所在文件名对应的文件（常用于 `include`/`import` 路径）；
- 相关选项：

```bash
:set suffixesadd+=.rb     " gf 时自动尝试的后缀
:set path+=lib/**         " 相对路径解析的搜索路径（与 :find 共享）
```

## 用全局标记在文件间跳转

- 小写标记 `ma` 只在当前缓冲区有效；**大写标记 `mA` 跨文件有效**；
- 工作流：开始修 bug 前先 `mA`，之后无论跳到多少文件，`'A`/`` `A `` 一步回到出发点；
- `:marks` 查看全部标记，`:delmarks {mark}` 删除。

## 移动小结

| 目的 | 命令 |
| ---- | ---- |
| 行内字符级 | `f` `t` `F` `T` + `;` `,` |
| 文档级模式 | `/` `?` + `n` `N`（第13章） |
| 语义单元 | 文本对象 + 操作符 |
| 精确往返 | 标记 / `` `` `` |
| 历史回溯 | `<C-o>` `<C-i>` `g;` `g,` |
| 跨文件 | `gf`、`:find`、全局标记、`<C-^>` |
