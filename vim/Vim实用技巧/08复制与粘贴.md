# 第10章 复制与粘贴：寄存器（register）

> Vim 的删除、复制（**yank**）、粘贴（**put**）都通过寄存器完成。理解寄存器族谱，"复制的东西被删除覆盖了"这类困惑就消失了。

## 结识 Vim 的寄存器

| 寄存器 | 英文名 | 用途 |
| ------ | ------ | ---- |
| `""` | unnamed（无名寄存器） | `x` `s` `d` `c` `y` 的默认目标，`p` 的默认来源 |
| `"0` | yank（复制专用寄存器） | **只有 `y`** 会写入，删除不碰它 |
| `"-` | small delete（小删除寄存器） | 少于一行的删除（`x` `dw` 等） |
| `"a`~`"z` | named（有名寄存器） | 显式指定 `"ayy`；**大写 `"A` 为追加** |
| `"_` | black hole（黑洞寄存器） | 只进不出，删除但不影响其他寄存器 |
| `"+` | system clipboard（系统剪贴板） | 与外部程序交换 |
| `"*` | primary selection（X11 主选区） | Linux 选中即复制的内容 |
| `"=` | expression（表达式寄存器） | 求值后插入（第3章） |
| `"/` | last search（查找寄存器） | 上次查找模式 |
| `"%` | current file（文件名寄存器） | 当前文件名 |
| `".` | last insert（插入寄存器） | 上次插入模式输入的内容 |
| `":` | last command line（命令行寄存器） | 上次执行的 Ex 命令 |

- `"{register}` 前缀指定读/写哪个寄存器：`"ayiw` 复制词到 a；`"bp` 粘贴 b；
- `:reg[isters]`（可带名字：`:reg a b`）查看内容。

## 基本操作：yank 与 put

| 命令 | 用途 |
| ---- | ---- |
| `y{motion}` / `yy` | 复制到无名寄存器（同时写 `"0`） |
| `p` / `P` | 粘贴到光标后/前（行级则粘贴到下/上一行） |
| `gp` / `gP` | 粘贴并把光标移到**粘贴内容之后**（方便连续 `.` 或多次粘贴） |
| `xp` | 交换光标处两个字符 |
| `yyp` | 复制当前行到下一行 |
| `ddp` | 交换当前行与下一行 |

## 复制专用寄存器 `"0`：复制内容不怕被覆盖

问题：`yiw` 复制的词在随后的 `d{motion}` 中被无名寄存器覆盖。
解决：复制的副本**同时**存在 `"0` 里：

```bash
yiw      " 复制 foo（""与"0 都有 foo）
jdd      " 删除一行（"" 被覆盖，"0 仍是 foo）
"0p      " 粘贴的仍是 foo
```

## 黑洞寄存器 `"_`：删除而不污染

```bash
"_diw    " 删除单词但不进入无名寄存器（接着 p 粘贴的仍是之前的内容）
```

适合"先删掉废文本，再粘贴新文本"的场景。

## 用有名寄存器暂存多份内容

```bash
"ayy     " 当前词/行存入 a
"Ayy     " 用大写寄存器名：追加写入 a
"ap      " 粘贴 a
```

- 宏也用同一批寄存器（第11章），注意别互相覆盖。

## 与系统剪贴板交互（system clipboard）

```bash
"+yy     " 复制当前行到系统剪贴板
"+p      " 从系统剪贴板粘贴
:set clipboard=unnamed    " 让 "" 直接映射到 "+（Linux 常用 clipboard=unnamedplus）
```

- 判断 Vim 是否支持剪贴板：`vim --version | grep clipboard`（需要 `+clipboard`）。

## 可视模式下的 p：交换文本利器

可视模式下 `p` 会**用寄存器内容替换选区**，被替换的旧内容又进入无名寄存器——天然适合"滚动交换"：

```bash
" 交换两个单词 foo 与 bar：
" 1. 光标在 foo 上：yiw
" 2. 光标移到 bar 上：viwp    （bar 进入 ""，foo 顶替 bar）
" 3. 光标移回原 foo 位置：viwp（粘贴 bar）
```

## 插入模式中粘贴（回顾）

- `<C-r>{register}` 快速粘贴；多行文本用 `<C-r><C-p>{register}` 按原义粘贴，避免自动缩进/注释前缀捣乱（`:set paste` 也可整体关闭格式化）。
