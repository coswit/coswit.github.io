# 第11章 宏（macro）：把重复工作录下来

> 宏 = 录制到寄存器里的一串按键。`.` 只能重复"一次修改"，宏能重复"一系列修改"，并且能在多行/多文件上批量执行。

## 录制与执行

| 操作 | 按键 |
| ---- | ---- |
| 开始/停止录制到寄存器 a | `qa` …… `q` |
| 执行寄存器 a 中的宏 | `@a` |
| 重复上一次执行的宏 | `@@` |
| 查看录制内容 | `:reg a` |
| 清空寄存器 a | `qaq`（录制空宏） |

例：给若干行行尾统一加逗号：

```bash
qa          " 录制到 a
A,<Esc>     " 行尾加逗号
j           " 移到下一行（关键！）
q           " 停止
3@a         " 对接下来 3 行执行（或不断 @@）
```

## 录制的规范：保证宏可以连续执行

一个"自律"的宏要满足三点：

1. **光标位置规范化**：每轮开始先把光标放到确定位置（通常 `0` 或 `^`）；
2. **用可重复的定位方式**：`f{char}`+`;`、`/pattern<CR>`+`n` 搜索定位，不要依赖固定次数的 `w w w`；
3. **结尾把光标送到下一轮的起点**（如 `j`），使 `@@` 能自动续跑。

## 串行（serial）还是并行（parallel）执行

- **串行**：`{N}@a` 或连按 `@@`——宏按顺序逐条执行，**一旦某行失败立即停止**（适合"必须一口气做完、出错要停"的任务）；
- **并行**：对范围内每一行独立执行——某行失败不影响其他行：

```bash
:%normal @a            " 对整个文件每行执行宏 a
:'<,'>normal @a        " 对高亮选区执行
:g/pattern/normal @a   " 只对匹配 pattern 的行执行（第15章）
```

- 例子：只给包含 TODO 的行行尾加分号：`:g/TODO/normal @a`。

## 给宏追加内容（纠错不必重录）

- `qA`（大写寄存器名）在 a 的**末尾追加**录制；
- 若已按 `q` 停后发现漏了一步，直接 `qA` 补录再 `q` 即可。

## 编辑宏

宏就是寄存器里的普通文本，可以粘贴出来改再存回去：

```bash
:put a      " 把宏的内容粘贴成一行文本
" ……编辑这一行……
0           " 回到行首
"ay$        " 从行首 yank 到行尾，重新存入 a
```

## 递归宏（recursive macro）：执行到文件尾

先清空寄存器，再在宏的结尾调用它自己：

```bash
qaq                 " 清空 a
qa                  " 开始录制
0f)x                " 示例修改步骤
j
@a                  " 结尾递归调用（此时 a 为空，不执行）
q                   " 停止后 a 才包含完整宏
@a                  " 启动：自顶向下跑到文件尾（失败自动停止）
```

## 宏与 `.` 的选择

- 一次修改的重复 → `.`；
- 一串动作的重复 → 宏；
- 跨文件批量执行 → `:argdo normal @a`（先 `:args` 圈定文件，第6章）。
