# 第12~13章 正则模式（\v 与 \V）与查找（search）

> Vim 正则的元字符转义随 magic 级别而异：`\v`（very magic）让所有元字符生效，`\V`（very nomagic）按原义匹配。本书约定：**查找域统一以 `\v` 开头**。

## \v 模式开关（very magic）：所有元字符生效

```bash
/\v"\w+"            " 匹配一对双引号中的单词
/\v<\d+>            " 匹配数字（< > 为单词边界 word boundary）
/\v(\w+)_(\w+)      " 捕获两组，替换时用 \1 \2
```

- `\v` 之后 `() [] {} + ? * | < > ^ $` 等全部按正则元字符解释，**无需反斜杠转义**；
- `:s` 的分隔符可换成熟字符：`:%s#\v"\w+"#XXX#g`。

## \V 模式开关（very nomagic）：按原义匹配（literal）

```bash
/\Va.k.a.           " 查找字面文本 a.k.a.，无需转义点号
```

- `\V` 之后**只有反斜杠 `\` 有特殊含义**——要匹配元字符本身时才写 `\.` `\*`；
- 查找"文件名、URL、价格（如 $3.99）"等含大量特殊字符的文本时最省心。

## 查找域与替换域的元字符是两套规则

**查找域（pattern）**：`\v` / `\V` 控制模式强度；`\zs`/`\ze` 圈定匹配边界。

**替换域（replacement）**：

| 符号 | 含义 |
| ---- | ---- |
| `\r` | 插入换行符 |
| `\n` | 插入空字符 NULL（历史遗留——与查找域里"匹配行尾"的 `\n` 含义不同！） |
| `\t` | 插入 Tab |
| `\\` | 插入反斜杠本身 |
| `\1`~`\9` | 第 n 个捕获组（capture group） |
| `\0` 或 `&` | 整个匹配（`&` 字面量需写 `\&`） |
| `~` | 上一次替换域的内容 |

## 用圆括号捕获子匹配

```bash
/\v(\w+)_(\w+)              " 分组捕获
:%s/\v(\w+)_(\w+)/\2_\1/g   " 交换下划线两侧
```

- `( )` 在 `\v` 下无需转义；只分组不捕获用 `%(...)`。

## 结识查找命令

| 命令 | 用途 |
| ---- | ---- |
| `/{pattern}<CR>` | 正向查找 |
| `?{pattern}<CR>` | 反向查找 |
| `n` / `N` | 跳到下一处 / 上一处（方向随 `/` `?`） |
| `/<CR>` / `?<CR>` | 按原方向 / 反方向重复上次查找 |
| `q/` | 打开查找历史窗口（可编辑再执行） |

## 高亮查找匹配项（hlsearch / incsearch）

```bash
:set hlsearch    " 高亮所有匹配（hls）
:set incsearch   " 边输入边跳转预览（强烈建议，ics）
:noh[lsearch]    " 临时清除高亮（下次查找自动恢复）
```

常见映射：把回车空闲时用作清除高亮：

```bash
nnoremap <silent> <CR> :noh<CR><CR>
```

## 基于单词的查找：`*` 与 `#`（whole word search）

| 按键 | 用途 |
| ---- | ---- |
| `*` / `#` | 正向/反向查找光标下的**整个单词**（自动加词边界） |
| `g*` / `g#` | 同上但不要求词边界（可匹配子串） |

- `*` 等价于 `/\<<C-r><C-w>\><CR>`：光标下单词自动成为查找模式；
- `*` 后接 `n`/`N` 导航 + `cw`/`.` 批量改名——贯穿全书的标准工作流。

## 统计匹配个数

```bash
:%s/pattern//gn    " n 标志：只统计不替换，报告 "N matches on M lines"
```

- 动手批量替换前先跑一遍，心里有数（详见第14章标志位）。

## 标明匹配的边界：`\zs` 与 `\ze`

只把"真正关心的部分"算作匹配：

```bash
/\v"\zs\w+\ze"     " 只高亮引号内的单词（引号用于定位但不参与匹配）
```

- 好处：与 `n`、`.` 配合时，`cw` 修改的范围正好是 `\zs`~`\ze` 之间；替换命令也只动这一段。

## 大小写敏感性（ignorecase / smartcase）

```bash
:set ignorecase    " 忽略大小写（ic）
:set smartcase     " 模式含大写字母时自动区分大小写（scs，需配合 ic）
```

- 模式内临时覆盖：`\c` 强制忽略、`\C` 强制区分（优先于选项设置）。

## 约定总结

1. 查找域以 `\v` 起头，像写现代正则一样写；
2. 长串字面文本用 `\V`，只在真正特殊字符前加 `\`；
3. 替换域记住 `\r`（换行）不是 `\n`；
4. 复用上次的模式：`/<CR>`，或 `:s//new/` 中的**空模式**即代表上次查找模式（第14章）；
5. 在多个文件中查找交给 grep / vimgrep / Quickfix（第17、18章）。
