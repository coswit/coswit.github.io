# 第14章 替换（substitute）

> `:substitute` 是批量修改的主力：`:[range]s/{pattern}/{replacement}/[flags]`。核心是模式复用、标志位（flags）与确认节奏。

## 结识 substitute 命令

```bash
:%s/pattern/replacement/g
```

常用标志（flags）：

| 标志 | 含义 | 用途 |
| ---- | ---- | ---- |
| `g` | global | 替换一行内**所有**匹配（缺省只换第一个） |
| `c` | confirm | 逐个确认 |
| `e` | suppress errors | 屏蔽"未找到匹配"的报错（批量脚本必备） |
| `i` / `I` | ignore / match case | 强制忽略 / 区分大小写 |
| `n` | count only | 只统计匹配数，不替换 |
| `&` | keep flags | 保留上次的标志位 |

- 分隔符可换：`:%s#foo/bar#baz#` 处理含 `/` 的文本更省事。

## 空模式 = 复用上次的查找模式

```bash
/foo<CR>          " 先查找（可以先 n/N 检查效果）
:%s//BAR/g        " 模式留空：直接复用上面的 foo
```

- `<C-r>/` 可在命令行中显式插入上次查找模式。

## 重复替换：`&`、`g&` 与 `@:`

| 命令 | 等效 | 用途 |
| ---- | ---- | ---- |
| `&` | `:s//~/`（无标志） | 在当前行重复上次替换（不带 g） |
| `g&` | `:%s//~/&` | **整个文件**重复上次替换（保留标志） |
| `:@:` | | 重复上次 Ex 命令（不限 :s） |

## 用查找 + `.` 手动替换（无须确认界面）

```bash
/target<CR>
cwreplaced<Esc>
n      " 下一处（跳过不想改的）
.      " 重复修改
```

- 比 `:s///gc` 快：改/不改的决定由 `.`/`n` 节奏自己掌握（第1章 `.` 范式）。

## 逐个确认替换（confirm 标志）

`:s/target/replacement/gc` 后每处匹配弹出提示：

| 按键 | 含义 |
| ---- | ---- |
| `y` | yes：替换本处，继续 |
| `n` | no：跳过本处 |
| `a` | all：替换本处并**替换余下全部** |
| `q` | quit：退出 |
| `l` | last：替换本处后退出 |
| `<C-e>` / `<C-y>` | 向下 / 向上滚动查看上下文 |

## 替换域中的特殊字符（回顾第12章）

`\r` 换行、`\t` Tab、`\1`~`\9` 捕获组、`\0`/`&` 整个匹配、`\\` 反斜杠、`~` 上次替换域。

大小写转换（替换域专属）：

| 符号 | 含义 |
| ---- | ---- |
| `\u` / `\l` | 下一个字符大写 / 小写（upper / lower） |
| `\U` / `\L` | 后续字符全大写 / 全小写，直到 `\E` 或替换结束 |

```bash
:%s/\v(.)(\w*)/\u\1\L\2/g    " 每个单词首字母大写，其余小写
```

## 在替换域中执行表达式（`\=`）

替换域以 `\=` 开头时作为 Vim 脚本表达式求值，`submatch(0)` 为整个匹配、`submatch(n)` 为捕获组：

```bash
:%s/\v\d+/\=submatch(0)*10/g         " 所有数字乘以 10
:%s/\v<\w+>/\=toupper(submatch(0))/g " 全部转大写（也可用 \U）
```

## 在多个文件中查找替换

```bash
:args **/*.txt
:argdo %s/\vfoo/bar/ge | update
```

- `e` 屏蔽无匹配文件的报错；`update` 只写回有改动的文件；前置 `:set hidden`。

```bash
" 可视选区只在选中范围内替换（范围直接来自选区）：
:'<,'>s/pattern/replacement/g
```
