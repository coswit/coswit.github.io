# 第15章 global 命令（:global）

> `:g[lobal]/{pattern}/[cmd]`：**在所有匹配行上执行任意 Ex 命令**——把"查找"与"批量操作"合二为一，是 Vim 最被低估的命令之一。

## 结识 global 命令

```bash
:[range]g[!]/{pattern}/[cmd]
```

- 默认 range 为 `%`（整个文件）；`cmd` 缺省为 `:p`（print）；
- `:g!` 或 `:v[global]`（inverse，反向）：对**不匹配**的行执行；
- 执行机制：Vim 先对范围内所有行做**两遍扫描**——第一遍标记（mark）匹配行，第二遍逐行执行命令，因此命令中删除/移动行都是安全的。

## 删除所有匹配行 / 保留匹配行

```bash
:g/pattern/d        " 删除所有含 pattern 的行
:g!/pattern/d       " 删除所有不含 pattern 的行（等价 :v/pattern/d）
:g/^\s*$/d          " 删除所有空白行
:g/\v<rat>/d        " 配合 \v
```

## 在匹配行上执行普通模式命令

```bash
:g/pattern/normal @a    " 在每个匹配行执行宏 a（第11章）
:g/^#/normal I//        " 给标题行统一加注释（示意）
```

- 与 `:%normal`（全部行）不同，`:g/pat/normal` 只作用于匹配行——**按内容筛选行再批量执行**。

## 用寄存器收集匹配行（汇总到一处）

利用**大写寄存器追加**特性：

```bash
:g/TODO/y A         " 把所有含 TODO 的行依次追加到寄存器 a
:reg a              " 查看
:put a              " 粘贴出汇总清单
```

## 复制/移动匹配行

```bash
:g/pattern/t$       " 把所有匹配行复制到文件末尾（保留原处）
:g/pattern/m0       " 把所有匹配行移到文件开头（原处消失）
```

## 经典应用：反转文件行序

```bash
:g/^/m0
```

- 原理：`^` 匹配所有行；`m0` 把每一行依次移到顶部——第一行被后续行依次顶下去，结果即逆序；
- 同理 `:g/^/m$` 无效果（移到尾部不打乱顺序），改用 `:g/./m0`（跳过空行可保留其位置）。

## 用途速查

| 任务 | 命令 |
| ---- | ---- |
| 删除匹配行 | `:g/pat/d` |
| 删除不匹配行 | `:v/pat/d` |
| 汇总匹配行 | `:g/pat/y A` → `:put a` |
| 匹配行移到文件尾 | `:g/pat/m$` |
| 整体倒序 | `:g/^/m0` |
| 匹配行批量执行宏 | `:g/pat/normal @a` |
