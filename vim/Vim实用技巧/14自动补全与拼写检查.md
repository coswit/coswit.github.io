# 第19~20章 自动补全（autocompletion）与拼写检查（spell check）

> 插入模式的两大辅助系统：**自动补全**以 `<C-x>` 进入补全子模式、按补全源选择候选；**拼写检查**高亮错误词并给出建议，两者通过 `<C-x><C-s>` 打通。

## 一、自动补全

## 认识关键字自动补全（keyword autocompletion）

- 插入模式按 `<C-n>` / `<C-p>`：在"补全来源"中查找下一个/上一个匹配词；
- 触发方式有两种：**自动**（输入若干字符后直接 `<C-n>`）与**显式**（`<C-x>…` 指定补全源）。

## 补全命令一览（`<C-x>` 子模式）

| 按键 | 补全源 |
| ---- | ------ |
| `<C-x><C-n>` | 当前缓冲区关键字（keywords in current buffer） |
| `<C-x><C-i>` | 当前 + 包含文件（included files）中的关键字 |
| `<C-x><C-]>` | tags 索引（第16章） |
| `<C-x><C-k>` | 字典（dictionary 选项） |
| `<C-x><C-t>` | 同义词词典（thesaurus 选项） |
| `<C-x><C-l>` | 整行（whole lines） |
| `<C-x><C-f>` | 文件名/路径（file names） |
| `<C-x><C-d>` | 宏定义/定义名（definitions） |
| `<C-x><C-v>` | Vim 命令行（编辑 vimrc 利器） |
| `<C-x><C-s>` | 拼写建议（spelling suggestions） |
| `<C-x><C-o>` | 全能补全（omni completion，按文件类型语义补全） |

## 与自动补全弹出菜单交互（pop-up menu）

| 按键 | 用途 |
| ---- | ---- |
| `<C-n>` / `<C-p>` | 选下一项 / 上一项 |
| `<C-y>` | 选中当前项，退出菜单 |
| `<C-e>` | 放弃菜单，恢复输入的原文 |
| `<C-h>` / `<BS>` | 再删一个字符并刷新候选 |

相关选项（'completeopt'）：

```bash
:set completeopt=menu,menuone,longest
" menu     显示弹出菜单
" menuone  只有一个候选也弹菜单
" longest  只插入最长公共前缀
" preview  额外显示预览窗口（tag/omni 信息）
```

## 掌控关键字补全的来源（'complete' 选项）

`'complete'` 决定 `<C-n>` 扫描的范围，常用标志：

| 标志 | 来源 |
| ---- | ---- |
| `.` | 扫描当前缓冲区 |
| `w` | 其他窗口中的缓冲区 |
| `b` | 缓冲区列表中其他已加载缓冲区 |
| `u` | 未加载的缓冲区 |
| `t` | tags |
| `i` | 当前文件 include 的文件 |
| `k` / `kspell` | 字典 / 拼写字典 |

```bash
:set complete=.,w,b,u,t    " 按需增减
```

## 各类补全源要点

```bash
" 字典补全（dictionary）
:set dictionary+=/usr/share/dict/words
<C-x><C-k>

" 同义词补全（thesaurus）：文件每行是一组同义词，第一个词作为补全关键字
:set thesaurus+=~/.vim/thesaurus/mthesaur.txt
<C-x><C-t>

" 整行补全：输入行首几个字符后 <C-x><C-l>，直接补出整行
" 文件名补全：路径上下文中 <C-x><C-f>（相对当前文件目录）

" 全能补全（omni completion）：由 filetype 插件提供 'omnifunc'
:set filetype?
<C-x><C-o>      " HTML/CSS/Ruby 等按语法上下文补全
```

## 练习建议

- 先练熟三组：`<C-p>`/`<C-n>`（源内导航）、`<C-x><C-o>`（语义补全）、`<C-x><C-f>`（路径补全）；
- 弹出菜单打断节奏时，用 `longest` 先只补公共前缀再继续输入；
- 语言级补全（LSP 类）在本书成书时代尚未出现，现代用法见 Neovim LSP 相关笔记。

## 二、拼写检查

## 对你的工作进行拼写检查

```bash
:set spell                 " 开启（:set nospell 关闭）
:set spelllang=en_us       " 指定语言/区域
```

| 按键 | 用途 |
| ---- | ---- |
| `]s` / `[s` | 跳到下一个 / 上一个拼写错误（bad word） |
| `z=` | 对光标下的词给出**修改建议列表**（按编号选择） |
| `zg` | good word：把光标下的词加入拼写文件 |
| `zw` | wrong word：把光标下的词标记为"错误词" |
| `zug` / `zuw` | undo：撤销 zg / zw |
| `zG` `zW` `zN` | 仅当前会话生效的好词/坏词（不写入文件） |

- 拼写检查按**窗口**局部生效：可以一个窗口开（注释/文档）、一个窗口不开（代码）。

## 使用其他拼写字典（spelllang）

```bash
:set spelllang=de_de       " 德语（首次使用 Vim 会提示下载/构建对应 spell 文件）
:set spelllang=en_gb       " 英式拼写
:set spelllang=en,de       " 多语言同时启用
```

- 词表文件位于 `$VIMRUNTIME/spell/`，个人词表默认 `~/.vim/spell/{lang}.utf-8.add`。

## 将单词添加到拼写文件（spellfile）

- `zg` 的目标文件由 `'spellfile'` 指定，可维护多份（如"代码术语表"和"人名表"各一份）：

```bash
:set spellfile=~/.vim/spell/en.utf-8.add
:set spellfile+=~/.vim/spell/proj-terms.utf-8.add
```

- 词表是普通文本文件，一行一词，可直接编辑或版本管理。

## 在插入模式中更正拼写错误

- `<C-x><C-s>`：以拼写建议作为补全源——光标前的错误词直接被替换为选中的建议；
- 流程：插入模式发现拼错 → `<C-x><C-s>` → `<C-n>`/`<C-p>` 选择 → 继续输入。
