# 第21章 接下来干什么（What's Next）

> 原书最后一章：把书里的技巧变成日常习惯的方法，以及继续精进的资源。

## 持续练习，形成肌肉记忆（muscle memory）

- 一次专注练一个技巧，直到不用思考（例如本周只用 `.` 范式，下周只用文本对象）；
- 慢一点没关系：刻意使用正确命令的前期成本，会被长期效率放大；
- 识别重复：每当发现自己在重复按键，就停下来问——"有没有这个操作的重复键？能否构造可重复的修改？"

## 让文档成为第一参考

```bash
:h user-manual     " 用户手册（按主题学习）
:h reference       " 参考手册（按命令检索）
:h index           " 各模式按键总表
:h tips            " 官方技巧列表
:h ex-cmd-index    " Ex 命令索引
```

- 忘记命令时优先 `:h`，而不是搜索——文档自带示例与相关选项链接。

## 定制你的 Vim（vimrc 起步配置）

- 把书中散见的建议汇总成自己的配置起点：

```bash
set nocompatible
set nrformats=          " <C-a>/<C-x> 只按十进制
set hidden              " 允许离开未保存缓冲区
set incsearch hlsearch smartcase ignorecase
set path+=$PWD/**       " :find / gf 工程化
set wildmenu wildmode=list:longest
```

- 键位映射只留给"高频且别扭"的操作（如 `inoremap jk <Esc>`、回车清除高亮）；
- 更进一步：写 Vim 脚本（`:h usr_41.txt`）、制作自己的插件。

## 全书回顾（一页清单）

1. `.` 范式（the Dot Formula）：一键移动 + 一键执行（`;` `n` 与 `.`）；
2. Vim 语法：`操作符（operator） + 动作命令（motion）`，优先文本对象（text object）；
3. 普通模式（Normal mode）是默认状态，插入模式（Insert mode）只用来输入；
4. Ex 命令的 `range` + `:normal` + `:g` = 批量处理三件套；
5. 寄存器（register）族谱：`"0` 保复制（yank）、`"_` 黑洞（black hole）、`"+` 剪贴板（clipboard）；
6. 宏（macro）：规范光标、可重复定位、结尾前进一行；串行 `@@` / 并行 `:normal @a`；
7. 正则约定：查找域 `\v`（very magic），字面量 `\V`（very nomagic），替换域记 `\r`；
8. 查找→确认→替换：`*`、`n`、`cw`、`.` 与 `:%s///g`、`:argdo` 两套节奏按需选用；
9. 工程化：ctags 跳定义，`:make` 收错误，grep/vimgrep 进 Quickfix。
