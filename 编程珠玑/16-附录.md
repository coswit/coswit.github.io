## 附录 1：算法目录（A Catalog of Algorithms）

本书覆盖了大学算法课的大部分内容，但视角不同——重应用与编码、轻数学分析。此目录把全书内容映射回标准大纲。

**排序**：输出是输入的有序排列。用途远不止"要有序输出"——**收集相等元素**（变位词、后缀数组聚相等短语）、**产生规范形**（词内字母排序作变位词签名）、**重排数据**（附加键 + 排序转置磁带矩阵）。

| 算法 | 复杂度 | 特点 |
| --- | --- | --- |
| 插入排序 | 最坏/随机 $O(n^2)$，几乎有序 $O(n)$ | 本书唯一**稳定排序（stable sort）**：相等键保持输入中的相对顺序 |
| Quicksort | 平均 $O(n\log n)$，最坏 $O(n^2)$ | 递归、平均对数栈空间；11.3 节改进版对任意输入平均 $O(n\log n)$；C 库 qsort 通常用它实现 |
| Heapsort | 任意输入 $O(n\log n)$ | 非递归、仅常数额外空间 |
| Merge Sort | —— | 适合排序文件（1.3 节） |
| 位图排序 | $O(n)$ | 整数来自小范围、无重复、无附加数据（1.4 节） |
| 基数排序 | —— | McIlroy 位串排序（11.5 题）可推广到大字母表 |

**搜索**：判定输入是否属于给定集合、可能取回关联信息。

| 算法 | 复杂度 | 特点 |
| --- | --- | --- |
| 顺序查找 | $O(n)$ | 最简单；遍布全书（连散列链表、稀疏矩阵、压缩词典都是它） |
| 二分查找 | 约 $\log_2 n$ 次比较 | 要求有序数组；9.3 节版可定位第一次出现 |
| 哈希 | 平均 $O(1)$ | 无最坏保证、不支持序操作 |
| 二分搜索树 | 平均 $O(\log n)$ | 平衡树给最坏保证，标准模板库（Standard Template Library, STL）set/map 的通常实现 |
| 键索引 | $O(1)$ | 键本身作数组下标：电话号码、字符、棋盘、哈希值…… |

**其他集合算法**：优先队列（堆实现，插入/取最小各 $O(\log n)$）；选择（第 k 小元素，快速选择期望 $O(n)$）。

**字符串算法**：变位词集（2.4/2.8 节）、字符分类查表（9.6 题）、词频统计（15.1 节，STL 与定制哈希）、最长重复子串与 Markov 文本生成的后缀数组（15.2/15.3 节）。

**向量与矩阵算法**：子序列交换（旋转三解法，2.3 节）、矩阵转置（排序法）、求最大值（哨兵）、共享空间的叠加结构（10.3/14.4 节）、稀疏向量与矩阵（3.1/10.2/13.8 节）、最大和子向量的五个算法（Column 8）。

**随机对象**：伪随机整数（Solution 12.1）、洗牌（Algorithm P）、随机子集（Knuth Algorithm S、集合法、打乱法、Floyd 算法）、未知总数时随机选一（蓄水池）。

**数值算法**：加法版欧几里得 gcd（2.3 题）、常系数线性递推（3.7 题）、快速幂（4.9 题）、查表算三角函数（9.11 题）、**Horner 法则**求多项式（Solution 9.12）、大组浮点数求和（从小到大合并减小舍入误差）。

## 附录 3：时空成本模型（Cost Models for Time and Space）

7.2 节的两个小程序可以长成一页式成本报告（完整代码在原书网站）。

**空间模型（spacemod.cpp）**：先用 `sizeof` 精确测量基本对象（32 位机典型值：char 1、short 2、int 4、指针 4、long 4、float 4、double 8），再对一打结构同时报 `sizeof` 与连续 `new` 返回指针的间距：

```text
structc     1   48 48 48 48 48 48 48 48 48 48
structic    8   48 48 48 48 48 48 48 48 48 48
structip    8   48 48 48 48 48 48 48 48 48 48
structdc    16  64 64 64 64 64 64 64 64 64 64
structcdc   24  -3744 4096 64 64 64 64 64 64 64 64
```

两个教训：估结构体大小要**先加各字段再算对齐**（structcdc 字段和 10 字节、实占 24 字节）；**分配器的开销**——sizeof ≤ 12 的结构实占 48 字节，13~28 字节实占 64 字节，一般每块是 16 的倍数、开销 36~47 字节（贵得惊人；作者用的另一些系统里 8 字节记录只多 8 字节开销）。

**时间模型（timemod.c）**：对一组 C 操作各测双层循环耗时，报五次原始时钟数与平均纳秒数（400MHz Pentium II、关闭优化——开了优化计时循环会被整个删掉、时间全为零）：

```text
Integer Arithmetic (n=5000)
 {}           10      // 空循环本身约 10 纳秒
 k = i + j    20
 k = i & j    20
 k = i / j    97      // 除法贵一个数量级
 k = i % j    97      // 取余同上

Max Function, Macro and Inline (n=5000)
 k = (i > j) ? i : j   26
 k = maxmac(i, j)      26
 k = maxfunc(i, j)     54   // 函数版比宏/内联贵约一倍

Math Functions (n=1000)
 k = rand()          40
 fk = sqrt(j+fi)    188
 fk = sin(j+fi)     344
 fk = sinh(j+fi)   2229   // 高级三角函数进入微秒级

Memory Allocation (n=500)
 free(malloc(16))       2484
 free(malloc(100))      3044
 free(malloc(2000))     4959   // 分配最贵，比基本操作贵两个数量级
```

读法与 9.2 节呼应：多数算术/逻辑运算约 20 纳秒一档；**除法与取余贵一个数量级**（所以内层循环里换 if）；函数调用比内联贵约 20 纳秒；**malloc 是最贵的常规操作**——这就是 9.1 节节点缓存与 13 篇一次性块分配能大幅提速的量化根据。这些数字只属于那台机器，但**各档之间的比值结构**在任何时代都值得先量一量再动手调优。
