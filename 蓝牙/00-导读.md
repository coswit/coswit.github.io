## 2. 蓝牙技术一分钟速览

**蓝牙(Bluetooth)** 是工作在 2.4 GHz ISM(Industrial, Scientific and Medical)免许可频段的短距离无线通信技术,由蓝牙技术联盟(Bluetooth Special Interest Group, SIG)制定与维护。今天的"蓝牙"实际上是**两套同名的技术**共用一个牌子:

- **经典蓝牙(Basic Rate / Enhanced Data Rate, BR/EDR)**:面向音频流、文件传输等较高吞吐场景,如耳机、车载。
- **低功耗蓝牙(Bluetooth Low Energy, BLE)**:2010 年随 Core Specification 4.0 引入,面向纽扣电池供电的传感器、遥控器、标签等场景,是物联网的主力协议,也是本系列的主角。

两者名字相同、品牌相同、常共存于同一颗双模(dual-mode)芯片,但空口调制、分组格式、协议栈几乎完全不同——**BLE 不是"低功耗版的经典蓝牙",而是一套独立的、设计目标完全不同的协议**,前身是诺基亚 2006 年提出的 Wibree 项目,2010 年被 SIG 收编为 Bluetooth 4.0 的 LE 部分。

## 3. 版本演进时间线(2010-2026)

| 版本 | 年份 | 关键特性 |
| ---- | ---- | -------- |
| 4.0 | 2010 | 引入 BLE,单模/双模芯片生态起步 |
| 4.1 | 2013 | BLE 与 LTE 共存优化;支持设备同时充当主机与从机;4.1 服务 |
| 4.2 | 2014 | 数据包长度扩展(Data Length Extension, DLE);隐私 1.2;IPv6 over BLE(6LoWPAN) |
| 5.0 | 2016 | 2M PHY 与 Coded PHY(长距离);扩展广播(Extended Advertising);广播容量提升 8 倍 |
| 5.1 | 2019 | 到达角/离开角(AoA/AoD)寻向;广播重试;周期广播同步转移 |
| 5.2 | 2020 | LE Audio 三大基石:等时信道 ISO、LC3 编解码、CIS/BIS;功率控制 |
| 5.3 | 2021 | 连接次速率(Conn Subrating);周期广播接收增强;信道分类;加密密钥长度协商增强 |
| 5.4 | 2023 | 带响应的周期广播(PAwR);加密广播数据——面向电子货架标签(ESL)等星型网络 |
| 6.0 | 2024 | **信道探测(Channel Sounding, CS)** 亚米级安全测距(宣称约 ±0.5 m);决策广播过滤;监测广播者;帧间距更新 |
| 6.1 | 2025 | 面向近距离安全的增强(如 SHIELD,配合 Channel Sounding 在未配对设备间建立共享密钥,强化中继攻击防护) |
| 6.2 / 6.3 | 2026 | 已由 SIG 采纳发布;更高吞吐(HDT)相关能力在推进中 |

> 以上 6.x 时间线截至 2026 年 8 月,以蓝牙 SIG 官网为准;具体特性的落地节奏通常滞后于规范发布 1-2 年(芯片 → 系统 → 应用)。

## 5. 术语与符号约定

- 本系列"蓝牙 5.x/6.x"均指核心规范(Core Specification)版本;广播、连接等协议行为以 4.2/5.x 规范为基准描述,更早版本的差异在文中单独标注。
- 角色 terminology 沿用新版规范:**Central / Peripheral**(中心/外围,旧称 master/slave)、**Broadcaster / Observer**(广播者/观察者)。
- 原书成书于 2012-2014 年(基于 4.0/4.1 规范),涉及已被 5.x 修订的内容(如广播 31 字节限制、AES-CCM 加密细节)时,笔记按新规范更新并注明。
