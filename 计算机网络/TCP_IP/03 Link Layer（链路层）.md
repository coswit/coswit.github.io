> Ethernet 帧格式、MAC 地址、交换机、VLAN 与 MPLS，以及 MTU。

## 1. 链路层的作用

链路层在**相邻节点**（同一链路/网络上的直连节点）之间传送数据：

- 为网络层（IP）提供服务：封装 IP 数据报为帧、寻址同链路设备、差错检测。
- 协议多样：Ethernet、Wi-Fi (802.11)、PPP、MPLS 等。IP 对链路技术的多样性完全透明——这正是 TCP/IP 长寿的关键之一。

```
        ┌────────┐   链路A    ┌────────┐   链路B    ┌────────┐
        │ 主机A  │──────────▶│ 路由器 │──────────▶│ 主机B  │
        └────────┘  Ethernet └────────┘   Wi-Fi   └────────┘
```

## 2. Ethernet 与 IEEE 802 局域网

### Ethernet II（DIX）帧格式

```
┌─────────┬─────┬─────┬──────────┬─────────────────────┬─────┐
│ 前导+SFD │ 目的 │ 源  │ Type/   │    数据 (46~1500B)   │ CRC │
│ (8B)    │ MAC │ MAC │ Len (2B) │      (不足46B补齐)    │(4B) │
└─────────┴─────┴─────┴──────────┴─────────────────────┴─────┘
```

| 字段 | 大小 | 说明 |
| ---- | ---- | ---- |
| Preamble + SFD | 8 B | `10101010...` ×7 + `10101011`，用于同步（不计入帧长） |
| Destination / Source MAC | 各 6 B | 48 bit 硬件地址 |
| Type / Length | 2 B | 值 ≥ **0x0600 (1536)** 视为 **EtherType**（IPv4=0x0800、ARP=0x0806、IPv6=0x86DD、802.1Q=0x8100）；≤ 1500 则为 IEEE 802.3 长度，后接 LLC/SNAP 头 |
| Data | 46–1500 B | 载荷（IP 数据报），短于 46 B 需 padding |
| CRC (FCS) | 4 B | 循环冗余校验，错误帧直接丢弃（不重传，交给上层） |

- 最小帧 64 B、最大帧 1518 B（不含 VLAN tag）；巨型帧（jumbo frame）可达约 9000 B，多用于存储/数据中心网络。
- **Ethernet（DIX）与 IEEE 802.3/802.2（LLC/SNAP）** 是两套并存的标准，现代 TCP/IP 网络几乎都用 Ethernet II 封装。

### MAC 地址

- 48 bit，通常写作 `aa:bb:cc:dd:ee:ff`（或 `-` 分隔）。
- 第一字节最低位 **I/G bit**：0 = 单播（unicast），1 = 组播（multicast）；次低位 **U/L bit**：0 = 全局唯一（厂商烧录 OUI），1 = 本地管理（locally administered，随机 MAC）。
- 前 24 bit 是厂商 OUI（IEEE 分配），后 24 bit 由厂商分配。
- IPv4 组播地址低 23 bit 映射到 MAC `01:00:5e:xx:xx:xx`；IPv6 组播低 32 bit 映射到 `33:33:xx:xx:xx:xx`（见第 9 章）。

### 全双工 / 半双工与 CSMA/CD

- **半双工（half-duplex）**：共享介质（同轴电缆、集线器），需 **CSMA/CD**（载波侦听多路访问/冲突检测）：发前侦听、边发边检、冲突退避（二进制指数退避）。
- **全双工（full-duplex）**：交换机点对点链路的现代形态，可同时收发，**不再需要 CSMA/CD**。
- 速率：10 Mb/s → 100 Mb/s → 1 Gb/s → 10/100 Gb/s+；全双工下信道由交换矩阵独享。
- 最小帧 64 B 的来历：半双工以太网要求帧时长不小于一个争用期（512 bit time），否则帧发完了还检测不到冲突；短载荷须用 padding 补齐到 46 B。

## 3. 网桥与交换机（Bridges and Switches）

- **网桥/交换机** 在链路层转发帧：学习每个端口收到的帧的**源 MAC**，建立 {MAC → 端口} 转发表（CAM 表）；按**目的 MAC** 查表转发，查不到则**泛洪（flood）** 到所有其他端口。
- **冲突域（collision domain）**：集线器的所有端口是一个冲突域；交换机每个端口是独立冲突域（全双工下冲突不复存在）。
- **广播域（broadcast domain）**：广播帧可达范围；交换机不隔离广播域，**路由器**（或 VLAN）隔离广播域。

### 环路与生成树协议（STP）

- 冗余链路形成**环路**时，广播帧被永久循环放大——**广播风暴（broadcast storm）**。
- **生成树协议（Spanning Tree Protocol, IEEE 802.1D）**：交换机之间交换 BPDU，计算出无环的生成树拓扑，逻辑阻塞冗余端口；链路故障后重新收敛（RSTP 加速收敛）。

### VLAN（802.1Q）

- 在 Ethernet 头中插入 **4 B tag**：TPID(0x8100) + 优先级 PCP(3bit) + DEI(1bit) + **VLAN ID(12bit，0–4095)**。
- 一个物理交换机被划分为多个逻辑广播域；VLAN 间通信需要路由器或三层交换机。

## 4. 其他链路技术

- **PPP（Point-to-Point Protocol）**：点对点串行链路（早期拨号），有 HDLC 式帧定界、LCP 链路协商、NCP（如 IPCP 协商 IP 地址）、可选认证（PAP/CHAP）。PPPoE 用于宽带拨号（MTU 1492）。
- **Loopback（环回接口）**：127/8 或 ::1，流量不离开协议栈，常用于本机服务测试；Linux 上 MTU 为 65536。
- **组播/广播能力差异**：Ethernet 天然支持组播/广播；点对点链路天然不支持（无所谓"广播"），影响第 9 章协议的设计。

## 5. MPLS（Multiprotocol Label Switching）

- 在 IP 头之前插入 **32 bit 垫层头（shim header）**：

```
┌───────────────┬──────┬─────┬──────┐
│ Label (20bit) │ TC(3)│ S(1)│TTL(8)│
└───────────────┴──────┴─────┴──────┘
```

- **标签交换（label switching）**：路由器（LSR）按入标签查 **LFT** 做标签交换转发，不解析 IP 头；入口 LER 打标签、出口 LER 弹出标签。
- 转发路径由控制平面（LDP、RSVP-TE）建立，称为 **LSP（Label Switched Path）**。
- 用途：流量工程（TE）、VPN（如 MPLS L2/L3 VPN）、快速重路由（FRR）。MPLS 位于链路层与网络层之间，"2.5 层"。
- **倒数第二跳弹出（PHP）**：常见优化，由倒数第二个 LSR 弹出标签，出口 LER 直接读 IP 头。

## 6. MTU 与路径 MTU

| 链路类型 | 典型 MTU |
| ---- | ---- |
| Ethernet / 802.3 | 1500 / 1492 |
| IEEE 802.11 (Wi-Fi) | 通常 1500（帧聚合可达更高） |
| PPPoE | 1492 |
| GRE 隧道 | ≈ 1476（外层开销） |
| IPv6（协议要求最小） | **1280**（所有链路必须支持） |
| Loopback | 65536 |

- 分组经过**路径上最小的 MTU** 决定能否一次发出：超长 IP 数据报需分片（IPv4）或源端分片/ PMTUD（IPv6 强制 PMTUD，详见第 8、10 章）。
- 隧道叠加封装会逐层缩小有效 MTU，是经典的"小包通、大包卡"问题根源（如 ping 通但 HTTP 不通）。

## 7. 要点回顾

- Ethernet II 帧：6+6+2+载荷+CRC；EtherType ≥ 0x0600 区分类型；载荷 46–1500 B。
- MAC 48 bit，I/G 位定单播/组播，U/L 位定全局/本地；交换机学习源 MAC、泛洪未知帧；STP 防环路；VLAN 隔离广播域。
- 冲突域随交换机消失，广播域靠路由器/VLAN 隔离。
- MPLS 用 20 bit 标签做快速转发与流量工程，介于 2/3 层之间。
